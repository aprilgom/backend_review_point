# FC0364 · 판단을 타입에 위임하는 표현

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0359](FC0359.md) · [다음 FC: FC0367 →](FC0367.md)

## 검토 질문

- [ ] 외부에서 값을 꺼내 비교하는 대신 타입에 의미 있는 판단을 요청하면 의도가 더 잘 드러나는가?

**직접 작성한 예시**

```java
enum RequestMethod {
    GET, POST;
    boolean isGet() { return this == GET; }
}
```

**적용 설명:** 판단을 타입에 보내는 작은 예다. 단순 비교를 감싼 메서드가 실제 가독성을 높이는지 검토한다.

## 구체적인 검토 사례

- [ ] **상황:** 외부가 값을 꺼내 같은 비교를 반복한다.
  - **판단 기준:** 의미 있는 판단을 타입에 둘 수 있다.

- [ ] **상황:** 단순 비교를 감싸는 메서드만 늘어난다.
  - **판단 기준:** 호출부가 더 읽기 쉬워지는지 본다.
