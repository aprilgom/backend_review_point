## 검토 질문

- [ ] 여러 식별자에 대한 개별 조회를 묶어서 처리하며 입력 순서와 반환 순서 차이도 다루는가?

**직접 작성한 예시**

```java
List<Station> stations = stationStore.findAllByIds(stationIds);
```

**적용 설명:** 역별 반복 조회 대신 일괄 조회한다. 반환 순서는 입력 순서와 다를 수 있어 필요하면 ID로 다시 배치한다.

## 구체적인 검토 사례

- [ ] **상황:** 관련 ID마다 개별 조회한다.
  - **판단 기준:** 한 번에 필요한 집합을 가져올 수 있다.

- [ ] **상황:** 요청 ID가 너무 많아 한 쿼리가 커진다.
  - **판단 기준:** 파라미터 제한과 묶음 크기를 고려한다.
