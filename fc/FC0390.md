# FC0390 · 현재 상태를 반영한 접근 검증

[소속 분야: 인증·보안·비밀값](../20-security.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0391](FC0391.md) · [다음 FC: FC0392 →](FC0392.md)

## 검토 질문

- [ ] 토큰 발급 당시 정보뿐 아니라 현재 계정 상태·폐기·자원 권한을 필요한 수준으로 확인하는가?

**직접 작성한 예시**

```java
VerifiedToken token = tokenVerifier.verify(rawToken);
Account account = accounts.requireActive(token.subject());
authorization.requireAllowed(account, resource);
```

**적용 설명:** 토큰 검증과 현재 계정 상태·자원 권한 확인을 구분한다. 폐기·만료·키 회전 정책도 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 토큰 발급 당시 상태만 신뢰한다.
  - **판단 기준:** 현재 계정·폐기·권한 요구를 확인한다.

- [ ] **상황:** 상태를 매번 조회해 부하가 커진다.
  - **판단 기준:** 허용 지연과 폐기 정책에 맞는 방법을 선택한다.
