## 검토 질문

- [ ] 스키마 자동 생성·삭제 옵션의 적용 시점과 데이터 손실 범위를 이해하고 환경별로 분리했는가?

**직접 작성한 예시**

```properties
# 일회성 테스트 DB에만 사용하는 설정 예
hibernate.hbm2ddl.auto=create-drop
```

**적용 설명:** 생성·삭제 수명에 따른 데이터 손실을 이해하는 예시다. 운영 설정으로 복사하지 않고 운영 스키마 변경은 명시적으로 관리한다.

## 구체적인 검토 사례

- [ ] **상황:** 종료 시 스키마를 삭제하는 옵션을 쓴다.
  - **판단 기준:** 일회성 환경에만 적용되는지 확인한다.

- [ ] **상황:** 환경 설정을 복사해 운영에 적용한다.
  - **판단 기준:** 데이터 수명에 맞는 옵션을 별도로 관리한다.
