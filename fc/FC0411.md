# FC0411 · ReservationServiceTest의 테스트가 실패한다고 보고한다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0403](FC0403.md) · [다음 FC: FC0409 →](FC0409.md)

- [ ] ReservationServiceTest의 테스트가 실패한다고 보고한다. (문제 보고)
  - 조건: 실패한 테스트 사례, 원인, 실행 환경 및 후속 수정 여부는 제시되지 않았다. 테스트 실패 보고 이상으로 원인을 추정하지 않는다.

- [ ] ReservationServiceTest의 테스트들이 전반적으로 실패하고 있다는 문제를 보고했다. (문제 보고)
  - 조건: 작성자는 theme_slot에 대한 FakeDao 부재가 원인이었다고 설명하고 수정했다고 보고했다. 수정 이후 테스트 통과 여부는 대화에서 별도로 확인되지 않는다.

- [ ] 지목한 ReservationServiceTest뿐 아니라 다른 곳에서도 테스트가 실패한다고 보고한다. (문제 보고)
  - 조건: 작성자는 예약 unique 제약 조건을 추가하면서 문제가 생겼다고 설명하고 테스트를 통과하도록 수정하겠다고 답했다. 이는 작성자의 원인 설명과 수정 계획이며, 실제 원인이나 수정 후 통과 여부는 확인되지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```sh
./gradlew test --tests '*BookingServiceTest' --rerun-tasks
```

**적용 설명:** 실패 재현 뒤 보고서에서 최초 원인과 준비 단계를 확인한다. 이 명령은 예시이며 이번 문서 작성 중 앱 테스트를 실행했다는 뜻은 아니다.
