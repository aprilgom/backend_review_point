# FC0335 · 메서드 사용처와 제거 근거

## 검토 질문

- [ ] 미사용으로 보이는 메서드를 정적·동적·외부 호출 가능성까지 확인하고 정리하는가?

**직접 작성한 예시**

```sh
git grep -n "legacyMethod" -- '*.java'
```

**적용 설명:** 정적 호출 검색의 예다. 결과가 없어도 리플렉션·외부 소비자·프레임워크 콜백 여부를 확인한다.

## 구체적인 검토 사례

- [ ] 해당 메서드가 사용되지 않는 것 같다고 지적했다. (관찰)
  - 조건: 리뷰 참여자의 추정이며, 실제 사용 여부나 제거 결과는 대화에서 확인되지 않는다.

- [ ] 해당 메서드가 사용되지 않는 것으로 보인다고 지적했다. (관찰)
  - 조건: 작성자 외 참여자의 관찰이며, 실제 사용 여부나 제거 결과는 대화에서 확인되지 않는다.

- [ ] ReservationTimeResponse에 사용되지 않는 메서드가 있음을 지적했다. (관찰)
  - 조건: 작성자는 서비스에서 from 메서드를 사용하도록 변경했다고 보고했다. 리뷰어가 메서드 삭제를 명시적으로 요구한 것은 아니다.
