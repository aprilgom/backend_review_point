## 검토 질문

- [ ] 변수 재할당을 막을 필요에 맞게 final을 사용하고 객체 자체의 불변성과 구분하는가?

**직접 작성한 예시**

```java
final Path resource = root.resolve(fileName);
```

**적용 설명:** 변수 재할당을 막는 final이다. Path 대상 파일이 불변이거나 접근이 안전해지는 것은 아니다.

## 구체적인 검토 사례

- [ ] **상황:** 일부 지역 변수만 불필요하게 재할당된다.
  - **판단 기준:** final 등으로 의도를 표현할 수 있다.

- [ ] **상황:** final이면 내부 객체도 불변이라고 본다.
  - **판단 기준:** 참조 재할당과 객체 변경을 구분한다.
