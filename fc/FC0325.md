# FC0325 · 재할당 제한과 선언 일관성

## 검토 질문

- [ ] 변수 재할당을 막을 필요에 맞게 final을 사용하고 객체 자체의 불변성과 구분하는가?

**직접 작성한 예시**

```java
final Path resource = root.resolve(fileName);
```

**적용 설명:** 변수 재할당을 막는 final이다. Path 대상 파일이 불변이거나 접근이 안전해지는 것은 아니다.

## 구체적인 검토 사례

- [ ] 다른 변수 선언과의 일관성을 위해 resource 변수에도 final을 붙이는 것을 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 final이 반드시 필요한 것은 아니라고 명시했다. 작성자는 반영하겠다고 답했으며, 실제 변경 여부는 확인되지 않는다.

- [ ] 일부 변수에만 final을 유지하는 이유와 final 사용을 일관되게 적용할 기준을 논의했다. (토론)
  - 조건: 작성자는 새 코드에는 평소 습관대로 final을 붙이지 않았고 기존 코드의 final만 유지했다고 설명하며, 전체 적용과 제거 중 의견을 물었다. 리뷰 참여자는 사용 여부를 통일하는 편을 선호하고 꼭 필요하지 않으면 제거한다고 답했으나, 자신의 의견을 따를 필요는 없다고 명시했다.

- [ ] final 사용을 일관되게 적용하자고 제안했다. (개선 제안)
  - 조건: 작성자는 코드 전반에서 재할당하지 않는 변수에 final을 붙였다고 보고했다.
