# FC0013 · 생성자 초기화 경로의 통합

## 검토 질문

- [ ] 여러 생성자가 같은 검증과 초기화를 수행하도록 위임 관계를 정리할 수 있는가?

**직접 작성한 예시**

```java
Counter() { this(0); }
Counter(int initial) {
    if (initial < 0) throw new IllegalArgumentException();
    this.value = initial;
}
```

**적용 설명:** 생성자 내부 조각이다. 검증과 초기화를 한 곳에 모으면 생성 경로별 규칙 차이를 줄일 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 생성자마다 동일 필드를 직접 초기화한다.
  - **판단 기준:** 하나의 초기화 경로에 위임해 검증 차이를 막는다.

- [ ] **상황:** 기본값이 생성자마다 다르다.
  - **판단 기준:** 편의 기본값과 필수 업무 규칙을 구분한다.
