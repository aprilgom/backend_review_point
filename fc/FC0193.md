# FC0193 · 변경 설명과 실제 제출 내용

## 검토 질문

- [ ] 설명한 파일 이동·수정이 실제 변경 목록과 커밋에 포함되어 있는가?

**직접 작성한 예시**

```sh
git diff --name-status
git diff --cached --name-status
```

**적용 설명:** 설명한 파일 이동이 작업 트리와 스테이징 변경에 실제로 포함되어 있는지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 설명한 파일 이동이 변경 목록에 없다.
  - **판단 기준:** 작업 트리·스테이징·커밋을 대조한다.

- [ ] **상황:** 관련 수정 일부만 전달한다.
  - **판단 기준:** 재현에 필요한 변경이 함께 포함되었는지 확인한다.
