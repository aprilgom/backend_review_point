# FC0193 · 설명한 패키지 이동이 코드에 보이지 않아 관련 커밋이 누락되었는지 확인을 요청했다.

[소속 분야: 문서·개발·학습 과정](../10-workflow.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0194](FC0194.md) · [다음 FC: FC0192 →](FC0192.md)

- [ ] 설명한 패키지 이동이 코드에 보이지 않아 관련 커밋이 누락되었는지 확인을 요청했다. (설계 질문)
  - 조건: 작성자는 댓글만 남기고 실제 이동을 하지 않았다고 인정하며 옮기겠다고 답했다. 이 대화에는 이동 완료를 확인하는 근거가 없다.

- [ ] 완료했다고 설명한 변경이 push되지 않아 확인할 수 없으므로 코드 반영 상태와 리뷰 요청 과정의 오류 여부를 확인해 달라고 요청했다. (설계 질문)
  - 조건: 리뷰어는 다른 코멘트의 작업 완료 설명도 함께 언급했다. 실제로 리뷰 요청 과정에 오류가 있었는지와 이후 push 여부는 이 대화에서 확인되지 않는다.

- [ ] 수정했다고 설명한 코드가 푸시되지 않은 것으로 보이므로, 코드를 푸시한 뒤 다시 리뷰를 요청해 달라고 한다. (개선 제안)
  - 조건: 리뷰 참여자가 당시 확인한 코드 상태를 바탕으로 한 요청이다. 이후 승인과 머지 안내만으로 누락된 변경이 모두 반영됐다고 확정하지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```sh
git diff --name-status
git diff --cached --name-status
```

**적용 설명:** 설명한 파일 이동이 작업 트리와 스테이징 변경에 실제로 포함되어 있는지 확인한다.
