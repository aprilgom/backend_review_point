# FC0424 · SQL 기반 테스트 데이터 준비

## 검토 질문

- [ ] SQL로 준비하는 데이터가 의도를 드러내고 실행 환경·정리·트랜잭션·병렬 실행 정책과 맞는가?

**직접 작성한 예시**

```sql
-- 테스트 전용 DB에서 실행할 준비 SQL
INSERT INTO category(id, name) VALUES (10, 'fixture');
```

**적용 설명:** SQL 준비 파일을 명시적으로 실행하는 예시다. 정리·트랜잭션·병렬 실행 정책과 함께 사용하며 운영 DB에서는 실행하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** SQL 파일로 공통 데이터를 준비한다.
  - **판단 기준:** 각 시나리오가 필요한 조건을 읽을 수 있게 한다.

- [ ] **상황:** 운영 초기화 파일을 테스트와 공유한다.
  - **판단 기준:** 수명·실행 환경·정리 정책을 분리한다.
