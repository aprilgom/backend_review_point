## 검토 질문

- [ ] 예상 용량 설정이 실제 분포에 맞으며 메모리 낭비와 재할당 비용의 절충을 설명할 수 있는가?

**직접 작성한 예시**

```java
List<Row> rows = new ArrayList<>(expectedRows);
```

**적용 설명:** 초기 용량은 크기와 다르다. 과도한 예상치는 메모리를 낭비하므로 실제 분포를 근거로 사용한다.

## 구체적인 검토 사례

- [ ] **상황:** 예상 행 수로 큰 초기 용량을 설정한다.
  - **판단 기준:** 실제 분포와 메모리 비용을 확인한다.

- [ ] **상황:** 초기 용량을 원소 개수로 착각한다.
  - **판단 기준:** 컬렉션의 크기와 할당을 구분한다.
