## 검토 질문

- [ ] 직접 렌더링하는 코드 대신 구성된 뷰 리졸버에 위임할 수 있으며 책임·설정·테스트가 명확한가?

**직접 작성한 예시**

```java
@org.springframework.stereotype.Controller
class HomeController {
    @org.springframework.web.bind.annotation.GetMapping("/home")
    String home() { return "home"; }
}
```

**적용 설명:** 기존 20개 제외 목록 밖에 있는 Spring 사례다. Handlebars 연동 리졸버가 구성되어 있다는 전제이며 컨트롤러는 직접 렌더링하지 않고 논리 뷰 이름을 반환한다.

## 구체적인 검토 사례

- [ ] **상황:** 직접 렌더링과 자동 뷰 처리가 혼용된다.
  - **판단 기준:** 어느 계층이 출력 책임을 가지는지 정한다.

- [ ] **상황:** 논리 뷰 이름만 반환하면 항상 동작한다고 본다.
  - **판단 기준:** 엔진·리졸버·템플릿 구성을 확인한다.
