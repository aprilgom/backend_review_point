# FC0122 · SQL 파라미터의 타입 보존

## 검토 질문

- [ ] 모든 값을 문자열로 바꾸지 않고 대상 SQL 타입에 맞게 바인딩하며 null도 명확히 처리하는가?

**직접 작성한 예시**

```java
statement.setLong(1, accountId);
statement.setBigDecimal(2, amount);
statement.setDate(3, java.sql.Date.valueOf(day));
```

**적용 설명:** 타입에 맞춰 바인딩한다. NULL은 대상 SQL 타입과 함께 setNull로 전달할 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 숫자·날짜를 모두 문자열로 바인딩한다.
  - **판단 기준:** 대상 SQL 타입과 변환 비용을 확인한다.

- [ ] **상황:** null을 문자열 값처럼 넣는다.
  - **판단 기준:** SQL NULL과 문자 데이터를 구분한다.
