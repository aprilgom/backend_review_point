# FC0373 · 저장소의 조회와 업무 판단 책임

## 검토 질문

- [ ] 복잡한 저장소가 조회 외의 업무 정책까지 담당하는지 확인하고 필요한 책임을 분리할 수 있는가?

**직접 작성한 예시**

```java
List<Order> candidates = orders.findPending();
List<Order> eligible = candidates.stream().filter(policy::canShip).toList();
```

**적용 설명:** 조회와 업무 판단을 나누는 대안이다. 데이터량이 크면 전부 메모리에 올리기보다 DB 조건·전용 조회 계약도 검토한다.

## 구체적인 검토 사례

- [ ] **상황:** 저장소가 복잡한 업무 판단까지 수행한다.
  - **판단 기준:** 조회와 정책을 나눌 수 있다.

- [ ] **상황:** 정책을 옮기며 전체 테이블을 읽는다.
  - **판단 기준:** 책임 분리 뒤에도 조회 범위를 제한한다.
