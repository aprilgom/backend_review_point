# FC0455 · 배열 스트림 API의 요소 의미

[소속 분야: 타입·타입 테스트](../24-type-safety.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0465](FC0465.md) · [다음 FC: FC0457 →](FC0457.md)

## 검토 질문

- [ ] 배열 종류에 따라 스트림 요소 타입과 개수가 달라지는 API 차이를 이해하고 선택했는가?

**직접 작성한 예시**

```java
int[] ids = {1, 2};
assertEquals(2, Arrays.stream(ids).count());
assertEquals(1, Stream.of(ids).count());
```

**적용 설명:** primitive 배열에서 두 호출의 요소 타입·개수가 다름을 보여준다. 참조형 배열과 혼동하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** primitive 배열을 일반 스트림 생성에 넘긴다.
  - **판단 기준:** 배열 하나와 원소들의 스트림을 구분한다.

- [ ] **상황:** 입력 타입이 바뀌었는데 테스트가 그대로다.
  - **판단 기준:** 요소 타입·개수·계산 결과를 확인한다.
