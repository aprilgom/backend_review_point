# FC0263 · 디버그 출력과 민감 정보

[소속 분야: 로그·관측](../15-observability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0264](FC0264.md)

## 검토 질문

- [ ] 개발용 출력이 운영에 남아 자격증명·토큰·개인정보를 노출하거나 로그를 오염시키지 않는가?

**직접 작성한 예시**

```javascript
const result = await signIn(credentials);
showSignedInState(result.user);
// credentials나 token을 console.log로 출력하지 않는다.
```

**적용 설명:** 로그인 디버그 출력 제거 예다. 브라우저 로그와 서버 로그 모두 비밀값 노출을 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 로그인 처리에 디버그 출력이 남는다.
  - **판단 기준:** 토큰·비밀번호가 콘솔에 찍히지 않게 한다.

- [ ] **상황:** 정리하면서 필요한 장애 로그도 없앤다.
  - **판단 기준:** 진단 목적과 임시 출력을 구분한다.
