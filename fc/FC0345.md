## 검토 질문

- [ ] 논리 뷰 이름의 선행 슬래시·접미사·상대 경로가 실제 템플릿 탐색에 어떤 영향을 주는지 알고 있는가?

**직접 작성한 예시**

```java
String viewName = "home";
Path template = templateRoot.resolve(viewName + ".html");
```

**적용 설명:** 자체 리졸버의 상대 이름 계약이다. 앞의 슬래시가 루트를 바꾸는지 확인하고 임의 사용자 입력을 경로로 쓰지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 논리 뷰 이름 앞에 슬래시를 붙인다.
  - **판단 기준:** 리졸버가 절대·상대 경로를 어떻게 해석하는지 본다.

- [ ] **상황:** 사용자 입력을 그대로 뷰 경로로 쓴다.
  - **판단 기준:** 허용된 이름과 경로 범위를 제한한다.
