# FC0266 · 저장 결과의 불필요한 재조회

## 검토 질문

- [ ] 저장 API가 필요한 값을 반환한다면 같은 객체를 즉시 다시 조회할 필요가 있는가?

**직접 작성한 예시**

```java
Payment saved = payments.save(payment);
return new PaymentReply(saved.id(), saved.amount());
```

**적용 설명:** save가 필요한 생성 ID·DB 기본값을 반영한 객체를 반환한다는 계약일 때 재조회를 줄인다.

## 구체적인 검토 사례

- [ ] **상황:** 저장 직후 같은 ID로 다시 조회한다.
  - **판단 기준:** 반환 객체가 필요한 값을 보장하면 생략할 수 있다.

- [ ] **상황:** DB 기본값을 반영하지 않은 객체를 반환한다.
  - **판단 기준:** 실제 저장 API 계약을 확인한다.
