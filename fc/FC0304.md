# FC0304 · SQL 상수 추출의 필요성

## 검토 질문

- [ ] SQL을 별도 상수로 옮길 때 재사용·길이·의미 측면의 이점이 사용처와 멀어지는 비용보다 큰가?

**직접 작성한 예시**

```java
String sql = "SELECT id, name FROM tag WHERE id = ?";
return runner.queryOne(sql, bind(id), mapper);
```

**적용 설명:** 한 번 쓰는 짧은 SQL을 가까이 두는 대안이다. 재사용·길이·의미에 따라 상수 추출을 결정한다.

## 구체적인 검토 사례

- [ ] **상황:** 한 번 쓰는 짧은 SQL을 먼 상수로 옮긴다.
  - **판단 기준:** 탐색 비용 대비 이점이 있는지 본다.

- [ ] **상황:** 같은 SQL이 여러 곳에서 달라진다.
  - **판단 기준:** 공유 의미가 분명하면 단일 정의를 둔다.
