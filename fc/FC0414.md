# FC0414 · 데이터 접근 계약의 직접 검증

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0413](FC0413.md) · [다음 FC: FC0412 →](FC0412.md)

## 검토 질문

- [ ] 서비스 테스트 통과만으로 충분하다고 보지 않고 매핑·부재·제약 같은 저장소 동작을 직접 확인하는가?

**직접 작성한 예시**

```java
User saved = dao.insert(new User("reader"));
assertEquals("reader", dao.find(saved.id()).orElseThrow().name());
assertTrue(dao.find(missingId).isEmpty());
```

**적용 설명:** DAO의 매핑·부재 계약을 직접 검증한다. 실제 DB 통합 테스트와 서비스 대역 테스트의 역할을 구분한다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스 테스트 통과로 DAO도 충분하다고 본다.
  - **판단 기준:** 매핑·부재·제약을 직접 검증한다.

- [ ] **상황:** 메모리 대역만으로 SQL을 검증한다.
  - **판단 기준:** 실제 DB에 필요한 통합 테스트를 둔다.
