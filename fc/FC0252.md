# FC0252 · 정적 리소스 경로와 부재 처리

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0249](FC0249.md) · [다음 FC: FC0245 →](FC0245.md)

## 검토 질문

- [ ] 잘못된 리소스 요청을 적절히 거절하고 경로 탈출·파일 부재를 안전하게 처리하는가?

**직접 작성한 예시**

```java
Path target = root.resolve(relative).normalize();
if (!target.startsWith(root) || !Files.isRegularFile(target)) return notFound();
```

**적용 설명:** root는 절대 정규화 경로라는 전제다. 심볼릭 링크 탈출까지 막으려면 실경로 확인과 링크 정책이 추가로 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 파일 경로에 상위 디렉터리 이동이 들어온다.
  - **판단 기준:** 허용 루트와 실경로 정책을 검증한다.

- [ ] **상황:** 없는 파일이 내부 예외로 전파된다.
  - **판단 기준:** 부재와 접근 금지를 정의한 결과로 변환한다.
