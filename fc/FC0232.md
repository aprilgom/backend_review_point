# FC0232 · 수정 시 유일성 검증

## 검토 질문

- [ ] 수정 대상 자신의 기존 값은 허용하면서 다른 객체의 고유값과 충돌하는 변경을 거절하는가?

**직접 작성한 예시**

```java
if (lines.existsByNameExceptId(newName, lineId)) throw new DuplicateLineName();
```

**적용 설명:** 자기 자신의 기존 이름은 제외하고 다른 엔티티와 충돌하는지 확인한다. DB 유일성 제약도 유지한다.

## 구체적인 검토 사례

- [ ] **상황:** 이름 변경 시 자기 이름도 중복으로 본다.
  - **판단 기준:** 자신을 제외한 충돌을 검사한다.

- [ ] **상황:** 이름 확인 후 동시 변경이 발생한다.
  - **판단 기준:** 유일성 제약 위반도 같은 업무 결과로 처리한다.
