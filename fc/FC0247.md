# FC0247 · 단건 조회의 null 전파 방지

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0244](FC0244.md) · [다음 FC: FC0250 →](FC0250.md)

## 검토 질문

- [ ] 조회 부재가 예상치 못한 null 접근 오류로 바뀌지 않도록 저장소와 호출부 계약을 맞췄는가?

**직접 작성한 예시**

```java
assertTrue(users.find(missingId).isEmpty());
```

**적용 설명:** Optional을 쓰는 저장소의 부재 동작 검증이다. 호출자가 get을 무조건 호출하지 않도록 사용부도 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 호출자가 조회 결과를 즉시 역참조한다.
  - **판단 기준:** 부재 경로를 명시적으로 처리한다.

- [ ] **상황:** Optional을 반환하고 무조건 get한다.
  - **판단 기준:** 사용부에서도 부재 계약을 지켜야 한다.
