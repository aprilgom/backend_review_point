# FC0410 · 상태 전이 대상 데이터의 정확성

## 검토 질문

- [ ] 상태 전환 시 다른 객체의 정보를 잘못 사용하는 오류를 구분 가능한 입력 데이터로 검증하는가?

**직접 작성한 예시**

```java
Booking promoted = waiting.promote(waitingId);
assertEquals(waitingCustomerId, promoted.customerId());
assertEquals(waitingSlotId, promoted.slotId());
```

**적용 설명:** 승격 대상과 다른 객체의 필드가 섞이지 않는지 검증한다. 서로 다른 값의 두 후보를 준비하면 오류를 드러내기 좋다.

## 구체적인 검토 사례

- [ ] **상황:** 상태 전이에서 다른 객체의 필드를 사용한다.
  - **판단 기준:** 구분 가능한 두 데이터로 결과를 검증한다.

- [ ] **상황:** 모든 픽스처 값이 같아 오류를 숨긴다.
  - **판단 기준:** 식별·소유·상태 값을 의도적으로 다르게 준비한다.
