# FC0192 · 기존 코드 문제의 가시화

## 검토 질문

- [ ] 직접 작성하지 않은 코드의 문제도 재현 가능한 검증으로 드러내고 영향도에 맞게 수정할 수 있는가?

**직접 작성한 예시**

```java
@Test void emptyTitleIsRejected() {
    assertThrows(IllegalArgumentException.class, () -> new Task(""));
}
```

**적용 설명:** 기존 코드의 문제를 발견하면 재현 가능한 검증으로 드러낸다. 요청 범위와 영향도를 확인해 수정 범위를 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 기존 코드 문제를 발견했지만 범위 밖이라 무시한다.
  - **판단 기준:** 영향도와 재현 근거로 수정 범위를 판단한다.

- [ ] **상황:** 근거 없이 넓은 리팩터링을 시작한다.
  - **판단 기준:** 문제를 드러내는 작은 검증부터 마련한다.
