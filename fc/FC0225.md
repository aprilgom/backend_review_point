# FC0225 · 누락값과 기본값의 구분

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0236](FC0236.md)

## 검토 질문

- [ ] 필수 입력의 누락이 0 같은 기본값으로 바뀌어 유효한 값처럼 처리되지 않는가?

**직접 작성한 예시**

```java
Integer age = input.age();
if (age == null) throw new MissingAge();
if (age < 0) throw new InvalidAge();
```

**적용 설명:** 누락과 실제 0을 구분한다. 0세 허용 여부는 업무 규칙으로 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 누락된 숫자 입력이 자동으로 0이 된다.
  - **판단 기준:** 부재와 유효한 0을 구분해 검증한다.

- [ ] **상황:** nullable을 쓴 뒤 내부에서 무조건 해제한다.
  - **판단 기준:** 경계에서 필수 여부를 확정한다.
