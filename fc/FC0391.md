# FC0391 · 세션 발급과 갱신 시점

## 검토 질문

- [ ] 익명·인증 세션의 수명을 구분하고 로그인 시 식별자 갱신 등 안전한 발급 정책을 적용하는가?

**직접 작성한 예시**

```java
Actor actor = authenticator.authenticate(credentials);
Session session = sessions.rotateAfterLogin(previousSessionId, actor);
reply.addCookie(sessionCookie(session));
```

**적용 설명:** 로그인 성공 시 새 세션 식별자를 발급해 고정 공격을 방어하는 계약이다. 익명 세션이 필요한 서비스는 별도 생명주기를 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 모든 익명 요청에 세션을 발급한다.
  - **판단 기준:** 익명 상태가 필요한지 수명을 정의한다.

- [ ] **상황:** 로그인 뒤에도 기존 ID를 그대로 쓴다.
  - **판단 기준:** 세션 고정 방어와 갱신 정책을 검토한다.
