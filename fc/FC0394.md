# FC0394 · 공개 동작을 검증하는 테스트

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0393 →](FC0393.md)

## 검토 질문

- [ ] 단순 생성 성공보다 실제로 보장해야 하는 결과·부작용·실패를 검증하는 테스트가 있는가?

**직접 작성한 예시**

```java
@Test void totalIncludesEveryLine() {
    assertEquals(new Money(900), basketWithPrices(400, 500).total());
}
```

**적용 설명:** 테스트 추가 시 실제 동작을 관측한다. 의미 없는 생성 성공 테스트만 늘리지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 객체 생성 성공만 검증한다.
  - **판단 기준:** 공개 결과와 중요한 부작용을 테스트한다.

- [ ] **상황:** 테스트 수만 늘리고 같은 경로를 반복한다.
  - **판단 기준:** 서로 다른 실패를 잡는지 확인한다.
