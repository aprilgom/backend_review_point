# FC0394 · 테스트 코드 추가를 검토하는 것을 제안했다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0393 →](FC0393.md)

- [ ] 테스트 코드 추가를 검토하는 것을 제안했다. (개선 제안)
  - 조건: 리뷰어는 반영을 강제하지 않았다. 작성자는 테스트의 필요성에는 동의하지만 무엇을 테스트해야 할지 명확하지 않고 메서드 분리가 충분하지 않다고 설명하며, 이후 구현 과정에서 추가하겠다고 답했다.

- [ ] 테스트 코드를 추가할 것을 제안했다. (개선 제안)
  - 조건: 구체적인 테스트 대상이나 시나리오는 지정하지 않았으며, 리뷰 참여자도 자신은 테스트를 작성하지 못했다고 덧붙인 권유다.

- [ ] 테스트 코드를 나중에 추가할 것을 제안했다. (개선 제안)
  - 조건: 추가할 테스트의 대상이나 검증 항목은 구체적으로 제시하지 않았다. 승인 및 머지 안내는 테스트 추가 완료의 근거가 아니다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
@Test void totalIncludesEveryLine() {
    assertEquals(new Money(900), basketWithPrices(400, 500).total());
}
```

**적용 설명:** 테스트 추가 시 실제 동작을 관측한다. 의미 없는 생성 성공 테스트만 늘리지 않는다.
