# FC0080 · web과 core의 빌드 설정에 중복 선언된 의존성을 제거해 보자고 제안했다.

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0073](FC0073.md) · [다음 FC: FC0087 →](FC0087.md)

- [ ] web과 core의 빌드 설정에 중복 선언된 의존성을 제거해 보자고 제안했다. (개선 제안)
  - 조건: 작성자는 루트 build.gradle에 설정하는 방식으로 반영하겠다고 답했다. 이는 반영 계획이며 실제 변경 완료를 입증하지는 않는다.

- [ ] jaxb-api를 별도 의존성으로 선언할 필요가 있는지 확인하고, 불필요하다면 제거하도록 제안했다. (토론)
  - 조건: 참여자는 처음에는 라이브러리 용도와 사용 여부를 질문했다. 이후 직접 선언을 제거해도 테스트와 페이지가 정상 동작했다고 보고하고, rest-assured에 포함되어 별도 명시가 필요 없다는 설명과 함께 캐시를 비우고 다시 불러오기를 제안했다. 이는 참여자의 확인 보고이며 작성자의 변경 결과는 제시되지 않았다.

- [ ] SubwayAdminApplication과 중복된 @EnableJpaAuditing 선언을 하나로 정리하고 EnableJpaAuditingConfig를 삭제하는 방안을 제안한다. (개선 제안)
  - 조건: 리뷰 참여자는 두 위치의 선언이 중복이라고 지적했다. 작성자 답변이나 실제 정리 결과는 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```kotlin
// app/build.gradle.kts
dependencies { implementation(project(":core")) }
// 두 모듈이 직접 사용하는 의존성은 각 모듈에 선언할 수 있다.
```

**적용 설명:** 의존성 선언이 두 번 보인다고 무조건 삭제하지 않는다. 직접 사용 여부와 api/implementation 전파 범위를 먼저 확인한다.
