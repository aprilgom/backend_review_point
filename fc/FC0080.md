# FC0080 · 중복 의존성 선언의 판단

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0073](FC0073.md) · [다음 FC: FC0087 →](FC0087.md)

## 검토 질문

- [ ] 여러 모듈의 중복 선언이 실제로 불필요한지 직접 사용과 전파 범위를 확인했는가?

**직접 작성한 예시**

```kotlin
// app/build.gradle.kts
dependencies { implementation(project(":core")) }
// 두 모듈이 직접 사용하는 의존성은 각 모듈에 선언할 수 있다.
```

**적용 설명:** 의존성 선언이 두 번 보인다고 무조건 삭제하지 않는다. 직접 사용 여부와 api/implementation 전파 범위를 먼저 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 여러 모듈에 같은 의존성이 보인다.
  - **판단 기준:** 각 모듈의 직접 사용 여부를 확인한다.

- [ ] **상황:** 중복이라는 이유로 선언을 삭제한다.
  - **판단 기준:** 전파되지 않는 의존성이라면 각 선언이 필요할 수 있다.
