# FC0012 · 정적 팩토리 메서드의 존재 이유

## 검토 질문

- [ ] 정적 팩토리가 생성자 호출을 감싸는 것 외에 이름·검증·캐싱·반환 타입 측면의 의미를 제공하는가?

**직접 작성한 예시**

```java
Money a = new Money(500);
Money b = Money.of(500); // 생성자 전달만 한다면 의미 차이가 작다.
Money c = Money.won(500); // 단위 정보를 드러내는 이름
```

**적용 설명:** 팩토리는 캐싱·검증·단위 등 실제 의미를 제공하는지 판단한다. of를 무조건 제거하라는 뜻은 아니다.

## 구체적인 검토 사례

- [ ] **상황:** 정적 팩토리가 생성자만 그대로 호출한다.
  - **판단 기준:** 이름·검증·캐싱 등 추가 의미가 있는지 검토한다.

- [ ] **상황:** 생성 단위나 정책이 호출부에서 모호하다.
  - **판단 기준:** 팩토리 이름으로 의미를 드러낼 수 있다.
