## 검토 질문

- [ ] 테스트 준비를 도우미로 감싸는 이점이 호출을 따라가야 하는 탐색 비용보다 큰가?

**직접 작성한 예시**

```java
// 준비 의도가 짧다면 굳이 여러 fixture를 추적할 필요가 없다.
Account account = new Account("reader", ACTIVE);
assertTrue(account.canRead());
```

**적용 설명:** Fixture가 항상 더 낫다는 규칙은 아니다. 반복량과 준비 코드의 탐색 비용을 함께 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 간단한 준비를 여러 도우미로 감싼다.
  - **판단 기준:** 호출을 따라가는 비용이 중복 감소보다 큰지 본다.

- [ ] **상황:** 복잡한 준비를 테스트마다 복사한다.
  - **판단 기준:** 의도를 설명하는 픽스처가 반복과 실수를 줄일 수 있다.
