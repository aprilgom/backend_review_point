# FC0298 · 반환 계약이 드러나는 메서드 이름

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0325](FC0325.md) · [다음 FC: FC0321 →](FC0321.md)

## 검토 질문

- [ ] 이름만으로 참·거짓 검증인지 값 조회인지 인증 결과 반환인지 예상할 수 있는가?

**직접 작성한 예시**

```java
Optional<Actor> authenticate(Credentials credentials) {
    return authentication.check(credentials);
}
```

**적용 설명:** boolean 검증인지 사용자 반환인지 이름과 반환 타입이 함께 설명해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 검증처럼 보이는 메서드가 값을 반환한다.
  - **판단 기준:** 이름과 반환 의미를 일치시킨다.

- [ ] **상황:** 실패 시 예외인지 false인지 알 수 없다.
  - **판단 기준:** 계약을 이름·타입·문서로 명시한다.
