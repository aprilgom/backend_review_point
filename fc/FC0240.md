# FC0240 · 예상 오류와 예상 밖 예외의 구분

## 검토 질문

- [ ] 일부 예외만 처리한 뒤 나머지가 어떻게 전파되는지 알고 서버 결함과 입력 오류를 구분하는가?

**직접 작성한 예시**

```java
try { return endpoint.handle(request); }
catch (InvalidInput invalid) { return error(400, "INVALID_INPUT"); }
catch (Exception unexpected) { recordFailure(unexpected); return error(500, "INTERNAL_ERROR"); }
```

**적용 설명:** 예상 입력 오류와 예상 밖 서버 오류를 구분한다. 가장 바깥 요청 경계에서만 일반 예외를 처리하는 예다.

## 구체적인 검토 사례

- [ ] **상황:** 특정 입력 예외만 처리한다.
  - **판단 기준:** 그 밖의 예외가 어떤 응답이 되는지 확인한다.

- [ ] **상황:** 최상위에서 모든 실패를 삼킨다.
  - **판단 기준:** 실패를 기록하고 계약에 맞는 결과를 반환한다.
