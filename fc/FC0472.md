# FC0472 · 콘솔에서도 웹과 동일하게 우승자와 최종 이동거리를 출력하라는 요구가 이동거리를 숫자로 표시하라는 의미인지 논의한다.

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0477](FC0477.md) · [다음 FC: FC0467 →](FC0467.md)

- [ ] 콘솔에서도 웹과 동일하게 우승자와 최종 이동거리를 출력하라는 요구가 이동거리를 숫자로 표시하라는 의미인지 논의한다. (토론)
  - 조건: 리뷰 참여자는 요구사항의 해석이 다를 수 있음을 인정하며 작성자의 생각을 물었다. 작성자는 해당 해석에 동의하고 출력 방식을 수정했다고 답했지만, 이것만으로 요구사항의 유일한 해석이나 실제 변경 결과가 확정되지는 않는다.

- [ ] 요구사항에 제시된 가격의 '원' 단위 표시를 반영한다. (개선 제안)
  - 조건: 리뷰어가 본문에서 요구사항의 단위 표시를 직접 언급했다. 첨부 이미지만으로 추가적인 화면 차이를 추정하지 않는다.

- [ ] 방 입장 시 새 창을 열기보다 현재 창에서 페이지를 이동하는 편이 사용성에 좋겠다고 제안했다. (개선 제안)
  - 조건: 사용성에 관한 제안이며 새 창 방식의 기술적 결함을 확정한 것은 아니다. 작성자는 페이지를 이동하도록 변경했다고 보고했다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
System.out.printf("우승자: %s, 최종 거리: %d%n", winner.name(), winner.distance());
```

**적용 설명:** 콘솔의 출력 요구를 명시한 예다. 숫자·단위·동점 표시 여부를 요구사항과 맞춘다.
