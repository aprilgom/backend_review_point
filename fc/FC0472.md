# FC0472 · 채널별 출력 요구의 일치

## 검토 질문

- [ ] 웹·콘솔 등 다른 채널에서도 요구된 결과·수치·단위를 일관되게 전달하는가?

**직접 작성한 예시**

```java
System.out.printf("우승자: %s, 최종 거리: %d%n", winner.name(), winner.distance());
```

**적용 설명:** 콘솔의 출력 요구를 명시한 예다. 숫자·단위·동점 표시 여부를 요구사항과 맞춘다.

## 구체적인 검토 사례

- [ ] **상황:** 채널에 따라 결과 수치가 다르게 보인다.
  - **판단 기준:** 업무 결과와 표시 요구를 맞춘다.

- [ ] **상황:** 단위·동점·빈 결과가 정의되지 않았다.
  - **판단 기준:** 채널별 표현 계약을 명시한다.
