# FC0124 · 단순 존재 확인의 저장소 계약

[소속 분야: 쿼리·데이터 조작](../07-data-query.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0118](FC0118.md) · [다음 FC: FC0123 →](FC0123.md)

## 검토 질문

- [ ] 존재 여부만 필요한 조회를 간결한 계약으로 표현하고 인증 등 별도의 책임과 혼합하지 않는가?

**직접 작성한 예시**

```java
boolean exists = accounts.existsByEmail(normalizedEmail);
```

**적용 설명:** 존재 확인용 저장소 계약 예시다. 비밀번호를 평문 조건에 넣는 인증 방식은 예시로 사용하지 않으며 인증은 해시 검증으로 별도 처리한다.

## 구체적인 검토 사례

- [ ] **상황:** 존재 확인에 전체 객체를 조회한다.
  - **판단 기준:** 참·거짓만 필요한 계약으로 줄일 수 있다.

- [ ] **상황:** 인증을 단순 값 일치 조회로 처리한다.
  - **판단 기준:** 비밀번호 해시 검증 등 별도 보안 책임을 유지한다.
