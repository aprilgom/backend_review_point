# FC0164 · 계층 간 입력 계약의 소유

[소속 분야: 의존성·교체 가능성](../09-dependency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0154](FC0154.md) · [다음 FC: FC0166 →](FC0166.md)

## 검토 질문

- [ ] 서비스가 사용하는 입력 타입이 표현 계층에 종속되지 않도록 계약의 위치와 변환 경계를 정했는가?

**직접 작성한 예시**

```java
package application;
public record CreateTaskCommand(String title) {}
```

**적용 설명:** 서비스 입력 계약을 애플리케이션 계층에 둔다. HTTP 요청 DTO는 컨트롤러에서 이 타입으로 변환한다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스 입력 타입이 UI 패키지에 있다.
  - **판단 기준:** 계약 소유 계층과 변환 위치를 검토한다.

- [ ] **상황:** 서비스에 HTTP 전용 제약이 퍼진다.
  - **판단 기준:** 전송 형식과 업무 입력 의미를 구분한다.
