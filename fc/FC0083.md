## 검토 질문

- [ ] 개발용 데이터와 스키마 변경을 구분하고 실행 환경·순서·중복 적용 정책을 명시했는가?

**직접 작성한 예시**

```sql
-- 개발용 초기 데이터 파일의 내용 예
INSERT INTO category(id, name) VALUES (1, 'sample');
```

**적용 설명:** 개발 데이터와 스키마 변경을 분리한다. 이 파일을 실행할 초기화 절차를 명시하고 운영에서 자동 적용되지 않게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 개발 초기 데이터를 서비스 코드에서 삽입한다.
  - **판단 기준:** 실행 목적과 환경을 분리해 관리한다.

- [ ] **상황:** 초기화 파일이 반복 실행된다.
  - **판단 기준:** 중복·스키마 순서·운영 적용을 통제한다.
