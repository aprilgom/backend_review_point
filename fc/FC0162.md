# FC0162 · 서비스 사이의 계층과 조율

[소속 분야: 의존성·교체 가능성](../09-dependency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0166](FC0166.md) · [다음 FC: FC0147 →](FC0147.md)

## 검토 질문

- [ ] 서비스 간 호출에 상하 관계와 조율 책임이 있으며 순환·실패·트랜잭션 경계가 명확한가?

**직접 작성한 예시**

```java
// 상위 유스케이스가 두 기능을 조율한다.
Receipt receipt = checkout.complete(basket);
notifications.sendReceipt(receipt);
```

**적용 설명:** 상하 관계와 실패·트랜잭션 경계를 정한다. 모든 서비스가 서로 호출하는 그래프는 피한다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스끼리 자유롭게 서로 호출한다.
  - **판단 기준:** 상위 유스케이스와 하위 기능을 구분한다.

- [ ] **상황:** 외부 호출 실패가 저장까지 되돌린다.
  - **판단 기준:** 실패·트랜잭션 경계를 의도대로 설계한다.
