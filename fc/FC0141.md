## 검토 질문

- [ ] 접근 패턴에 맞게 로딩 전략을 선택하고 추가 쿼리·컨텍스트 수명·제공자 동작을 검증했는가?

**직접 작성한 예시**

```java
@ManyToOne(fetch = FetchType.LAZY)
private Team team;
```

**적용 설명:** 지연 로딩의 필요성과 실제 제공자 동작을 확인한다. 접근 시 추가 쿼리와 영속성 컨텍스트 밖 접근 문제도 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** 모든 연관관계를 즉시 로딩한다.
  - **판단 기준:** 실제 접근 패턴과 추가 데이터량을 측정한다.

- [ ] **상황:** 지연 로딩을 컨텍스트 밖에서 실행한다.
  - **판단 기준:** 필요한 조회 시점과 경계를 명시한다.
