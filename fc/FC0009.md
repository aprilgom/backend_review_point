## 검토 질문

- [ ] 반복되는 객체 생성과 저장 준비를 공통화하면서 시나리오별 중요한 차이는 호출부에 남겼는가?

**직접 작성한 예시**

```java
private User savedUser(String name) {
    return users.save(new User(name));
}
User owner = savedUser("owner");
```

**적용 설명:** 여러 테스트의 동일한 저장 준비를 묶은 예시다. 테스트마다 저장소를 격리한다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 기본 객체를 여러 테스트에서 저장한다.
  - **판단 기준:** 재사용 도우미도 매번 독립된 객체를 만든다.

- [ ] **상황:** 시나리오 차이까지 공통 준비에 숨긴다.
  - **판단 기준:** 결과에 영향을 주는 값은 테스트에서 명시한다.
