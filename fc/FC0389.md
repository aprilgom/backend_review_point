# FC0389 · 비밀번호와 개인정보의 저장 보호

[소속 분야: 인증·보안·비밀값](../20-security.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0388](FC0388.md) · [다음 FC: FC0391 →](FC0391.md)

## 검토 질문

- [ ] 비밀번호 전용 해시와 개인정보 보호 요구를 구분하고 평문·부적절한 암호화로 저장하지 않는가?

**직접 작성한 예시**

```java
String encoded = passwordHasher.hash(rawPassword);
accounts.create(loginName, encoded);
boolean matches = passwordHasher.verify(attempt, encoded);
```

**적용 설명:** passwordHasher는 검증된 비밀번호 전용 해시 구현을 뜻한다. 비밀번호에 가역 암호화나 단순 빠른 해시를 직접 구현하지 않는다. 개인정보 보관은 별도 정책이다.

## 구체적인 검토 사례

- [ ] **상황:** 비밀번호를 평문이나 가역 방식으로 저장한다.
  - **판단 기준:** 검증된 비밀번호 전용 해시를 사용한다.

- [ ] **상황:** 개인정보와 비밀번호에 같은 보관 정책을 쓴다.
  - **판단 기준:** 복원 필요·접근·보존 요구를 구분한다.
