# FC0387 · 응답 정보의 최소 공개

[소속 분야: 인증·보안·비밀값](../20-security.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0388 →](FC0388.md)

## 검토 질문

- [ ] 응답에 필요한 공개 필드만 포함하고 토큰·자격증명·내부 정보가 직렬화되지 않는가?

**직접 작성한 예시**

```java
record PublicUser(long id, String displayName) {}
return new PublicUser(user.id(), user.displayName());
```

**적용 설명:** 해시·토큰·내부 설정을 응답 타입에 포함하지 않는다. 전체 엔티티 자동 직렬화보다 공개 필드를 명시한다.

## 구체적인 검토 사례

- [ ] **상황:** 응답에 내부 비밀 필드가 직렬화된다.
  - **판단 기준:** 공개할 필드만 명시적으로 선택한다.

- [ ] **상황:** 필드를 숨겼지만 오류 메시지로 새어 나온다.
  - **판단 기준:** 정상·실패 응답을 함께 검토한다.
