# FC0397 · 테스트가 거의 없는 것으로 보이는데 구현하지 않은 이유가 있는지 질문했다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0401](FC0401.md) · [다음 FC: FC0404 →](FC0404.md)

- [ ] 테스트가 거의 없는 것으로 보이는데 구현하지 않은 이유가 있는지 질문했다. (설계 질문)
  - 조건: 작성자는 이번 단계에서 테스트의 학습 우선순위를 낮게 두었다고 설명하고, 필수 기능 요구사항을 검증하는 컨트롤러 통합 테스트를 추가했다고 보고했다. 추가된 테스트의 내용과 충분성은 이 대화에서 확인되지 않는다.

- [ ] 새로 추가한 기능들의 테스트가 작성되지 않은 이유를 질문했다. (설계 질문)
  - 조건: 작성자는 다른 리뷰의 1번 사항과 관련해 세 가지 방법의 한계를 고민하느라 테스트를 아직 작성하지 못했다고 설명하고, 머지 후에도 고민하고 구현하겠다는 의사를 밝혔다. 참조된 다른 리뷰의 구체적인 내용과 이후 테스트 작성 여부는 이 단위에서 확인되지 않는다.

- [ ] 잘못된 예외가 던져지는 실수를 테스트 코드에서 검증할 수 없는지 질문했다. (설계 질문)
  - 조건: 작성자는 모든 서비스 예외 테스트에서 예외 클래스·ErrorCode·메시지를 함께 검증하도록 추가했다고 보고했다. 이 세 항목의 검증은 작성자가 설명한 대응이며, 리뷰 참여자가 각각을 명시적으로 요구한 것은 아니다. 실제 테스트 내용이나 실행 결과는 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
@Test void emptyBasketHasZeroTotal() {
    assertEquals(Money.ZERO, new Basket().total());
}
```

**적용 설명:** 현재 가장 작은 동작부터 실행 가능한 검증을 마련한다.
