# FC0397 · 최소 동작 검증의 확보

## 검토 질문

- [ ] 구현한 핵심 동작에 재현 가능한 최소 테스트가 있어 변경 시 빠르게 피드백을 받을 수 있는가?

**직접 작성한 예시**

```java
@Test void emptyBasketHasZeroTotal() {
    assertEquals(Money.ZERO, new Basket().total());
}
```

**적용 설명:** 현재 가장 작은 동작부터 실행 가능한 검증을 마련한다.

## 구체적인 검토 사례

- [ ] **상황:** 핵심 로직에 자동 검증이 없다.
  - **판단 기준:** 작은 공개 동작부터 재현한다.

- [ ] **상황:** 환경 준비가 어려워 모든 테스트를 미룬다.
  - **판단 기준:** 순수 로직부터 독립적으로 검증할 수 있다.
