# FC0326 · 테스트 구간의 시각적 구분

## 검토 질문

- [ ] 준비·실행·검증을 읽기 쉽게 구분하며 불필요한 빈 줄로 흐름을 끊지 않는가?

**직접 작성한 예시**

```java
Task task = sampleTask();

task.complete();

assertTrue(task.isComplete());
```

**적용 설명:** 준비·실행·검증 구간을 한 줄 간격으로 나눈 예다. 팀 규칙에 맞게 적용한다.

## 구체적인 검토 사례

- [ ] **상황:** 테스트의 준비·실행·단언이 붙어 있다.
  - **판단 기준:** 의미 있는 간격으로 흐름을 구분한다.

- [ ] **상황:** 빈 줄이 많아 관련 코드가 멀어진다.
  - **판단 기준:** 짧고 일관된 구획을 유지한다.
