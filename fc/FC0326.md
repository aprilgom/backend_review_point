# FC0326 · 테스트 코드에서 연속된 빈 줄 대신 빈 줄을 하나씩만 사용하도록 요청했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0304](FC0304.md) · [다음 FC: FC0324 →](FC0324.md)

- [ ] 테스트 코드에서 연속된 빈 줄 대신 빈 줄을 하나씩만 사용하도록 요청했다. (개선 제안)
  - 조건: 작성자는 반영했다고 답했으며, 실제 변경 여부를 별도로 확인한 근거는 없다.

- [ ] OrderServiceTest 클래스 선언 직후 빈 줄이 두 줄 들어가 있음을 지적한다. (관찰)
  - 조건: 코드 서식에 대한 지적이다. 작성자의 감사 답변만으로 공백 정리가 이루어졌다고 판단하지 않는다.

- [ ] DispatcherServletTest의 테스트 메서드 위에 있는 불필요한 빈 줄을 정리해 달라고 제안했다. (개선 제안)
  - 조건: 예외 중심 테스트에 대한 칭찬과 별개로 여백 정리라는 구체적인 개선 요청이 포함되어 있다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
Task task = sampleTask();

task.complete();

assertTrue(task.isComplete());
```

**적용 설명:** 준비·실행·검증 구간을 한 줄 간격으로 나눈 예다. 팀 규칙에 맞게 적용한다.
