# FC0200 · 작은 구현과 피드백의 반복

## 검토 질문

- [ ] 하나의 정답을 미리 찾기보다 검증 가능한 작은 구현으로 가정을 확인하며 개선하는가?

**직접 작성한 예시**

```java
PricePolicy first = new FlatPricePolicy();
assertEquals(new Money(100), first.price(sample));
```

**적용 설명:** 작은 작동 구현을 검증하며 다음 요구로 확장한다. 추상적 정답을 찾느라 검증 가능한 피드백을 미루지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 구조의 정답을 찾느라 구현을 시작하지 못한다.
  - **판단 기준:** 작은 동작을 만들고 피드백으로 개선한다.

- [ ] **상황:** 처음 성공한 구현을 그대로 고정한다.
  - **판단 기준:** 새 요구와 측정 결과에 따라 다시 판단한다.
