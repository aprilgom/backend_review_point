# FC0480 · 완료 후 조회·변경 흐름

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0468](FC0468.md) · [다음 FC: FC0476 →](FC0476.md)

## 검토 질문

- [ ] 작업 완료 알림 뒤에도 사용자가 결과를 다시 확인하거나 필요한 후속 작업을 수행할 수 있는가?

**직접 작성한 예시**

```html
<p role="status">예약이 완료되었습니다.</p>
<a href="/my-bookings">내 예약 확인 및 취소</a>
```

**적용 설명:** 완료 메시지 뒤 후속 작업 경로를 제공한다. 서버 조회·취소 권한 확인은 별도로 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 작업 완료 알림 뒤 후속 경로가 없다.
  - **판단 기준:** 결과 조회와 필요한 변경으로 이동하게 한다.

- [ ] **상황:** 편의 링크만으로 권한을 처리한다.
  - **판단 기준:** 서버에서도 해당 작업의 권한을 확인한다.
