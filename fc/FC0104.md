# FC0104 · 동시성 컬렉션의 보장 범위

## 검토 질문

- [ ] 스레드 안전한 컬렉션을 써도 내부 객체 변경과 여러 연산의 조합까지 안전한지 확인했는가?

**직접 작성한 예시**

```java
ConcurrentMap<String, Session> sessions = new ConcurrentHashMap<>();
Session current = sessions.computeIfAbsent(key, ignored -> new Session());
```

**적용 설명:** 지도 자체의 생성 경쟁을 제어한다. Session 내부의 변경 가능한 필드까지 자동으로 스레드 안전해지는 것은 아니다.

## 구체적인 검토 사례

- [ ] **상황:** 동시성 Map 안에 가변 객체를 저장한다.
  - **판단 기준:** Map의 보호와 객체 내부 보호를 구분한다.

- [ ] **상황:** 여러 키를 함께 갱신한다.
  - **판단 기준:** 단일 키 연산의 원자성만으로 충분한지 확인한다.
