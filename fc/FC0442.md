# FC0442 · 대역 반환 객체의 준비 순서

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0437](FC0437.md)

## 검토 질문

- [ ] 대역에 객체를 넘기기 전에 의도한 상태를 만들고 이후 변경으로 기대값이 흔들리지 않게 하는가?

**직접 작성한 예시**

```java
table.setEmpty(true);
given(tables.find(id)).willReturn(Optional.of(table));
```

**적용 설명:** 대역 반환을 설정하기 전에 의도한 상태를 준비한다. 이후 가변 객체 변경이 테스트를 혼란스럽게 하지 않도록 한다.

## 구체적인 검토 사례

- [ ] **상황:** 대역 반환을 설정한 뒤 객체 상태를 바꾼다.
  - **판단 기준:** 기대 상태를 먼저 구성해 의도를 드러낸다.

- [ ] **상황:** 같은 가변 객체를 여러 시나리오가 공유한다.
  - **판단 기준:** 변경 전파로 기대가 흔들리지 않게 격리한다.
