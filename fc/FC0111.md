# FC0111 · 동시 식별자 생성의 보장 범위

[소속 분야: 비동기·동시성](../05-concurrency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0110](FC0110.md) · [다음 FC: FC0105 →](FC0105.md)

## 검토 질문

- [ ] 원자적 증가 값이 보장하는 프로세스 범위와 재시작·다중 인스턴스·오버플로의 한계를 구분하는가?

**직접 작성한 예시**

```java
AtomicLong nextId = new AtomicLong();
long id = nextId.incrementAndGet();
```

**적용 설명:** 단일 프로세스 안에서 경쟁을 제어하는 예다. 재시작·다중 인스턴스·오버플로까지 해결하는 전역 ID 생성기는 아니다.

## 구체적인 검토 사례

- [ ] **상황:** 프로세스 내부 원자 증가로 ID를 만든다.
  - **판단 기준:** 보장 범위를 단일 실행으로 한정한다.

- [ ] **상황:** 여러 인스턴스가 같은 초기값에서 시작한다.
  - **판단 기준:** 분산 고유성과 재시작 후 중복을 별도 해결한다.
