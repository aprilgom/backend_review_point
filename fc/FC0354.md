# FC0354 · 방 목록 렌더링에서 각 자식에 고유한 key prop이 필요하다는 경고를 확인하고 수정해 달라는 요청이다.

- [ ] 방 목록 렌더링에서 각 자식에 고유한 key prop이 필요하다는 경고를 확인하고 수정해 달라는 요청이다. (문제 보고)
  - 조건: 리뷰 참여자는 고유한 key prop 관련 경고를 직접 인용했다. 작성자는 해결했다고 답했지만, 어떤 key를 부여했는지와 경고 해소 여부는 후속 코드로 확인되지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```jsx
{rooms.map(room => <RoomRow key={room.id} room={room} />)}
```

**적용 설명:** 백엔드 목록에 포함된 화면 사례다. 삭제·정렬에도 안정적인 식별자를 key로 사용한다.
