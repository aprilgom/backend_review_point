# FC0354 · 목록 렌더링의 안정적인 키

## 검토 질문

- [ ] 목록 원소의 키가 삭제·정렬·갱신에도 같은 대상을 식별하며 중복되지 않는가?

**직접 작성한 예시**

```jsx
{rooms.map(room => <RoomRow key={room.id} room={room} />)}
```

**적용 설명:** 백엔드 목록에 포함된 화면 사례다. 삭제·정렬에도 안정적인 식별자를 key로 사용한다.

## 구체적인 검토 사례

- [ ] **상황:** 목록 원소의 key가 중복된다.
  - **판단 기준:** 같은 대상을 안정적으로 식별하게 한다.

- [ ] **상황:** 정렬되는 목록에 배열 인덱스를 key로 쓴다.
  - **판단 기준:** 항목 이동 시 상태가 다른 대상에 붙지 않는지 본다.
