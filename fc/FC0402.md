## 검토 질문

- [ ] JSON 전체 문자열 형식보다 검증 대상 필드와 값의 의미를 확인하는가?

**직접 작성한 예시**

```java
JsonNode body = mapper.readTree(response.body());
assertEquals("ready", body.path("state").asText());
```

**적용 설명:** JSON 공백·키 순서 대신 의미 있는 필드를 검증한다. 필드 부재와 기본값이 섞이지 않게 존재 검사도 고려한다.

## 구체적인 검토 사례

- [ ] **상황:** JSON 전체 문자열을 비교한다.
  - **판단 기준:** 공백·키 순서와 의미를 구분한다.

- [ ] **상황:** 없는 필드를 기본값으로 읽어 통과한다.
  - **판단 기준:** 필요하면 존재와 타입도 단언한다.
