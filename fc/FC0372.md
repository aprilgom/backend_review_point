## 검토 질문

- [ ] 핸들러 호출 결과를 얻는 단계와 사용자 응답으로 출력하는 단계를 분리했는가?

**직접 작성한 예시**

```java
ViewResult result = adapter.invoke(handler, request);
renderer.render(result, response);
```

**적용 설명:** 핸들러 실행과 뷰 출력은 다른 단계다. JSON 등 다른 결과를 지원할 때 경계가 유지되는지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 핸들러 호출과 화면 출력이 한곳에 있다.
  - **판단 기준:** 결과를 전달하고 렌더링을 분리할 수 있다.

- [ ] **상황:** 새 결과 형식을 추가하기 어렵다.
  - **판단 기준:** 출력 책임의 확장 지점을 확인한다.
