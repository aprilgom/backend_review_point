# FC0301 · 객체 조립 절차의 단계 분리

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0303](FC0303.md) · [다음 FC: FC0313 →](FC0313.md)

## 검토 질문

- [ ] 생성자 선택·의존성 해석·인스턴스 생성을 구분해 읽기 쉽고 실패 원인을 찾기 쉬운가?

**직접 작성한 예시**

```java
Constructor<?> constructor = selectConstructor(type);
Object[] arguments = resolveArguments(constructor);
return constructor.newInstance(arguments);
```

**적용 설명:** 자체 객체 조립기의 선택·인자 해석·생성 단계를 분리한다. 예외 처리와 순환 의존 검사는 별도 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 생성자 선택부터 인스턴스 생성까지 한 메서드다.
  - **판단 기준:** 의미 있는 단계로 분리한다.

- [ ] **상황:** 분리 후 예외 원인을 잃는다.
  - **판단 기준:** 선택·해석·생성 중 실패 단계를 보존한다.
