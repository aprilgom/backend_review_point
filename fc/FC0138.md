# FC0138 · 연관 컬럼의 기본 명명 규칙

## 검토 질문

- [ ] 연관 컬럼 이름을 생략했을 때 생성되는 매핑을 알고 실제 스키마와 일치시키는가?

**직접 작성한 예시**

```java
@ManyToOne
@JoinColumn(name = "owner_id")
private Owner owner;
```

**적용 설명:** 외래 키 이름을 명시한 예다. 생략 시 생성되는 이름을 실제 매핑 메타데이터·DDL로 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 연관 컬럼 이름을 생략한다.
  - **판단 기준:** 기본 이름과 기존 스키마를 대조한다.

- [ ] **상황:** 리팩터링으로 필드 이름이 바뀐다.
  - **판단 기준:** 암묵적 매핑 변경이 생기는지 점검한다.
