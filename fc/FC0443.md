# FC0443 · 실행 중인 앱과 테스트의 격리

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0447](FC0447.md) · [다음 FC: FC0448 →](FC0448.md)

## 검토 질문

- [ ] 개발 서버가 떠 있어도 포트·DB·캐시 충돌 없이 테스트를 실행할 수 있는가?

**직접 작성한 예시**

```java
TestServer server = TestServer.startOnAvailablePort();
try { assertEquals(200, server.client().get("/health").status()); }
finally { server.close(); }
```

**적용 설명:** 개발 서버와 다른 포트를 확보하는 가상 도우미다. DB·캐시도 함께 격리해야 두 서버가 서로 영향을 주지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 실행 중인 앱과 테스트가 같은 포트를 쓴다.
  - **판단 기준:** 테스트 서버 주소를 독립적으로 확보한다.

- [ ] **상황:** 포트만 나누고 DB·캐시는 공유한다.
  - **판단 기준:** 외부 상태도 격리해야 한다.
