# FC0100 · 세션 내부 상태의 동시 접근

## 검토 질문

- [ ] 같은 사용자의 동시 요청이 세션 내부 값에 접근할 때 복합 갱신까지 안전한가?

**직접 작성한 예시**

```java
sessionAttributes.compute("visits", (key, old) ->
    old == null ? 1 : ((Integer) old) + 1);
```

**적용 설명:** sessionAttributes가 ConcurrentHashMap이라는 전제다. 같은 세션에 여러 요청이 오므로 복합 갱신도 원자적으로 수행한다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 세션에 요청 두 개가 동시에 온다.
  - **판단 기준:** 세션 내부 복합 변경도 보호한다.

- [ ] **상황:** 조회 후 증가를 별개 호출로 처리한다.
  - **판단 기준:** 원자적 갱신 API나 적절한 잠금을 사용한다.
