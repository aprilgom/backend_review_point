# FC0197 · 학습 테스트의 공유

[소속 분야: 문서·개발·학습 과정](../10-workflow.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0196](FC0196.md) · [다음 FC: FC0201 →](FC0201.md)

## 검토 질문

- [ ] 새롭게 확인한 언어·라이브러리 동작을 재현 가능한 학습 테스트로 남겼는가?

**직접 작성한 예시**

```java
@Test void listCopyDoesNotFollowLaterMutations() {
    List<Integer> source = new ArrayList<>(List.of(1));
    List<Integer> copy = List.copyOf(source);
    source.add(2);
    assertEquals(List.of(1), copy);
}
```

**적용 설명:** 프로덕션 테스트와 구별되는 학습 테스트를 함께 전달하는 예시다.

## 구체적인 검토 사례

- [ ] 가능하다면 다음 리뷰 요청에는 진행한 학습 테스트도 포함해 달라고 제안했다. (개선 제안)
  - 조건: 필수 요구가 아닌 선택적 제안이며, 이후 댓글에서는 학습 테스트의 포함 여부를 확인할 수 없다.

- [ ] 다음 리뷰 요청에는 학습 테스트도 함께 제출해 달라고 요청했다. (개선 제안)
  - 조건: 작성자는 학습 테스트를 추가했다고 보고하면서 트랜잭션 관련 내용은 다음 단계에서 진행하겠다고 덧붙였다. 리뷰 참여자는 이후 학습 테스트와 리팩터링을 긍정적으로 평가하고 머지를 안내했다. 이 대화에는 학습 테스트의 구체적인 검증 내용은 제시되지 않았다.

- [ ] 다음 리뷰 요청에는 학습 테스트도 함께 제출해 달라고 요청했다. (학습 제약)
  - 조건: 다음 리뷰 요청 시점에 대한 제출 요청이다. 학습 테스트의 구체적인 검증 대상이나 실제 추가 여부는 이 대화에서 확인되지 않는다.
