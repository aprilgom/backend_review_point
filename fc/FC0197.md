## 검토 질문

- [ ] 새롭게 확인한 언어·라이브러리 동작을 재현 가능한 학습 테스트로 남겼는가?

**직접 작성한 예시**

```java
@Test void listCopyDoesNotFollowLaterMutations() {
    List<Integer> source = new ArrayList<>(List.of(1));
    List<Integer> copy = List.copyOf(source);
    source.add(2);
    assertEquals(List.of(1), copy);
}
```

**적용 설명:** 프로덕션 테스트와 구별되는 학습 테스트를 함께 전달하는 예시다.

## 구체적인 검토 사례

- [ ] **상황:** 새 동작을 수동으로 한 번 확인한다.
  - **판단 기준:** 반복 실행 가능한 학습 테스트로 남긴다.

- [ ] **상황:** 실험 코드가 제품 계약처럼 취급된다.
  - **판단 기준:** 학습 가정과 운영 검증을 구분한다.
