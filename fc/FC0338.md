# FC0338 · 명시적 import와 팀 규칙

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0333](FC0333.md) · [다음 FC: FC0342 →](FC0342.md)

## 검토 질문

- [ ] 선택한 스타일 규칙에 맞게 필요한 타입을 명시하고 학습 제약을 보편적 규칙과 구분하는가?

**직접 작성한 예시**

```java
import java.util.ArrayList;
import java.util.List;
```

**적용 설명:** 명시적 import를 요구하는 스타일 규칙의 예다. 학습 제약을 모든 프로젝트의 필수 규칙으로 확대하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 와일드카드 import를 사용하는 규칙이 불명확하다.
  - **판단 기준:** 프로젝트의 선택된 스타일을 따른다.

- [ ] **상황:** 학습용 규칙을 기술적 정답으로 주장한다.
  - **판단 기준:** 정책 준수와 기능상 필요를 구분한다.
