# FC0408 · 테스트 대상 API의 실제 등록

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0398](FC0398.md) · [다음 FC: FC0403 →](FC0403.md)

## 검토 질문

- [ ] 테스트가 호출하는 API가 실제로 존재하고 경로·메서드·서버 구성과 일치하는가?

**직접 작성한 예시**

```java
assertTrue(routes.contains("/health", Method.GET));
assertEquals(200, client.get("/health").status());
```

**적용 설명:** 테스트가 호출하는 경로가 실제로 등록되었는지 확인한다. 첫 단언은 등록 단위 테스트, 두 번째는 서버 테스트 형태다.

## 구체적인 검토 사례

- [ ] HttpMethodTest가 호출하는 API가 없어 테스트가 실패한다고 보고하고 확인을 요청했다. (문제 보고)
  - 조건: 작성자는 미션 전에 만든 연습용 POST 로직의 프로덕션 코드만 삭제하고 테스트를 남겼다고 설명했으며, 해당 테스트도 삭제했다고 보고했다. 실제 삭제 여부나 이후 테스트 통과 여부는 이 대화만으로 확인되지 않는다.

- [ ] Http11ProcessorTest 실행 시 일부 테스트가 실패한다고 보고하고 확인을 요청했다. (문제 보고)
  - 조건: kang-hyungu의 실행 결과 보고이며, 실패한 테스트명이나 원인은 제시되지 않았다. 이후 승인 발언만으로 해당 실패가 해결되었다고 판단할 수 없다.

- [ ] Http11ProcessorTest의 해당 테스트가 실패한다고 보고하며 확인을 요청했다. (문제 보고)
  - 조건: 참여자의 실패 보고이며, 구체적인 실패 메시지나 원인 및 수정 결과는 제공되지 않았다.
