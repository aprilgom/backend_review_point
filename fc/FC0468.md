# FC0468 · 다음 행동을 안내하는 오류

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0480 →](FC0480.md)

## 검토 질문

- [ ] 실패 원인뿐 아니라 안전한 다음 행동을 안내하고 결과가 불확실한 작업에 무조건 재시도를 권하지 않는가?

**직접 작성한 예시**

```json
{"code":"TEMPORARY_FAILURE","message":"처리하지 못했습니다. 잠시 후 다시 시도해 주세요."}
```

**적용 설명:** 사용자가 취할 수 있는 행동을 안내한다. 결제처럼 결과가 불확실한 작업은 무조건 재시도 대신 상태 조회를 안내한다.

## 구체적인 검토 사례

- [ ] **상황:** 오류가 났다는 문구만 보여 준다.
  - **판단 기준:** 사용자가 취할 안전한 다음 행동을 안내한다.

- [ ] **상황:** 결과가 불확실한 작업에 재시도만 권한다.
  - **판단 기준:** 상태 조회·중복 방지 필요를 먼저 판단한다.
