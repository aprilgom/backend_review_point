# FC0468 · 다음 행동을 안내하는 오류

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0480 →](FC0480.md)

## 검토 질문

- [ ] 실패 원인뿐 아니라 안전한 다음 행동을 안내하고 결과가 불확실한 작업에 무조건 재시도를 권하지 않는가?

**직접 작성한 예시**

```json
{"code":"TEMPORARY_FAILURE","message":"처리하지 못했습니다. 잠시 후 다시 시도해 주세요."}
```

**적용 설명:** 사용자가 취할 수 있는 행동을 안내한다. 결제처럼 결과가 불확실한 작업은 무조건 재시도 대신 상태 조회를 안내한다.

## 구체적인 검토 사례

- [ ] 오류 메시지가 실패 이유뿐 아니라 사용자가 다음에 어떻게 행동해야 하는지도 안내하는지 검토하도록 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 기존 메시지의 실패 이유는 명확하다고 평가하면서도 다음 행동을 알기 어렵다고 지적했다. 작성자는 현재 상태와 사용자의 다음 행동을 함께 명시하도록 수정했다고 보고했으나, 수정된 문구 자체는 이 대화에 제시되지 않았다.

- [ ] 결제 실패 사용자에게 토스 서버로 직접 문의하라는 메시지를 전달하는 것이 적절한지 검토하자. (설계 질문)
  - 조건: 작성자는 외부 결제사 문의가 운영자의 몫이라고 보고, 잠시 후 재시도하거나 다른 결제 수단을 이용하도록 안내하는 문구로 수정했다고 보고했다. 리뷰어는 해당 문구를 긍정적으로 평가하면서 실제 문의가 필요한 상황도 있지만 대부분 사용자가 해결할 수 없는 상황이라고 설명했다.

- [ ] 중복 가입 오류 메시지에서 사용자에게 username이라는 내부 용어를 알릴 필요가 있는지 묻는다. (설계 질문)
  - 조건: 작성자는 사용자 입장에서 메시지를 작성하지 못했다고 인정하고 수정했다고 보고했다. 변경된 메시지의 구체적인 내용은 제공되지 않았다.
