# FC0299 · 타입 표기 규칙의 일관성

## 검토 질문

- [ ] 명시적 타입과 타입 추론의 사용 기준이 정해져 있고 기존 코드에도 일관되게 적용되는가?

**직접 작성한 예시**

```java
List<Station> stations = stationStore.findAll();
List<Line> lines = lineStore.findAll();
```

**적용 설명:** 명시적 타입을 택한 프로젝트의 일관된 예다. var 사용 여부 자체를 보편적 정답으로 취급하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 맥락에 타입 추론과 명시형을 혼용한다.
  - **판단 기준:** 팀의 기준을 일관되게 적용한다.

- [ ] **상황:** 모든 타입을 명시하거나 생략하도록 강제한다.
  - **판단 기준:** 호출부의 정보량과 가독성을 비교한다.
