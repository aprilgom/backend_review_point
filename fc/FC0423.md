# FC0423 · 공개 생성 경로를 사용하는 테스트

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0421](FC0421.md) · [다음 FC: FC0426 →](FC0426.md)

## 검토 질문

- [ ] 테스트 전용 생성자를 추가하기보다 실제 생성 API로 유효한 객체를 준비할 수 있는가?

**직접 작성한 예시**

```java
User user = User.register("reader");
```

**적용 설명:** 제품에서 쓰는 생성 경로로 테스트 객체를 만든다. 테스트 편의를 위해 불변식을 우회하는 생성자를 추가하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 테스트용 우회 생성자를 제품에 추가한다.
  - **판단 기준:** 공개 생성 API와 픽스처를 활용한다.

- [ ] **상황:** 객체 생성에 너무 많은 준비가 필요하다.
  - **판단 기준:** 실제 책임·의존 복잡성도 점검한다.
