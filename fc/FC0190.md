# FC0190 · 코드 생성 도구의 도입 근거

## 검토 질문

- [ ] 반복 코드 감소를 위해 도구를 도입할 때 생성 결과·빌드 영향·언어 기능 대안을 이해했는가?

**직접 작성한 예시**

```java
public record LabelView(long id, String name) {}
```

**적용 설명:** 반복 코드 감소에는 record 같은 언어 기능도 대안이다. Lombok을 선택했다면 생성되는 코드와 빌드 도구 설정을 이해한다.

## 구체적인 검토 사례

- [ ] **상황:** 반복 코드가 많다는 이유로 생성 도구를 넣는다.
  - **판단 기준:** 언어 기능과 비교하고 생성 결과를 이해한다.

- [ ] **상황:** 생성된 동등성이나 문자열 표현이 과도하다.
  - **판단 기준:** 필드·접근 수준·민감 정보 포함을 검토한다.
