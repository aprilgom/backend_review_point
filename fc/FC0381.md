# FC0381 · 조회 실행과 변경 실행의 계약

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0376](FC0376.md) · [다음 FC: FC0371 →](FC0371.md)

## 검토 질문

- [ ] 목록 결과를 만드는 조회와 변경 건수를 반환하는 실행을 구분해 서로 다른 책임을 명확히 했는가?

**직접 작성한 예시**

```java
List<User> queryUsers(String sql, StatementBinder binder) { /* 조회 */ }
int executeChange(String sql, StatementBinder binder) { /* 변경 건수 */ }
```

**적용 설명:** 조회 결과와 변경 건수의 계약을 분리한 시그니처 조각이다. 본문은 생략했으므로 그대로 컴파일되는 구현은 아니다.

## 구체적인 검토 사례

- [ ] **상황:** 한 실행 메서드가 조회와 갱신을 모두 처리한다.
  - **판단 기준:** 반환값과 실패 계약이 다른 책임을 나눈다.

- [ ] **상황:** 공통 자원 처리까지 완전히 복제한다.
  - **판단 기준:** 실행 절차는 재사용하고 결과 계약은 분리한다.
