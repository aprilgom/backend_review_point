# FC0173 · 생성자 주입과 필수 의존성

## 검토 질문

- [ ] 필수 의존성을 생성 시점에 제공해 불완전한 객체 상태를 줄이고 테스트에서 명시적으로 조립하는가?

**직접 작성한 예시**

```java
final class InvoiceService {
    private final Invoices invoices;
    InvoiceService(Invoices invoices) { this.invoices = Objects.requireNonNull(invoices); }
}
```

**적용 설명:** 필수 의존성을 생성 시 제공하므로 불완전한 객체 상태를 줄인다.

## 구체적인 검토 사례

- [ ] **상황:** 의존성을 나중에 필드로 채운다.
  - **판단 기준:** 생성 시 필수 의존성을 받도록 한다.

- [ ] **상황:** 누락된 의존성이 실행 때 발견된다.
  - **판단 기준:** 불완전한 객체가 만들어지지 않게 검증한다.
