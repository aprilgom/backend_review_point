# FC0469 · 이미지 처리에서 불필요한 404를 보내지 않는 방향을 고려하며, 현재의 기본 이미지 표시 방식도 적절한 선택으로 볼 수 있다.

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0473](FC0473.md) · [다음 FC: FC0479 →](FC0479.md)

- [ ] 이미지 처리에서 불필요한 404를 보내지 않는 방향을 고려하며, 현재의 기본 이미지 표시 방식도 적절한 선택으로 볼 수 있다. (토론)
  - 조건: 리뷰 참여자는 논의된 두 방법 모두 괜찮다고 했지만, 두 대안의 구체적인 내용은 입력에 없다. 기본 이미지 방식에 대한 수용 의견이지 특정 구현으로 변경하라는 요구는 아니며, 작성자는 감사만 표했다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```html
<img src="/images/item-17.png" alt="상품 사진"
     onerror="this.onerror=null;this.src='/images/placeholder.png'">
```

**적용 설명:** 기본 이미지로 한 번만 대체하는 예다. CSP가 인라인 이벤트를 막는 앱에서는 스크립트에 이벤트를 등록하고 기본 파일도 배포한다.
