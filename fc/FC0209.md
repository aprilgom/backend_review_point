# FC0209 · 날짜 의미를 보존하는 타입

[소속 분야: 도메인 모델·값 표현](../11-domain-model.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0204](FC0204.md) · [다음 FC: FC0208 →](FC0208.md)

## 검토 질문

- [ ] 날짜를 임의 문자열 대신 검증·연산 가능한 타입으로 표현하고 시각·시간대와 구분하는가?

**직접 작성한 예시**

```java
LocalDate day = LocalDate.parse("2025-03-01");
LocalDate next = day.plusDays(1);
```

**적용 설명:** 날짜 의미와 연산을 타입으로 표현한다. 날짜에 임의의 시간대나 시각을 덧붙이지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 날짜를 문자열로 잘라 계산한다.
  - **판단 기준:** 날짜 타입의 검증·연산을 사용한다.

- [ ] **상황:** 날짜에 임의 시간대를 붙인다.
  - **판단 기준:** 순수 날짜와 실제 시점을 구분한다.
