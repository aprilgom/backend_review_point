## 검토 질문

- [ ] 중복·개수·외부 변경 같은 컬렉션 규칙을 한 경계에서 보장할 필요가 있는가?

**직접 작성한 예시**

```java
record Tags(List<String> values) {
    Tags {
        values = List.copyOf(values);
        if (new HashSet<>(values).size() != values.size()) throw new IllegalArgumentException();
    }
}
```

**적용 설명:** 중복 금지와 외부 변경 차단을 컬렉션 경계에 모은다. 단순 목록에 규칙이 없다면 래퍼가 불필요할 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 목록의 중복·개수 검증이 여러 곳에 흩어진다.
  - **판단 기준:** 컬렉션 경계에서 공통 불변식을 보장한다.

- [ ] **상황:** 외부가 내부 목록을 직접 수정한다.
  - **판단 기준:** 방어적 복사나 제한된 변경 API를 사용한다.
