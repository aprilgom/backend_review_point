## 검토 질문

- [ ] 컨트롤러 이름에 웹·콘솔 같은 채널뿐 아니라 담당 기능도 드러나는가?

**직접 작성한 예시**

```java
final class OrderWebController {}
final class OrderConsoleController {}
```

**적용 설명:** 접근 채널과 담당 도메인을 함께 드러낸다.

## 구체적인 검토 사례

- [ ] **상황:** 채널만 표시한 컨트롤러 이름을 쓴다.
  - **판단 기준:** 담당 기능도 드러낸다.

- [ ] **상황:** 하나의 컨트롤러가 여러 기능을 처리한다.
  - **판단 기준:** 이름이 길어지는 원인이 책임 혼합인지 본다.
