# FC0334 · 진입 채널과 기능을 구분하는 이름

## 검토 질문

- [ ] 컨트롤러 이름에 웹·콘솔 같은 채널뿐 아니라 담당 기능도 드러나는가?

**직접 작성한 예시**

```java
final class OrderWebController {}
final class OrderConsoleController {}
```

**적용 설명:** 접근 채널과 담당 도메인을 함께 드러낸다.

## 구체적인 검토 사례

- [ ] ConsoleController와 WebController의 이름에 어떤 기능을 담당하는 컨트롤러인지 더 명확히 드러내도록 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 ConsoleCarGameController를 예로 들었다. 작성자는 ConsoleRacingGameController와 WebRacingGameController로 명명했다고 보고했으며, 특정 예시 이름을 그대로 사용하라는 요구는 아니었다.

- [ ] 관리자 기능만 다루는 컨트롤러라면 MemberController보다 AdminMemberController라는 이름을 제안했다. (개선 제안)
  - 조건: 관리자 기능만 담당한다는 조건의 명명 제안이다. 작성자는 유지보수상 이점이 있겠다고 동의했지만, 이름 변경을 완료했다고 보고하지는 않았다.

- [ ] ControllerHandlerAdapter의 이름이 혼동될 수 있어 다른 이름을 검토하자는 의견을 냈다. (토론)
  - 조건: 작성자는 Controller 타입의 핸들러를 처리하는 HandlerAdapter라는 명명 기준과 HandlerExecutionHandlerAdapter와의 일관성을 설명했다. 리뷰 참여자는 이유를 이해했고 자신도 대안을 찾지 못했으므로 즉시 변경을 강요하지 않겠다고 완화했다. 명명 관심사 자체를 명백히 철회한 것은 아니다.
