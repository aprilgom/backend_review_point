# FC0324 · 테스트 이름과 실제 범위

## 검토 질문

- [ ] 컨트롤러·서비스·DB 등 실제 포함 범위를 테스트 클래스와 패키지 이름에서 오해하지 않게 하는가?

**직접 작성한 예시**

```java
class TaskApiIntegrationTest {
    // HTTP → 서비스 → 실제 테스트 DB까지 검증
}
```

**적용 설명:** 실제 범위가 통합 테스트라면 클래스·패키지 이름에서 범위를 오해하지 않게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 컨트롤러 테스트가 실제 DB까지 띄운다.
  - **판단 기준:** 이름과 패키지가 통합 범위를 설명해야 한다.

- [ ] **상황:** 이름만 단위 테스트로 바꾼다.
  - **판단 기준:** 실제 실행 의존과 검증 대상을 구분한다.
