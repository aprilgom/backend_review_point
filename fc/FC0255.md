# FC0255 · 실패 상태 반환과 화면 이동의 구분

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0253](FC0253.md)

## 검토 질문

- [ ] API 실패 응답과 사용자 안내 화면으로의 리다이렉트 중 요구된 흐름을 정확히 구현했는가?

**직접 작성한 예시**

```http
HTTP/1.1 303 See Other
Location: /login-error
```

**적용 설명:** 실패 안내 화면으로 이동하는 계약 예다. 인증 실패 상태를 반환하는 API 계약과 리다이렉트 화면 흐름을 혼동하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 화면 이동 요구를 상태 코드만으로 구현한다.
  - **판단 기준:** 브라우저 흐름과 API 계약을 구분한다.

- [ ] **상황:** 실패 페이지로 이동하면서 원인을 잃는다.
  - **판단 기준:** 안전한 안내와 재시도 경로를 유지한다.
