# FC0340 · 가드 절과 중첩 축소

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0343](FC0343.md) · [다음 FC: FC0332 →](FC0332.md)

## 검토 질문

- [ ] 실패·비대상 조건을 먼저 처리해 중첩을 줄이면서 필수 후처리와 자원 해제를 유지하는가?

**직접 작성한 예시**

```java
if (user == null) return;
if (!user.isActive()) return;
sendNotice(user);
```

**적용 설명:** 가드 절로 중첩을 줄인 예다. 조기 반환이 자원 해제나 필수 후처리를 건너뛰지 않도록 한다.

## 구체적인 검토 사례

- [ ] 사용자 정보를 처리하는 코드의 중첩 깊이가 2 이상이므로 줄여 보자고 제안했다. (개선 제안)
  - 조건: 작성자는 로직을 추출해 보겠다고 답했다. 실제 중첩 감소나 추출 완료 여부는 확인되지 않는다.

- [ ] try문으로 중첩 관리가 어려운 점을 인정하면서도 코드의 중첩 깊이를 1로 줄여보는 것을 제안한다. (개선 제안)
  - 조건: 필수 규칙이 아닌 개선 제안이다. 작성자는 쿼리 실행 전후 Connection에서 PreparedStatement를 실행하는 로직을 분리했다고 보고했으며, 링크된 커밋의 실제 구현이나 중첩 깊이 감소 결과는 확인하지 않았다.

- [ ] 주문 완료 여부를 확인하는 반복문을 스트림으로 바꾸어 중첩 깊이를 1단계로 줄여보자고 제안했다. (개선 제안)
  - 조건: 작성자는 제안에 동의했지만 실제 변경 여부는 답변만으로 확인되지 않는다.
