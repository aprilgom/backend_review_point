## 검토 질문

- [ ] 같은 부하 조건에서 지연·처리량·DB 사용량을 비교해 커넥션 풀 크기를 결정하는가?

**직접 작성한 예시**

```csv
poolSize,p95_ms,throughput,db_cpu
4,측정값,측정값,측정값
8,측정값,측정값,측정값
```

**적용 설명:** 비교 실험 기록 템플릿이다. 동일 데이터·동시 사용자 수·워밍업 조건에서 측정하고 숫자를 결과로 가장하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 커넥션 수를 늘리면 무조건 빨라진다고 본다.
  - **판단 기준:** DB 부하와 대기 지연을 함께 측정한다.

- [ ] **상황:** 서로 다른 부하 조건의 결과를 비교한다.
  - **판단 기준:** 데이터·동시성·워밍업 조건을 맞춘다.
