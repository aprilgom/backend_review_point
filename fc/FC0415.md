# FC0415 · 기본 요청 매핑 규칙의 검증

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0412](FC0412.md) · [다음 FC: FC0416 →](FC0416.md)

## 검토 질문

- [ ] 요청 메서드를 생략했을 때의 기본 지원 범위를 계약대로 테스트하는가?

**직접 작성한 예시**

```java
for (Method method : supportedMethods) {
    assertTrue(router.find("/any", method).isPresent());
}
```

**적용 설명:** 자체 라우터에서 메서드 생략은 모든 지원 메서드라는 계약일 때의 테스트다. 기본 계약이 다르면 기대값도 달라진다.

## 구체적인 검토 사례

- [ ] **상황:** 메서드 생략 시 기본 매핑을 확인하지 않는다.
  - **판단 기준:** 지원되는 요청 종류를 계약대로 테스트한다.

- [ ] **상황:** 생략이 전체 허용이라고 추측한다.
  - **판단 기준:** 실제 프레임워크·자체 규칙을 확인한다.
