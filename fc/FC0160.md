## 검토 질문

- [ ] 다른 기능을 호출할 때 저장소 직접 접근 대신 공통 정책을 제공하는 서비스를 재사용할 이유가 있는가?

**직접 작성한 예시**

```java
Customer customer = customerService.requireActive(customerId);
orderService.place(customer, lines);
```

**적용 설명:** 공통 활성 상태 검증을 서비스 계약으로 재사용하는 예시다. 단순 조회마다 서비스를 겹쳐 만들 필요는 없다.

## 구체적인 검토 사례

- [ ] **상황:** 여러 기능이 같은 활성 상태 검사를 복제한다.
  - **판단 기준:** 정책 서비스로 공유할 수 있다.

- [ ] **상황:** 서비스가 조회만 그대로 중계한다.
  - **판단 기준:** 추가 호출 계층이 필요한지 검토한다.
