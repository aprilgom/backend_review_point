- [ ] 호출 메타데이터에 이미 만든 실행 대상을 전달해 반복 생성을 줄이며 수명과 동시성 계약을 유지하는가?

**직접 작성한 예시**

```java
HandlerExecution execution = new HandlerExecution(controller, actionMethod);
```

**적용 설명:** 실행 메타데이터에 이미 만든 인스턴스를 전달한다. 동시 호출 시 안전성과 수명 범위를 먼저 정한다.

- [ ] **상황:** 리플렉션 호출마다 대상 객체를 만든다.
  - **판단 기준:** 메타데이터와 이미 만든 대상을 재사용할 수 있다.

- [ ] **상황:** 실행 대상을 전역으로 묶는다.
