# FC0280 · HandlerExecution 생성자에서 컨트롤러 인스턴스를 받아 매 요청마다 인스턴스를 생성하지 않는 방안에 대한 의견을 물었다.

[소속 분야: 성능·측정](../16-performance.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0267](FC0267.md) · [다음 FC: FC0281 →](FC0281.md)

- [ ] HandlerExecution 생성자에서 컨트롤러 인스턴스를 받아 매 요청마다 인스턴스를 생성하지 않는 방안에 대한 의견을 물었다. (개선 제안)
  - 조건: 반복 인스턴스 생성을 줄이는 대안으로 제시했으며, 현재 구현을 확정적인 결함으로 규정하지 않았다. 작성자는 동의하고 변경하겠다고 답했지만 실제 변경 결과는 이 대화만으로 확인되지 않는다.

- [ ] HandlerExecution이 요청마다 컨트롤러 인스턴스를 새로 생성해야 하는지 질문한다. (설계 질문)
  - 조건: 반복 생성의 필요성을 묻는 질문이며 성능 결함이 확정된 것은 아니다. 작성자는 외부에서 한 번 생성한 인스턴스를 전달받아 필드로 보유하는 방안이 좋겠다고 답했으나 실제 변경 여부는 확인되지 않는다.

- [ ] 요청 처리 때마다 Handler를 생성하는 대신 미리 생성한 인스턴스를 재사용하자고 제안했다. (개선 제안)
  - 조건: 객체 재사용 제안이며, 생성 비용에 대한 측정이나 공유 인스턴스의 안전성 검토는 대화에 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
HandlerExecution execution = new HandlerExecution(controller, actionMethod);
```

**적용 설명:** 실행 메타데이터에 이미 만든 인스턴스를 전달한다. 동시 호출 시 안전성과 수명 범위를 먼저 정한다.
