# FC0079 · 빌드 산출물의 정적 리소스 제공

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0090](FC0090.md) · [다음 FC: FC0096 →](FC0096.md)

## 검토 질문

- [ ] 정적 리소스가 산출물에 포함되고 실행 서버가 올바른 경로·형식으로 제공하는가?

**직접 작성한 예시**

```java
// 자체 정적 파일 핸들러를 등록하는 개념 코드
router.getPrefix("/assets/", staticFiles(resourceRoot));
```

**적용 설명:** 빌드 산출물에 리소스가 들어 있는지와 해당 경로를 실제 서버가 제공하는지 모두 확인한다. 경로 탈출 방지는 staticFiles에서 구현해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 로컬 실행에서는 리소스가 보인다.
  - **판단 기준:** 패키징된 산출물에서도 파일을 확인한다.

- [ ] **상황:** 파일은 있지만 서버 경로가 없다.
  - **판단 기준:** 리소스 포함과 요청 매핑을 별도로 검증한다.
