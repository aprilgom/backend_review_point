# FC0079 · 빌드 산출물의 정적 리소스 제공

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0090](FC0090.md) · [다음 FC: FC0096 →](FC0096.md)

## 검토 질문

- [ ] 정적 리소스가 산출물에 포함되고 실행 서버가 올바른 경로·형식으로 제공하는가?

**직접 작성한 예시**

```java
// 자체 정적 파일 핸들러를 등록하는 개념 코드
router.getPrefix("/assets/", staticFiles(resourceRoot));
```

**적용 설명:** 빌드 산출물에 리소스가 들어 있는지와 해당 경로를 실제 서버가 제공하는지 모두 확인한다. 경로 탈출 방지는 staticFiles에서 구현해야 한다.

## 구체적인 검토 사례

- [ ] Gradle 빌드 시 CSS를 불러오지 못하는 문제를 보고하고, 정적 리소스를 기본 서블릿에 매핑하는 web.xml 추가를 제안했다. (문제 보고)
  - 조건: 리뷰어는 app/webapp/WEB-INF에 web.xml을 추가하는 구체적인 설정 예시를 제공했다. 작성자는 화면이 예쁘게 나온다고 답했지만 테스트 통과는 3단계로 미루겠다고 했다. 화면 개선은 작성자의 보고이며, 테스트 성공이나 설정의 전체 유효성을 확인한 근거는 아니다.

- [ ] CSS·JS가 정상 동작하지 않는 문제에 대해 app/webapp/WEB-INF에 web.xml을 추가하는 방안을 제안했다. (개선 제안)
  - 조건: 작성자는 자바 기반 서블릿 초기화와 ResourceFilter가 있는 상황에서 필터 때문에 XML을 쓰는 것이 맞는지 반문했다. 제안자는 자신은 XML 추가 후 동작한 것만 확인했으며 방식의 적절성은 더 알아봐야 한다는 취지로 답했다. web.xml이 필요한 원인이나 유일한 해결책이라는 결론은 없다.
