# FC0478 · 404.html에서 이미지가 깨져 보이는 문제를 보고하고 수정을 요청했다.

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0476](FC0476.md) · [다음 FC: FC0477 →](FC0477.md)

- [ ] 404.html에서 이미지가 깨져 보이는 문제를 보고하고 수정을 요청했다. (문제 보고)
  - 조건: 리뷰 참여자가 관찰한 표시 문제이며, 원인이나 수정 결과는 대화에 없다.

- [ ] login 및 login.html 요청에서 화면이 나오지 않는 문제를 보고하고 정적 화면이 제대로 표시되는지 확인해 달라고 요청했다. (문제 보고)
  - 조건: 리뷰 참여자는 이후 정상 작동한다고 보고하며 머지를 안내했다. 다만 구체적인 변경 내용이나 확인한 요청 범위는 제시하지 않았다.

- [ ] 루트 경로를 제외한 페이지에서 오류가 발생하고 CSS가 로드되지 않는 현상을 보고하며 로컬 환경에서도 확인해 달라고 요청했다. (문제 보고)
  - 조건: 리뷰 참여자의 실행 환경에서 관찰한 문제다. 작성자는 제출 직전 리팩터링 중 경로 설정 등에 문제가 생겼으며 정상 작동하도록 수정했다고 보고했다. 첨부 이미지의 상세 로그나 실제 수정 결과는 확인할 수 없으며, 이후 승인을 재검증의 증거로 보지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```html
<img src="/assets/not-found.svg" alt="페이지를 찾을 수 없습니다">
```

**적용 설명:** 중첩된 잘못된 경로에서도 루트 기준 리소스를 찾게 한다. 하위 경로 배포라면 base path를 반영한다.
