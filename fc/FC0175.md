# FC0175 · 도메인 중심 저장 계약

## 검토 질문

- [ ] 저장 구현이 도메인 계약을 따르도록 의존 방향을 정하고 도메인이 데이터 접근 기술을 모르도록 했는가?

**직접 작성한 예시**

```java
// domain: 계약
interface Orders { void save(Order order); }
// persistence: 도메인 계약 구현
final class SqlOrders implements Orders { /* JDBC 구현 */ }
```

**적용 설명:** 도메인이 저장 구현을 import하지 않도록 의존 방향을 역전한다. 구현 본문은 생략했다.

## 구체적인 검토 사례

- [ ] **상황:** 도메인이 저장 기술의 타입을 참조한다.
  - **판단 기준:** 도메인 계약을 구현하는 어댑터로 방향을 바꾼다.

- [ ] **상황:** 인터페이스만 안쪽으로 옮긴다.
  - **판단 기준:** 반환값·예외에도 기술 의존이 남았는지 본다.
