# FC0172 · 기능별 최소 의존 역할

## 검토 질문

- [ ] 기능이 필요한 최소 역할에 의존하며 관련 없는 저장·서비스 책임을 끌어오지 않는가?

**직접 작성한 예시**

```java
interface SlotAvailability { boolean available(LocalDate day); }
CalendarService calendar = new CalendarService(slotAvailability);
```

**적용 설명:** 날짜 기능에 필요한 최소 조회 역할을 의존한다. 이름보다 실제 책임 방향을 기준으로 판단한다.

## 구체적인 검토 사례

- [ ] **상황:** 단순 조회 기능이 큰 서비스 전체에 의존한다.
  - **판단 기준:** 필요한 최소 역할을 추출할 수 있다.

- [ ] **상황:** 역할을 지나치게 잘게 나눈다.
  - **판단 기준:** 호출 맥락의 응집도와 탐색 비용을 비교한다.
