# FC0087 · 배포 서비스의 접근 가능성

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0080](FC0080.md) · [다음 FC: FC0088 →](FC0088.md)

## 검토 질문

- [ ] 배포 주소에 실제로 접근할 수 있으며 프로세스·포트·네트워크·라우팅 문제를 구분해 진단하는가?

**직접 작성한 예시**

```http
GET /health HTTP/1.1
Host: service.example.invalid
```

**적용 설명:** 가상의 진단 요청이다. 프로세스·리스닝 포트·방화벽·라우팅·의존 서비스 상태를 구분해 접근 실패 원인을 좁힌다.

## 구체적인 검토 사례

- [ ] **상황:** 배포 후 주소에 접근할 수 없다.
  - **판단 기준:** 프로세스·포트·방화벽·라우팅을 단계별로 확인한다.

- [ ] **상황:** 프로세스만 살아 있으면 정상으로 판단한다.
  - **판단 기준:** 필수 의존 서비스와 실제 요청 성공도 확인한다.
