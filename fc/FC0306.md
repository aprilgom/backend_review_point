# FC0306 · 반복 리터럴의 의미 있는 상수화

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0300](FC0300.md) · [다음 FC: FC0311 →](FC0311.md)

## 검토 질문

- [ ] 같은 의미로 반복되는 값을 이름 붙여 관리하고 우연히 값만 같은 리터럴은 구분하는가?

**직접 작성한 예시**

```java
private static final String SESSION_COOKIE = "SESSION";
String value = cookies.get(SESSION_COOKIE);
```

**적용 설명:** 같은 의미로 반복되는 문자열을 이름 붙인다. 우연히 값만 같은 문자열까지 묶지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 의미의 문자열을 반복 입력한다.
  - **판단 기준:** 이름 있는 상수로 오타·변경 누락을 줄인다.

- [ ] **상황:** 값만 같다는 이유로 묶는다.
  - **판단 기준:** 독립적으로 바뀔 수 있으면 분리한다.
