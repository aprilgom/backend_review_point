# FC0306 · 반복되는 문자열을 상수로 추출하도록 요청했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0300](FC0300.md) · [다음 FC: FC0311 →](FC0311.md)

- [ ] 반복되는 문자열을 상수로 추출하도록 요청했다. (개선 제안)
  - 조건: 작성자는 문자열 대신 상수를 사용했다는 취지의 커밋 링크를 남겼다. 변경된 코드 자체는 대화 본문에 제시되지 않았다.

- [ ] 쿼리 문자열 위치를 찾는 데 사용하는 `?` 리터럴을 리팩터링하면서 상수로 분리하자는 제안이다. (개선 제안)
  - 조건: 작성자는 제안에 동의했으나 실제 변경 여부는 이 대화에서 확인되지 않는다.

- [ ] 여러 번 사용하는 'Content-Length' 문자열을 상수로 추출하는 방안을 고려하자는 제안이다. (개선 제안)
  - 조건: 리뷰 참여자는 개인 취향이나 팀 컨벤션에 따라 선택이 달라질 수 있다고 명시했으며 필수 변경으로 요구하지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
private static final String SESSION_COOKIE = "SESSION";
String value = cookies.get(SESSION_COOKIE);
```

**적용 설명:** 같은 의미로 반복되는 문자열을 이름 붙인다. 우연히 값만 같은 문자열까지 묶지 않는다.
