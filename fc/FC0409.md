# FC0409 · 서비스 소유 정책의 테스트

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0411](FC0411.md) · [다음 FC: FC0413 →](FC0413.md)

## 검토 질문

- [ ] 서비스가 담당하는 정책과 저장 부작용을 도메인·컨트롤러 테스트에만 맡기지 않고 확인하는가?

**직접 작성한 예시**

```java
assertThrows(DuplicateName.class, () -> service.create(existingName));
assertEquals(1, repository.countByName(existingName));
```

**적용 설명:** 서비스가 소유한 중복 정책과 저장 부작용을 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스의 정책 테스트가 없다.
  - **판단 기준:** 서비스 소유 판단과 부작용을 확인한다.

- [ ] **상황:** 도메인 규칙을 서비스 테스트에만 의존한다.
  - **판단 기준:** 책임별 검증 범위를 나눈다.
