# FC0467 · 방 이름 입력을 취소하면 null 이름의 방이 생성되므로, 입력하지 않은 경우 방이 생성되지 않도록 하자.

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0472](FC0472.md) · [다음 FC: FC0471 →](FC0471.md)

- [ ] 방 이름 입력을 취소하면 null 이름의 방이 생성되므로, 입력하지 않은 경우 방이 생성되지 않도록 하자. (문제 보고)
  - 조건: 리뷰 참여자가 입력 취소 시의 동작을 보고했다. 작성자는 입력했을 때만 방이 생성되도록 변경했다고 답했으나 실제 동작은 확인되지 않는다.

- [ ] 게임 종료 버튼을 누른 뒤에도 게임을 이어서 진행할 수 있는 동작이 의도된 것인지 질문했다. (설계 질문)
  - 조건: 리뷰어는 자신의 구현에서는 게임을 강제로 끝낸다고 비교했지만, 현재 동작을 결함으로 확정하지 않았다. 이 대화에는 의도를 설명하는 작성자 답변이 없다.

- [ ] 관리자 권한을 가진 사용자의 이름을 입력하면 관리자 화면으로 이동하는 동작에 대한 안내 문구가 화면에 없음을 지적했다. (문제 보고)
  - 조건: 관심사는 권한 분리 자체의 보안성보다 사용자가 화면 전환 동작을 이해할 수 있는지에 있다. 작성자는 안내 부족이 혼란을 줄 수 있다는 데 동의하고 문구 보완 계획을 밝혔으며, 반영 완료 여부는 확인되지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```javascript
const name = prompt("방 이름");
if (name !== null && name.trim() !== "") await createRoom(name.trim());
```

**적용 설명:** 취소와 빈 입력을 구분하고 생성 요청을 보내지 않는다. 서버에서도 동일한 필수값 검증을 수행한다.
