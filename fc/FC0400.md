# FC0400 · 정적 리소스 핸들러 테스트에서 CSS와 자바스크립트 파일 처리도 검증하면 좋겠다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0419](FC0419.md)

- [ ] 정적 리소스 핸들러 테스트에서 CSS와 자바스크립트 파일 처리도 검증하면 좋겠다. (개선 제안)
  - 조건: 추가 검증 범위를 제안한 것이며, 구체적인 검증 항목이나 반영 결과는 대화에 없다.

- [ ] 현재 사용자 화면에서 테마가 실제로 표시되는지 확인해 달라고 요청했다. (개선 제안)
  - 조건: 표시 오류를 확정한 발언이 아니라 화면 동작 확인 요청이다. 작성자는 사용자용 전체 테마 조회 기능을 빠뜨렸다고 답하고 해당 기능 추가를 보고했으나, 화면 검증 결과를 직접 제시하지는 않았다.

- [ ] 핸들러 맵에 존재하지 않는 키로 조회했을 때의 동작을 확인하는 테스트를 추가하면 좋겠다. (개선 제안)
  - 조건: 작성자는 NPE가 발생할 것 같다고 답하면서도 다른 매핑에서 핸들러를 계속 찾도록 의도적으로 null을 반환한다고 설명했다. 리뷰 참여자는 이 설계 이유를 합리적이라고 수용하고, 없는 키에 대한 Map.get()은 null을 반환한다고 정정했다. 테스트 제안의 명시적 철회나 테스트 추가 결과는 없다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
assertEquals(200, client.get("/assets/site.css").status());
assertEquals("text/css", client.get("/assets/site.css").mediaType());
assertEquals(200, client.get("/assets/site.js").status());
```

**적용 설명:** 정적 파일 종류별 상태·본문·미디어 타입을 검증한다. 파일 존재만 확인하는 테스트와 구분한다.
