# FC0145 · 이미 특정 구간에 속한 역을 삭제할 때 어떻게 처리되는지 확인한다.

[소속 분야: 데이터 관계·영속성](../08-persistence.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0144](FC0144.md)

- [ ] 이미 특정 구간에 속한 역을 삭제할 때 어떻게 처리되는지 확인한다. (설계 질문)
  - 조건: 리뷰어는 삭제 동작을 질문했으며 구체적인 실패 결과를 확정하지 않았다. 작성자는 구간에 포함된 역을 삭제하려 하면 예외를 발생시키는 로직을 추가했다고 보고했다.

- [ ] 역이 두 개인 노선에서 역을 삭제하면 노선까지 함께 삭제되는 동작이 의도된 것인지 질문했다. (설계 질문)
  - 조건: 작성자는 의도한 동작이라고 답했지만, 다시 보니 노선까지 삭제할 필요가 있었는지는 의문이라고 밝혔다. 동작을 변경했다는 보고는 없으며 결함으로 확정된 것은 아니다.

- [ ] 역을 삭제할 때 관련 노선과 구간에 어떤 영향이 생기는지 확인하도록 질문했다. (설계 질문)
  - 조건: 작성자는 삭제 전에 해당 역이 Section에 존재하면 예외를 발생시켜 삭제를 막도록 변경했다고 보고했다. 리뷰어가 특정 삭제 정책을 직접 요구한 것은 아니며, 실제 연관 데이터 처리 결과는 확인되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
assertThrows(ReferencedStation.class, () -> stations.delete(inUseStation));
assertTrue(stations.exists(inUseStation));
```

**적용 설명:** 참조 중인 역 삭제를 거절하는 계약을 테스트한다. DB 참조 제약과 애플리케이션 오류 변환도 일치해야 한다.
