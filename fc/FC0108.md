# FC0108 · 실행기 종류와 대기열 정책

[소속 분야: 비동기·동시성](../05-concurrency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0099](FC0099.md) · [다음 FC: FC0109 →](FC0109.md)

## 검토 질문

- [ ] 실행기를 선택할 때 스레드 수뿐 아니라 대기열·거절·종료 동작까지 비교했는가?

**직접 작성한 예시**

```java
ExecutorService workers = Executors.newFixedThreadPool(4);
// 지속적 입력이라면 기본 무제한 대기열이 메모리를 늘릴 수 있다.
```

**적용 설명:** 고정 스레드 수가 전체 작업량 제한을 뜻하지 않는다. 부하가 제한되지 않으면 유한 대기열과 거절 정책을 고려한다.

## 구체적인 검토 사례

- [ ] **상황:** 고정 풀을 전체 부하 제한으로 간주한다.
  - **판단 기준:** 대기열이 무제한인지 확인한다.

- [ ] **상황:** 종료 중 작업이 계속 제출된다.
  - **판단 기준:** 수락 중단과 잔여 작업 처리 방침을 정한다.
