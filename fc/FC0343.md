# FC0343 · 테스트 설명과 검증 내용의 일치

## 검토 질문

- [ ] 표시 이름과 메서드 이름이 실제 검증 조건·기대 결과와 일치하는가?

**직접 작성한 예시**

```java
@Test
@DisplayName("빈 이름으로 생성하면 거절한다")
void rejectsEmptyName() {
    assertThrows(InvalidName.class, () -> new Name(""));
}
```

**적용 설명:** JUnit 5 표시 이름 예시다. 메서드 이름과 설명이 서로 다른 동작을 약속하지 않게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 표시 이름과 메서드명이 다른 조건을 말한다.
  - **판단 기준:** 실제 준비·단언과 함께 정리한다.

- [ ] **상황:** 설명이 너무 포괄적이다.
  - **판단 기준:** 경계 입력과 기대 결과를 구체적으로 적는다.
