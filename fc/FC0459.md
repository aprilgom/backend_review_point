# FC0459 · 필수 인자의 nullable 여부

[소속 분야: 타입·타입 테스트](../24-type-safety.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0456](FC0456.md) · [다음 FC: FC0458 →](FC0458.md)

## 검토 질문

- [ ] 정상 호출에서 반드시 필요한 값이라면 경계에서 부재를 처리하고 내부 타입의 null 가능성을 줄일 수 있는가?

**직접 작성한 예시**

```java
void delete(long requiredId) { repository.delete(requiredId); }
```

**적용 설명:** 정상 호출에서 필수 식별자라면 nullable을 줄일 수 있다. HTTP 파싱에서 누락·오류를 먼저 처리한다.

## 구체적인 검토 사례

- [ ] **상황:** 필수 삭제 ID를 내부까지 nullable로 전달한다.
  - **판단 기준:** 입력 경계에서 부재를 처리할 수 있다.

- [ ] **상황:** nullable을 제거하며 잘못된 입력을 무시한다.
  - **판단 기준:** 파싱 실패를 명확한 오류로 반환한다.
