## 검토 질문

- [ ] result·value 같은 포괄적인 이름 대신 실제 데이터를 설명하는 이름을 사용할 수 있는가?

**직접 작성한 예시**

```java
List<Station> stations = repository.findAll();
```

**적용 설명:** result 대신 실제 담긴 도메인 개념을 사용한다.

## 구체적인 검토 사례

- [ ] **상황:** 여러 변수가 result나 value로만 불린다.
  - **판단 기준:** 담긴 데이터와 역할을 표현한다.

- [ ] **상황:** 호출 맥락에서 이미 명확한 이름을 늘린다.
  - **판단 기준:** 불필요한 반복 없이 이해되는 수준을 택한다.
