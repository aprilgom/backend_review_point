# FC0456 · 인자 타입의 최소 범위

[소속 분야: 타입·타입 테스트](../24-type-safety.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0464](FC0464.md) · [다음 FC: FC0459 →](FC0459.md)

## 검토 질문

- [ ] 실제로 필요한 타입보다 넓은 Object 등으로 받아 런타임 오류를 늘리지 않는가?

**직접 작성한 예시**

```java
List<Class<?>> scan(String basePackage) { return scanner.find(basePackage); }
```

**적용 설명:** Object 대신 필요한 타입을 받으면 잘못된 인자를 컴파일 단계에서 줄일 수 있다. 문자열 내용 검증은 별도다.

## 구체적인 검토 사례

- [ ] **상황:** 문자열만 필요한 인자를 Object로 받는다.
  - **판단 기준:** 타입을 좁혀 잘못된 호출을 줄인다.

- [ ] **상황:** 구체 타입이면 값 검증도 끝났다고 본다.
  - **판단 기준:** 빈값·형식·범위는 따로 검증한다.
