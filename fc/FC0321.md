# FC0321 · @GetMapping("")의 빈 문자열 인자를 생략해 @GetMapping으로 간결하게 표현하도록 제안했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0298](FC0298.md) · [다음 FC: FC0327 →](FC0327.md)

**혼합·경계:** @GetMapping 표현 외에 메서드 명명 등 일반 가독성 사례가 포함됨.

- [ ] @GetMapping("")의 빈 문자열 인자를 생략해 @GetMapping으로 간결하게 표현하도록 제안했다. (개선 제안)
  - 조건: 원문 맥락 확인

- [ ] Theme을 매핑하는 메서드 이름을 getReservationRowMapper에서 getThemeRowMapper로 변경하자고 제안했다. (개선 제안)
  - 조건: 제안 코드와 대상 코드에서 명명 변경을 확인할 수 있으며, 실제 반영 여부는 제시되지 않았다.

- [ ] 인자가 없는 @GetMapping()에서 괄호를 생략해 @GetMapping으로 표기하자는 제안이다. (개선 제안)
  - 조건: 코드 제안만 있으며 동작상 결함이나 변경 결과는 언급되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
@org.springframework.web.bind.annotation.GetMapping
List<TaskReply> listTasks() { return query.listTasks(); }
```

**적용 설명:** 혼합 FC에 남은 Spring 전용 표현 예시다. 빈 문자열과 기본값이 실제 매핑 의미에서 같을 때만 생략한다.
