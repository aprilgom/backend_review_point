# FC0215 · 날짜와 시각을 함께 고려한 경계 검증

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0216 →](FC0216.md)

## 검토 질문

- [ ] 같은 날짜라도 이미 지난 시각을 구분하고 현재 시점과 같은 값의 허용 여부를 정했는가?

**직접 작성한 예시**

```java
LocalDateTime requested = LocalDateTime.of(day, time);
if (!requested.isAfter(LocalDateTime.now(clock))) throw new PastSlot();
```

**적용 설명:** 날짜만 비교하면 같은 날 이미 지난 시간을 놓친다. 해당 업무 시간대와 정확히 현재 시각인 경우의 정책을 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 날짜만 비교해 과거 시각을 허용한다.
  - **판단 기준:** 날짜·시각을 업무 시간대로 함께 판단한다.

- [ ] **상황:** 정확히 현재 시점인 값을 다룬다.
  - **판단 기준:** 허용 경계를 명시하고 고정 시계로 검증한다.
