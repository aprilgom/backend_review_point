# FC0142 · 행동 협력을 위한 객체 관계

[소속 분야: 데이터 관계·영속성](../08-persistence.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0141](FC0141.md) · [다음 FC: FC0143 →](FC0143.md)

## 검토 질문

- [ ] 객체가 관련 객체의 행동과 협력해야 할 때 ID만 보유하는 것보다 직접 참조가 적절한가?

**직접 작성한 예시**

```java
record Segment(Station start, Station end) {
    boolean touches(Station station) { return start.equals(station) || end.equals(station); }
}
```

**적용 설명:** 구간이 역의 동작과 협력할 때 객체 참조가 의미를 드러낸다. 객체 그래프 크기·로딩 비용과 동등성 계약이 전제다.

## 구체적인 검토 사례

- [ ] **상황:** 관련 객체의 정보를 매번 외부에서 조립한다.
  - **판단 기준:** 직접 객체 협력이 규칙을 단순화할 수 있다.

- [ ] **상황:** 관계를 객체로 바꾸면서 전체 그래프를 읽는다.
  - **판단 기준:** 로딩 범위와 동등성 계약을 확인한다.
