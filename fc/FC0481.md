# FC0481 · 변경 후 파생 화면 상태의 갱신

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0479](FC0479.md)

## 검토 질문

- [ ] 삭제·취소 뒤 순번·합계·정렬 같은 파생 상태를 최신 서버 결과와 일치시키는가?

**직접 작성한 예시**

```javascript
await cancelWaiting(waitingId);
const updated = await fetchMyWaiting();
renderWaiting(updated);
```

**적용 설명:** 취소한 DOM만 제거하지 않고 서버 기준 순번을 갱신한다. 재조회 실패·경쟁 요청의 오래된 응답 처리도 설계한다.

## 구체적인 검토 사례

- [ ] **상황:** 취소 항목만 지워 남은 순번이 틀린다.
  - **판단 기준:** 파생 상태를 재조회하거나 일관되게 계산한다.

- [ ] **상황:** 이전 재조회 응답이 나중 상태를 덮어쓴다.
  - **판단 기준:** 경쟁 요청과 실패 시 화면 정책을 정한다.
