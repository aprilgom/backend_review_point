# FC0412 · 수정 후 테스트 결과의 확인

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0414](FC0414.md) · [다음 FC: FC0415 →](FC0415.md)

## 검토 질문

- [ ] 수정 뒤 필요한 테스트를 실제 실행하고 일부 성공이나 캐시 결과를 전체 성공으로 오해하지 않는가?

**직접 작성한 예시**

```sh
./gradlew clean test
```

**적용 설명:** 수정 후 테스트가 실제 통과하는지 확인하고 결과를 리뷰에 기록한다. 캐시된 성공이나 일부 실행만으로 전체 성공을 주장하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 수정 뒤 일부 테스트만 실행한다.
  - **판단 기준:** 변경에 필요한 범위가 실제 통과했는지 확인한다.

- [ ] **상황:** 캐시된 성공을 새 결과로 보고한다.
  - **판단 기준:** 실행 조건과 결과를 구분해 기록한다.
