# FC0412 · 현재 테스트가 실패하고 있으므로 수정한 뒤 다시 리뷰를 요청해 달라고 요구했다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0414](FC0414.md) · [다음 FC: FC0415 →](FC0415.md)

- [ ] 현재 테스트가 실패하고 있으므로 수정한 뒤 다시 리뷰를 요청해 달라고 요구했다. (문제 보고)
  - 조건: 후속 총평에서 같은 리뷰어가 테스트가 잘 동작한다고 보고했다. 실패한 테스트의 종류, 원인 및 구체적인 수정 내용은 이 대화에 제시되지 않아 확인할 수 없다. 작성자의 로깅 질문과 다른 스레드 참조는 별도의 직접 리뷰 근거로 확장하지 않았다.

- [ ] 테스트 코드가 실패하고 있으므로 확인해 달라고 요청했다. (문제 보고)
  - 조건: 리뷰 참여자의 실패 보고이며, 어떤 테스트가 어떤 원인으로 실패하는지는 제시되지 않았다. 후속 승인만으로 해당 실패의 해결을 확정하지 않는다.

- [ ] 테스트가 실패하고 있으므로 확인한 뒤 다시 리뷰를 요청해 달라고 요구한다. (문제 보고)
  - 조건: 리뷰어의 테스트 실패 보고이며, 실패한 테스트나 원인은 제시되지 않았다. 이후 일정상 머지를 진행한다는 안내만으로 테스트가 해결되었다고 볼 수 없다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```sh
./gradlew clean test
```

**적용 설명:** 수정 후 테스트가 실제 통과하는지 확인하고 결과를 리뷰에 기록한다. 캐시된 성공이나 일부 실행만으로 전체 성공을 주장하지 않는다.
