# FC0129 · 참조 대상의 현재 상태 확인

[소속 분야: 데이터 관계·영속성](../08-persistence.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0130](FC0130.md) · [다음 FC: FC0131 →](FC0131.md)

## 검토 질문

- [ ] 관련 데이터를 복제해 보관할지 ID로 조회할지 결정할 때 현재 상태와 스냅샷 요구를 구분했는가?

**직접 작성한 예시**

```java
Product product = products.find(line.productId()).orElseThrow();
if (!product.isActive()) throw new InactiveProduct();
```

**적용 설명:** 장바구니 스냅샷 대신 현재 상태를 확인한다. 가격 스냅샷이 필요한 시점과 조회 비용도 구분한다.

## 구체적인 검토 사례

- [ ] **상황:** 참조 대상의 상태를 복사해 보관한다.
  - **판단 기준:** 현재 상태가 필요한 시점에는 재확인한다.

- [ ] **상황:** 항상 최신 값으로 과거 결과를 다시 계산한다.
  - **판단 기준:** 확정 시점 스냅샷이 필요한 정보는 구분한다.
