# FC0015 · 커지는 메서드의 책임 분리

## 검토 질문

- [ ] 기능 추가로 커지는 메서드를 입력 변환·정책 판단·출력 변경처럼 의미 있는 단위로 나눌 수 있는가?

**직접 작성한 예시**

```java
void attachSession(HttpReply reply, Session session) {
    String value = sessionCookie(session.id());
    reply.addHeader("Set-Cookie", value);
}
```

**적용 설명:** 쿠키 문자열 구성과 응답 추가를 분리한다. sessionCookie는 인코딩·Secure·HttpOnly·SameSite 정책을 구현해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 기능 추가로 한 메서드가 계속 길어진다.
  - **판단 기준:** 입력 변환과 정책 판단 등 책임 단위로 나눈다.

- [ ] **상황:** 짧은 표현까지 모두 메서드로 분리한다.
  - **판단 기준:** 호출 깊이와 읽기 흐름이 개선되는지 비교한다.
