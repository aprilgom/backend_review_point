# FC0281 · 한 요청이 유발하는 쿼리 수

## 검토 질문

- [ ] 조회부터 응답 생성까지 발생하는 추가 쿼리를 관측하고 필요한 시점에만 로딩하는가?

**직접 작성한 예시**

```java
long before = sqlCounter.count();
service.getBooking(id);
long queries = sqlCounter.count() - before;
```

**적용 설명:** 테스트용 카운터로 조회 한 번의 쿼리 수를 관측한다. 지연 로딩으로 응답 직렬화 중 추가되는 쿼리도 포함해 본다.

## 구체적인 검토 사례

- [ ] **상황:** 주 조회 하나만 보고 쿼리 수를 판단한다.
  - **판단 기준:** 응답 직렬화까지 발생하는 조회를 관측한다.

- [ ] **상황:** 필요 없는 관계를 먼저 읽는다.
  - **판단 기준:** 실제 사용하는 시점과 조회 범위를 맞춘다.
