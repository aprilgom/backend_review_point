# FC0084 · 환경 의존 값의 외부 설정

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0077](FC0077.md) · [다음 FC: FC0081 →](FC0081.md)

## 검토 질문

- [ ] 외부 서비스 주소 등 환경에 따라 달라지는 값을 코드에서 분리하고 누락·잘못된 설정을 검증하는가?

**직접 작성한 예시**

```java
String endpoint = Objects.requireNonNull(System.getenv("PAYMENT_ENDPOINT"));
PaymentClient client = new PaymentClient(URI.create(endpoint));
```

**적용 설명:** 외부 주소를 환경 설정으로 주입하는 예시다. 허용 스킴·호스트 검증과 시작 시 누락 오류 처리도 구현한다.

## 구체적인 검토 사례

- [ ] **상황:** 외부 주소를 코드에 직접 적는다.
  - **판단 기준:** 환경별 구성으로 옮기고 시작 시 검증한다.

- [ ] **상황:** 설정이 없을 때 임의 기본 주소를 쓴다.
  - **판단 기준:** 잘못된 대상 호출보다 명확한 실패가 나을 수 있다.
