## 검토 질문

- [ ] 비용이 큰 그래프·인덱스 등을 재사용할 수 있으며 변경 시 무효화·버전·동시 재생성을 처리하는가?

**직접 작성한 예시**

```java
Graph graph = graphCache.get(networkVersion, () -> buildGraph(stations, segments));
```

**적용 설명:** 읽기 많은 그래프의 재사용 예다. 노선 변경 시 버전·무효화·동시 재생성을 처리해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 변경이 드문 그래프를 매 요청 재구성한다.
  - **판단 기준:** 버전별 재사용이나 지연 초기화를 검토한다.

- [ ] **상황:** 원본이 바뀌어도 캐시가 그대로다.
  - **판단 기준:** 무효화·교체·동시 생성 정책을 둔다.
