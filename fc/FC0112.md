# FC0112 · 식별자의 고유성 검증

## 검토 질문

- [ ] 같은 식별자를 가진 객체가 중복 저장될 수 있는지 생성·저장·DB 제약 경계에서 확인했는가?

**직접 작성한 예시**

```java
bookings.add(new Booking(new BookingId(7)));
assertThrows(DuplicateBooking.class, () -> bookings.add(new Booking(new BookingId(7))));
```

**적용 설명:** 같은 식별자가 두 번 추가되는 경우를 검증한다. 저장소에도 고유 제약을 두어 경쟁 조건을 방어한다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 ID의 객체를 두 번 추가한다.
  - **판단 기준:** 저장 결과와 중복 실패 계약을 검증한다.

- [ ] **상황:** 화면에서만 중복 입력을 막는다.
  - **판단 기준:** 직접 요청과 동시 저장도 방어해야 한다.
