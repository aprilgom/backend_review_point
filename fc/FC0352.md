## 검토 질문

- [ ] 템플릿 파일 형식과 컨트롤러의 논리 뷰 반환값이 엔진·리졸버 구성에 맞는가?

**직접 작성한 예시**

```handlebars
<h1>{{title}}</h1>
<ul>{{#each tasks}}<li>{{name}}</li>{{/each}}</ul>
```

**적용 설명:** resources/templates/home.hbs에 둘 수 있는 Handlebars 템플릿 예다. 해당 리졸버·접미사 설정이 필요하며 기존 분류상 남은 Spring 연동 사례임을 유지한다.

## 구체적인 검토 사례

- [ ] **상황:** 템플릿 파일 접미사가 리졸버와 다르다.
  - **판단 기준:** 파일 형식과 탐색 규약을 맞춘다.

- [ ] **상황:** 출력할 값이 템플릿에 전달되지 않는다.
  - **판단 기준:** 모델 키·이스케이프·반복 표현을 확인한다.
