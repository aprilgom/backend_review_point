# FC0352 · Spring Boot의 Handlebars 지원을 활용해 템플릿 확장자를 html에서 hbs로 바꾸고 파일명을 반환하는 뷰 처리 방식을 안내한다.

[소속 분야: 렌더링·데이터 로딩](../18-rendering.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0349](FC0349.md) · [다음 FC: FC0354 →](FC0354.md)

- [ ] Spring Boot의 Handlebars 지원을 활용해 템플릿 확장자를 html에서 hbs로 바꾸고 파일명을 반환하는 뷰 처리 방식을 안내한다. (개선 제안)
  - 조건: 참여자는 현재 사용하는 Handlebars 지원 기능을 전제로 설명했다. 외부 링크의 내용은 추가 근거로 사용하지 않았으며, 앞선 승인이나 머지 언급은 이 방식의 적용 결과를 입증하지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```handlebars
<h1>{{title}}</h1>
<ul>{{#each tasks}}<li>{{name}}</li>{{/each}}</ul>
```

**적용 설명:** resources/templates/home.hbs에 둘 수 있는 Handlebars 템플릿 예다. 해당 리졸버·접미사 설정이 필요하며 기존 분류상 남은 Spring 연동 사례임을 유지한다.
