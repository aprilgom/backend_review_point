# FC0379 · 서비스 결과의 도메인 노출

## 검토 질문

- [ ] 컨트롤러에 도메인 객체를 반환할 때 가변 상태·지연 로딩·내부 필드가 노출되는 영향을 검토했는가?

**직접 작성한 예시**

```java
record OrderSummary(long id, long total) {}
OrderSummary getOrder(long id) { return summarize(orders.get(id)); }
```

**적용 설명:** 컨트롤러에 가변 도메인 객체·지연 로딩 상태가 새어 나가지 않게 결과를 제한한다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스가 가변 엔티티를 그대로 반환한다.
  - **판단 기준:** 외부 수정과 내부 필드 노출을 검토한다.

- [ ] **상황:** 직렬화 중 지연 로딩이 발생한다.
  - **판단 기준:** 서비스 결과 경계와 필요한 조회 범위를 맞춘다.
