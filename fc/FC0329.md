# FC0329 · 상황과 기대 결과를 담은 테스트명

## 검토 질문

- [ ] 테스트 이름이 단계 번호가 아니라 어떤 조건에서 어떤 결과를 검증하는지 설명하는가?

**직접 작성한 예시**

```java
@Test void rejectsBookingInThePast() {
    assertThrows(PastSlot.class, () -> book(yesterday));
}
```

**적용 설명:** 단계 번호보다 상황·기대 결과를 이름에 담는다.

## 구체적인 검토 사례

- [ ] **상황:** 테스트 이름이 숫자나 작업 단계뿐이다.
  - **판단 기준:** 상황과 기대 결과를 이름으로 설명한다.

- [ ] **상황:** 이름은 오류 검증인데 정상 결과만 확인한다.
  - **판단 기준:** 설명과 실제 단언을 일치시킨다.
