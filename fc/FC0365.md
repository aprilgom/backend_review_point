# FC0365 · 도메인 개념별 패키지 응집도

## 검토 질문

- [ ] 서로 다른 도메인 개념이 섞여 있다면 응집도와 탐색성을 높이는 하위 패키지 분리가 필요한가?

**직접 작성한 예시**

```text
domain/
  route/Route.java
  station/Station.java
  booking/Booking.java
```

**적용 설명:** 개념별 응집도를 드러낸 구조다. 아직 작은 모델을 미리 세분화할 필요는 없다.

## 구체적인 검토 사례

- [ ] **상황:** 한 패키지에 다른 도메인 개념이 섞인다.
  - **판단 기준:** 변경 응집도에 맞게 나눌 수 있다.

- [ ] **상황:** 작은 모델을 미리 과도하게 분할한다.
  - **판단 기준:** 실제 탐색·의존 비용을 기준으로 판단한다.
