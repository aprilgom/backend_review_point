# FC0077 · 애플리케이션이 실행되지 않는다고 보고하고, 테이블 구조 문제인지 확인해 달라고 요청했다.

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0082](FC0082.md) · [다음 FC: FC0084 →](FC0084.md)

- [ ] 애플리케이션이 실행되지 않는다고 보고하고, 테이블 구조 문제인지 확인해 달라고 요청했다. (문제 보고)
  - 조건: 실행 실패는 리뷰 참여자의 보고이고 테이블 구조는 추정 원인이다. 작성자는 마지막 수정 사항을 push하지 않은 것 같다고 답했지만, 이 대화에는 수정 배포나 재실행 결과가 없다.

- [ ] 테스트와 빌드가 실행되지 않는 것 같다며 확인을 요청했다. (문제 보고)
  - 조건: 리뷰어는 자신이 놓친 실행 방법 등이 있으면 알려 달라고 덧붙여 보고의 불확실성을 열어 두었다. 이 단위에는 구체적인 실패 로그, 원인 또는 해결 결과가 없다.

- [ ] 애플리케이션이 실행되지 않는 것으로 보이므로 정상 기동되도록 수정한 뒤 다시 리뷰를 요청해 달라고 했다. (문제 보고)
  - 조건: 기동 실패의 구체적인 원인은 제시되지 않았다. 작성자는 문제 상황을 모두 수정했다고 답했으나, 실제 정상 기동 여부를 확인할 실행 결과는 대화에 없다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```sql
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'task';
```

**적용 설명:** 시작 오류의 실제 예외와 테이블 정의를 대조하는 진단 예시다. DB별 메타데이터 접근법은 다를 수 있다.
