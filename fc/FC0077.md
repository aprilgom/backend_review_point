## 검토 질문

- [ ] 애플리케이션 시작 실패를 실제 오류와 DB 구조를 대조해 재현하고 원인을 좁힐 수 있는가?

**직접 작성한 예시**

```sql
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'task';
```

**적용 설명:** 시작 오류의 실제 예외와 테이블 정의를 대조하는 진단 예시다. DB별 메타데이터 접근법은 다를 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 시작 실패를 코드 오류로만 추측한다.
  - **판단 기준:** 실제 예외와 연결·스키마 상태를 대조한다.

- [ ] **상황:** 컬럼 변경이 일부 환경에만 반영됐다.
  - **판단 기준:** 마이그레이션 버전과 실행 순서를 확인한다.
