# FC0081 · 라이브러리 버전 선택의 근거

## 검토 질문

- [ ] 선언·해석된 버전을 확인하고 호환성·필요 기능·유지보수 관점에서 선택 이유를 설명할 수 있는가?

**직접 작성한 예시**

```sh
./gradlew dependencyInsight --dependency jackson-core --configuration runtimeClasspath
```

**적용 설명:** 선언 버전과 실제 선택 버전·충돌 원인을 확인하는 예시다. 최신 여부만으로 변경하지 않고 호환성과 필요한 기능을 검토한다.

## 구체적인 검토 사례

- [ ] **상황:** 버전을 습관적으로 최신으로 올린다.
  - **판단 기준:** 필요 기능·호환성·변경 내용을 확인한다.

- [ ] **상황:** 선언 버전과 실제 사용 버전이 다르다.
  - **판단 기준:** 의존성 충돌과 선택 규칙을 추적한다.
