# FC0018 · Content-Type:과 charset=utf-8 문자열 리터럴이 반복되는 부분을 재사용할 방법이 있는지 묻는다.

[소속 분야: 추상화·중복](../01-abstraction.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0015](FC0015.md) · [다음 FC: FC0021 →](FC0021.md)

- [ ] Content-Type:과 charset=utf-8 문자열 리터럴이 반복되는 부분을 재사용할 방법이 있는지 묻는다. (설계 질문)
  - 조건: 확장자별 ContentType 구분 자체가 아니라 공통 문자열의 반복에 관한 질문이며, 구체적인 재사용 방식은 지정하지 않았다.

- [ ] Menu 초기화 시 기존 생성자를 재사용하는 방식을 제안한다. (개선 제안)
  - 조건: 작성자는 반영했다고 답했으며, 실제 변경 내용은 이 대화에서 확인되지 않는다.

- [ ] 임베디드 값 객체를 재사용할 때 반복될 수 있는 AttributeOverride 선언을 줄일 방법을 검토한다. (토론)
  - 조건: 작성자는 엔티티에서 매핑을 모아 보면 중첩된 값 객체의 칼럼을 파악하기 쉽고 현재 중복도 발생하지 않았다고 설명했다. 리뷰 참여자는 ORM을 사용하면서 객체에 집중하기 위해 Embeddable 내부에 Column을 선언하는 방식을 선호한다고 답했다. 이를 반드시 변경해야 하는 규칙으로 제시하지는 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
static final String JSON_UTF8 = "application/json; charset=utf-8";
reply.addHeader("Content-Type", JSON_UTF8);
```

**적용 설명:** 같은 의미의 미디어 타입을 재사용한다. 임의의 헤더 문자열까지 한 상수로 합치지 않는다.
