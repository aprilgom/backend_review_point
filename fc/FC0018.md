# FC0018 · 반복 프로토콜 문자열의 관리

## 검토 질문

- [ ] 같은 의미의 헤더·미디어 타입 문자열을 재사용 가능한 표현으로 관리하고 있는가?

**직접 작성한 예시**

```java
static final String JSON_UTF8 = "application/json; charset=utf-8";
reply.addHeader("Content-Type", JSON_UTF8);
```

**적용 설명:** 같은 의미의 미디어 타입을 재사용한다. 임의의 헤더 문자열까지 한 상수로 합치지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 헤더 문자열이 여러 곳에 반복된다.
  - **판단 기준:** 의미가 같은 표현을 상수나 값 타입으로 묶는다.

- [ ] **상황:** 우연히 같은 문자열을 하나로 합친다.
  - **판단 기준:** 변경 이유가 다르면 별도 정의를 유지한다.
