# FC0032 · 단건 조회와 목록 조회의 공통 구현

## 검토 질문

- [ ] 공통 조회 절차를 재사용하면서 단건 조회의 0건·복수 건 계약을 명시하는가?

**직접 작성한 예시**

```java
List<User> rows = query(sql, binder, this::mapUser);
if (rows.size() != 1) throw new UnexpectedRowCount(rows.size());
return rows.get(0);
```

**적용 설명:** 단건 조회를 공통 query에 위임하되 0건·복수 건 계약을 명시한다. query가 JDBC 자원을 안전하게 닫는다는 전제다.

## 구체적인 검토 사례

- [ ] **상황:** 단건 조회와 목록 조회의 절차가 겹친다.
  - **판단 기준:** 공통 실행을 재사용하고 결과 개수 검사는 분리한다.

- [ ] **상황:** 단건 조회에서 여러 행이 반환된다.
  - **판단 기준:** 첫 행을 조용히 택하지 말고 계약 위반을 처리한다.
