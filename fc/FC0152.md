# FC0152 · 객체 생성과 의존성 사용의 분리

## 검토 질문

- [ ] 의존 객체의 선택·생성을 조립 지점으로 옮겨 구현 교체와 테스트를 쉽게 할 수 있는가?

**직접 작성한 예시**

```java
ReportService service = new ReportService(new FileExporter());
ReportService testService = new ReportService(new InMemoryExporter());
```

**적용 설명:** 생성 결정을 호출자에게 넘겨 환경별 구현을 바꾼다. 프레임워크가 없어도 적용할 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스 내부에서 외부 클라이언트를 생성한다.
  - **판단 기준:** 구현 선택을 조립 지점으로 옮길 수 있다.

- [ ] **상황:** 생성자를 통해 임의 객체를 모두 노출한다.
  - **판단 기준:** 필수 역할만 의존성으로 받는다.
