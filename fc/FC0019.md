## 검토 질문

- [ ] 날짜·시간 등 반복되는 출력 형식을 공통 설정으로 통일할 수 있으며 개별 예외도 명시할 수 있는가?

**직접 작성한 예시**

```java
DateTimeFormatter clockFormat = DateTimeFormatter.ofPattern("HH:mm");
String rendered = time.format(clockFormat);
```

**적용 설명:** 시간 출력 규약을 공통화하는 최소 예시다. JSON 직렬화에 적용하려면 사용하는 직렬화기의 공통 설정에도 연결해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 시간 출력 형식이 필드마다 달라진다.
  - **판단 기준:** 기본 직렬화 정책을 공통 설정으로 모은다.

- [ ] **상황:** 외부 계약 하나가 다른 형식을 요구한다.
  - **판단 기준:** 공통 규칙을 깨기보다 해당 경계에 예외를 둔다.
