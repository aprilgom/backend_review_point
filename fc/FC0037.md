# FC0037 · 반복 화면 요소의 고유 식별자

[소속 분야: 접근성·의미론](../02-accessibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0036](FC0036.md) · [다음 FC: FC0041 →](FC0041.md)

## 검토 질문

- [ ] 반복 렌더링되는 요소의 id가 문서 전체에서 고유하고 레이블 연결도 정확한가?

**직접 작성한 예시**

```html
<label for="item-17">수량</label>
<input id="item-17" name="quantity">
<label for="item-18">수량</label>
<input id="item-18" name="quantity">
```

**적용 설명:** 반복 렌더링되는 항목에서도 id는 문서 전체에서 고유해야 한다. label과의 연결을 함께 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** 반복 요소가 같은 HTML id를 사용한다.
  - **판단 기준:** 문서 전체에서 고유한 식별자를 만든다.

- [ ] **상황:** 레이블이 다른 입력에 연결된다.
  - **판단 기준:** 식별자 생성과 연결 참조를 함께 검증한다.
