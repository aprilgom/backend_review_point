# FC0134 · 객체 참조와 식별자 참조

## 검토 질문

- [ ] 다른 객체의 동작이 필요한지 식별만 필요한지에 따라 연관관계 표현을 선택했는가?

**직접 작성한 예시**

```java
record Purchase(CustomerId customerId, List<Line> lines) {}
```

**적용 설명:** 다른 집합의 식별자만 보유하는 모델 예시다. 즉시 동작 협력이 필요한 객체라면 직접 참조가 더 자연스러울 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 다른 집합의 객체 전체를 보유한다.
  - **판단 기준:** 필요한 동작 협력이 있는지 확인한다.

- [ ] **상황:** ID만 남긴 뒤 외부 조회가 과도해진다.
  - **판단 기준:** 결합도 감소와 조회 비용을 함께 비교한다.
