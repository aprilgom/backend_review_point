## 검토 질문

- [ ] 컨트롤러의 입출력 처리와 업무 규칙·흐름 조율을 분리해 변경 이유가 섞이지 않게 했는가?

**직접 작성한 예시**

```java
CreateLineCommand command = toCommand(request);
LineReply reply = lineService.create(command);
return created(reply);
```

**적용 설명:** 컨트롤러는 입출력 변환을 담당하고 업무 흐름은 서비스로 위임한다. 단순 전달 계층만 늘리는지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 컨트롤러에 계산·저장 절차가 집중된다.
  - **판단 기준:** 입출력과 유스케이스 조율을 분리한다.

- [ ] **상황:** 서비스를 만들었지만 단순 전달만 한다.
  - **판단 기준:** 실제 변경 이유와 책임이 분리됐는지 본다.
