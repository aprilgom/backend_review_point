# FC0220 · 선언형 검증의 실행 경로

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0217](FC0217.md) · [다음 FC: FC0221 →](FC0221.md)

## 검토 질문

- [ ] 검증 애너테이션뿐 아니라 실제 검증이 실행되는 경로·시점·오류 변환까지 확인했는가?

**직접 작성한 예시**

```java
record CreateLabel(@jakarta.validation.constraints.NotBlank String name) {}
var violations = validator.validate(new CreateLabel(""));
assertFalse(violations.isEmpty());
```

**적용 설명:** Spring 전용 API 대신 표준 Bean Validation 호출로 예시를 작성했다. 애너테이션만 붙이고 검증을 실행하지 않으면 동작하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 검증 애너테이션만 붙이고 실행하지 않는다.
  - **판단 기준:** 실제 검증 경로와 실패 변환을 확인한다.

- [ ] **상황:** 검증 그룹에 따라 일부 제약이 빠진다.
  - **판단 기준:** 사용 경계에서 적용되는 그룹을 검증한다.
