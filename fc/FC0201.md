# FC0201 · API 문서화 방식의 선택

## 검토 질문

- [ ] 명세 중심과 테스트 기반 문서화를 사용자·동기화 비용·계약 검증 요구에 맞게 비교했는가?

**직접 작성한 예시**

```yaml
openapi: 3.0.3
info: {title: Sample API, version: "1"}
paths:
  /health:
    get:
      responses:
        '200': {description: Service is ready}
```

**적용 설명:** API 명세 조각이다. 명세 중심 문서와 테스트에서 생성하는 문서를 동기화 비용·사용자·검증 방식으로 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 문서 도구를 익숙함만으로 선택한다.
  - **판단 기준:** 사용자·계약 검증·동기화 비용을 비교한다.

- [ ] **상황:** 문서와 실제 응답이 달라진다.
  - **판단 기준:** 변경 시 함께 검증되는 절차를 마련한다.
