# FC0094 · 불필요한 설정 파일과 키

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0091](FC0091.md) · [다음 FC: FC0090 →](FC0090.md)

## 검토 질문

- [ ] 설정 파일과 키에 실제 사용처가 있으며 비어 있거나 무의미한 구성이 혼란을 주지 않는가?

**직접 작성한 예시**

```properties
# 빈 설정 파일 대신 필요한 키와 기본값만 문서화한 예
app.worker-count=4
```

**적용 설명:** 이 키를 실제로 읽는 구성 코드가 있을 때만 둔다. 용도 없는 빈 파일은 제거하거나 존재 이유를 설명한다.

## 구체적인 검토 사례

- [ ] **상황:** 빈 설정 파일이 목적 없이 남아 있다.
  - **판단 기준:** 필요한 기본값·사용처가 있는지 확인한다.

- [ ] **상황:** 읽지 않는 키에 설명을 추가한다.
  - **판단 기준:** 설명보다 실제 소비 코드와 계약을 먼저 확인한다.
