# FC0094 · 불필요한 설정 파일과 키

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0091](FC0091.md) · [다음 FC: FC0090 →](FC0090.md)

## 검토 질문

- [ ] 설정 파일과 키에 실제 사용처가 있으며 비어 있거나 무의미한 구성이 혼란을 주지 않는가?

**직접 작성한 예시**

```properties
# 빈 설정 파일 대신 필요한 키와 기본값만 문서화한 예
app.worker-count=4
```

**적용 설명:** 이 키를 실제로 읽는 구성 코드가 있을 때만 둔다. 용도 없는 빈 파일은 제거하거나 존재 이유를 설명한다.

## 구체적인 검토 사례

- [ ] 내용이 없는 application.properties 파일이 추가되어 있음을 지적했다. (관찰)
  - 조건: 빈 파일의 존재를 지적했으며, 이로 인한 동작 오류나 구체적인 처리 방법은 설명하지 않았다.

- [ ] Flyway 파일 전체를 주석 처리한 이유가 스키마 변경 때문인지 묻고, 그렇다면 Flyway로 스키마 변경을 수행해 보도록 제안한다. (조건부 제안)
  - 조건: 스키마 변경이 주석 처리의 이유라는 가정 아래 제안한 것으로, 실제 이유는 작성자의 답변으로 확인되지 않았다. 후속 리뷰에서 리뷰 참여자는 Flyway 반영을 확인했다고 밝혔지만 구체적인 변경 내용이나 검증 결과는 제공하지 않았다.

- [ ] 정적 리소스에 추가된 pki-validation 파일의 용도를 확인한다. (설계 질문)
  - 조건: 작성자는 HTTPS 적용을 위해 SSL 인증서를 발급받는 과정의 인증 파일이며 현재는 필요 없어졌다고 설명했다. GitHub에 올리지 않는 것이 맞다는 판단도 작성자의 설명이며, 리뷰 참여자가 비밀 유출을 지적하거나 파일 제거를 직접 요구한 것은 아니다.
