# FC0153 · 재사용 모듈의 의존 방향

[소속 분야: 의존성·교체 가능성](../09-dependency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0151](FC0151.md) · [다음 FC: FC0150 →](FC0150.md)

## 검토 질문

- [ ] 공통 모듈이 애플리케이션 구체 타입을 참조하지 않고 바깥에서 구현을 공급받는가?

**직접 작성한 예시**

```java
package framework;
public interface HandlerRegistry { Object find(String path); }
// app이 구현체를 공급하고 framework는 app 패키지를 import하지 않는다.
```

**적용 설명:** 재사용 모듈이 애플리케이션 구체 타입을 참조하지 않는 방향이다.

## 구체적인 검토 사례

- [ ] **상황:** 공통 모듈이 앱의 구체 구현을 import한다.
  - **판단 기준:** 공통 계약을 두고 앱이 구현을 공급하게 한다.

- [ ] **상황:** 패키지만 옮기고 의존은 그대로 남는다.
  - **판단 기준:** 실제 참조 방향을 다시 확인한다.
