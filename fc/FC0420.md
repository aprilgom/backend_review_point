# FC0420 · 필수 연관 데이터의 부재 테스트

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0418](FC0418.md) · [다음 FC: FC0419 →](FC0419.md)

## 검토 질문

- [ ] 필수 참조 대상이 없을 때 의도한 오류와 후속 저장·외부 호출의 미실행을 검증하는가?

**직접 작성한 예시**

```java
assertThrows(TableNotFound.class, () -> orderService.place(missingTableId, lines));
assertEquals(0, orders.count());
```

**적용 설명:** 필수 연관 객체가 없을 때의 실패와 저장되지 않는 결과를 검증한다.

## 구체적인 검토 사례

- [ ] 주문에 지정된 주문 테이블을 찾을 수 없을 때 예외가 발생하는 경우도 테스트하자는 제안이다. (개선 제안)
  - 조건: 리뷰 참여자가 findById 결과 부재 시 예외를 던지는 코드를 추가 테스트 대상으로 제시했다. 작성자는 추가 테스트를 2단계에서 반영하겠다고 답했다.

- [ ] 주문 생성 시 주문 테이블이 empty인 경우 예외가 발생하는 테스트도 필요하다고 제안했다. (개선 제안)
  - 조건: README의 주문 생성 요구사항에 달린 의견이다. 테스트 추가 여부나 실제 예외 동작은 제공된 대화에서 확인되지 않는다.

- [ ] 주문 테이블의 주문이 조리 중이거나 식사 중일 때 예외가 발생하는 테스트 케이스를 추가하자고 제안했다. (개선 제안)
  - 조건: 작성자는 해당 예외들이 대부분 DAO 메서드 검증을 필요로 해 누락했다고 설명했다. 이후 2단계에서 Repository를 사용하면서 서비스에서 검증 가능한 경우를 추가했다고 보고했으며, 실제 변경 내용은 이 대화만으로 확인되지 않는다.
