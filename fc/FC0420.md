# FC0420 · 필수 연관 데이터의 부재 테스트

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0418](FC0418.md) · [다음 FC: FC0419 →](FC0419.md)

## 검토 질문

- [ ] 필수 참조 대상이 없을 때 의도한 오류와 후속 저장·외부 호출의 미실행을 검증하는가?

**직접 작성한 예시**

```java
assertThrows(TableNotFound.class, () -> orderService.place(missingTableId, lines));
assertEquals(0, orders.count());
```

**적용 설명:** 필수 연관 객체가 없을 때의 실패와 저장되지 않는 결과를 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** 필수 참조 대상이 항상 존재하도록 준비한다.
  - **판단 기준:** 부재 오류와 저장 미실행을 확인한다.

- [ ] **상황:** 부재를 null 접근 예외로 처리한다.
  - **판단 기준:** 업무 실패 계약을 명시한다.
