# FC0257 · 화면에서 사용할 gameId는 숨겨진 태그보다 자바스크립트 변수로 보관하는 편을 제안한다.

[소속 분야: 프론트엔드 상태](../14-frontend-state.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0258](FC0258.md)

- [ ] 화면에서 사용할 gameId는 숨겨진 태그보다 자바스크립트 변수로 보관하는 편을 제안한다. (개선 제안)
  - 조건: 작성자가 모델로 전달한 값을 핸들바의 숨겨진 div에 보관하는 구현에 대해 대안을 묻자, 리뷰어가 자바스크립트 변수를 선호한다고 답했다. 구체적인 전달 코드나 변경 결과는 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```javascript
const gameId = pageData.gameId;
startGame(gameId);
```

**적용 설명:** DOM에 숨긴 태그 대신 상태로 보관하는 예시다. 클라이언트 값은 신뢰할 수 없으므로 서버에서 권한을 확인한다.
