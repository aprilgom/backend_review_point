# FC0257 · 화면 상태의 저장 위치

[소속 분야: 프론트엔드 상태](../14-frontend-state.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0258](FC0258.md)

## 검토 질문

- [ ] 화면에서 사용할 상태를 불필요한 숨은 DOM 대신 적절한 상태 변수에 보관하고 서버에서 신뢰하지 않는가?

**직접 작성한 예시**

```javascript
const gameId = pageData.gameId;
startGame(gameId);
```

**적용 설명:** DOM에 숨긴 태그 대신 상태로 보관하는 예시다. 클라이언트 값은 신뢰할 수 없으므로 서버에서 권한을 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 상태를 보관하려고 숨은 DOM을 만든다.
  - **판단 기준:** 상태 변수나 모델로 관리할 수 있는지 본다.

- [ ] **상황:** 클라이언트 ID를 권한 증거로 사용한다.
  - **판단 기준:** 서버에서 소유·접근 권한을 다시 확인한다.
