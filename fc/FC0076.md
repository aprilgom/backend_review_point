# FC0076 · 추가한 JPA 설정 옵션 각각이 무엇을 의미하는지 설명을 요청했다.

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0074](FC0074.md) · [다음 FC: FC0089 →](FC0089.md)

**혼합·경계:** JPA·Hibernate 옵션과 Spring 설정이 섞임.

- [ ] 추가한 JPA 설정 옵션 각각이 무엇을 의미하는지 설명을 요청했다. (설계 질문)
  - 조건: 작성자는 show-sql, format_sql, ddl-auto의 create, defer-datasource-initialization의 의미와 설정 이유를 설명했다. 이는 작성자의 설명이며 설정의 기술적 타당성에 대한 후속 확인은 없다.

- [ ] 추가한 JPA 설정 옵션이 어떤 기능을 하는지 설명해 달라고 질문했다. (설계 질문)
  - 조건: 작성자는 SQL 출력·포맷 설정의 역할과 ddl-auto의 각 선택지를 설명하고, 로컬 테스트·개발 환경에서 스키마가 자주 바뀌므로 create-drop을 명시했다고 답했다. 옵션의 기본값과 동작에 관한 설명은 작성자의 설명이며, 리뷰어가 그 정확성을 확인하거나 설정 변경을 요구한 후속 발언은 없다.

- [ ] application.properties에 추가한 설정 옵션이 어떤 기능을 하는지 설명을 요청했다. (설계 질문)
  - 조건: 리뷰어는 해당 옵션의 기능을 질문했으며 설정 오류를 지적하지는 않았다. 작성자는 데이터베이스 연결 URL, SQL 출력 및 포맷팅, ddl-auto의 각 모드에 관해 설명했다. 이 답변만으로 설정 키의 유효성이나 실제 적용 결과가 검증된 것은 아니다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```properties
hibernate.show_sql=false
hibernate.format_sql=true
```

**적용 설명:** SQL 출력 여부와 포맷 옵션은 별개다. 각 설정의 소비 주체·기본값·환경별 효과를 확인하며 포맷 설정만으로 로그가 출력되지는 않는다.
