# FC0054 · 요청 본문과 미디어 타입의 일치

## 검토 질문

- [ ] 요청의 인코딩 방식·파싱 방식·Content-Type이 서로 일치하는가?

**직접 작성한 예시**

```http
POST /labels HTTP/1.1
Content-Type: application/x-www-form-urlencoded

name=study&color=blue
```

**적용 설명:** 폼 인코딩 본문에 맞춘 헤더 예시다. JSON 본문을 받는 계약이라면 JSON 헤더와 파서를 함께 사용한다.

## 구체적인 검토 사례

- [ ] **상황:** 폼 본문을 JSON으로 선언한다.
  - **판단 기준:** 인코딩·파서·미디어 타입을 일치시킨다.

- [ ] **상황:** 헤더만 바꾸고 본문 형식은 그대로 둔다.
  - **판단 기준:** 실제 전송 바이트와 수신 계약을 함께 수정한다.
