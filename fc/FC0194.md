# FC0194 · 우선 스프링의 다양한 기능을 활용하고, 궁금한 기능이 생기면 코드를 따라가며 학습하는 방식을 제안했다.

[소속 분야: 문서·개발·학습 과정](../10-workflow.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0193 →](FC0193.md)

**혼합·경계:** Spring 학습 외에 프레임워크 탐색·학습 범위 조절이 포함됨.

- [ ] 우선 스프링의 다양한 기능을 활용하고, 궁금한 기능이 생기면 코드를 따라가며 학습하는 방식을 제안했다. (개선 제안)
  - 조건: 스프링의 학습 범위가 방대하다는 점을 고려한 제안이다. 『토비의 스프링』은 유명하지만 어렵기 때문에 선뜻 추천하기는 어렵다고 덧붙였으며, 필독을 요구하지 않았다.

- [ ] 익숙하지 않은 프레임워크나 라이브러리를 사용할 때 내부 메서드 구현을 따라가며 참고하는 학습 방법을 제안했다. (개선 제안)
  - 조건: JdbcTemplate에서 DataAccessUtils를 사용하는 부분을 찾아보는 과정을 예로 들었다. 별도의 필수 과제로 요구한 것은 아니다.

- [ ] 이번 단계에서는 인증·인가의 개념과 구현을 위한 학습에 집중하고, 반드시 알아야 한다고 판단한 키워드부터 학습하도록 범위를 안내했다. (학습 제약)
  - 조건: 이번에 마치지 못한 학습은 다음 미션에서 이어가도 된다고 명시했다. 관련 내용을 모두 이번 단계에서 완수해야 한다는 요구는 아니다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
assertEquals(List.of("before", "handler", "after"), observedCalls);
```

**적용 설명:** 궁금한 프레임워크 동작을 작은 관측 테스트로 좁히는 예시다. 이 순서는 가정이므로 사용 환경의 실제 결과와 비교한다.
