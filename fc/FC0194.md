# FC0194 · 작은 실험을 통한 기술 학습

## 검토 질문

- [ ] 궁금한 라이브러리 동작을 좁은 관측 테스트로 검증하고 내부 구현과 연결해 설명할 수 있는가?

**직접 작성한 예시**

```java
assertEquals(List.of("before", "handler", "after"), observedCalls);
```

**적용 설명:** 궁금한 프레임워크 동작을 작은 관측 테스트로 좁히는 예시다. 이 순서는 가정이므로 사용 환경의 실제 결과와 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 라이브러리 동작을 추측으로 설명한다.
  - **판단 기준:** 작은 관측 테스트로 가정을 확인한다.

- [ ] **상황:** 많은 내부 코드를 한 번에 읽는다.
  - **판단 기준:** 질문 하나의 실행 경로부터 좁혀 따라간다.
