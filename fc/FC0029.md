# FC0029 · 보조 생성자의 위임과 기본값

[소속 분야: 추상화·중복](../01-abstraction.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0030](FC0030.md) · [다음 FC: FC0031 →](FC0031.md)

## 검토 질문

- [ ] 기본값을 제공하는 생성자도 주 생성자의 검증·초기화 규칙을 일관되게 사용하는가?

**직접 작성한 예시**

```java
Reservation(LocalDate day) { this(day, LocalTime.NOON); }
Reservation(LocalDate day, LocalTime time) {
    this.day = Objects.requireNonNull(day);
    this.time = Objects.requireNonNull(time);
}
```

**적용 설명:** 기본 시간을 제공하는 생성자도 같은 초기화 경로를 사용한다. 기본값 자체가 요구사항에 맞는지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 보조 생성자가 주 생성자의 검증을 빠뜨린다.
  - **판단 기준:** 기본값만 정하고 주 생성자에 위임한다.

- [ ] **상황:** 편의 생성자가 임의의 업무 기본값을 넣는다.
  - **판단 기준:** 호출자가 그 기본값을 선택해도 되는지 검토한다.
