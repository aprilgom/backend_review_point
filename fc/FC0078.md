# FC0078 · 모듈별 build.gradle 설정에 불필요한 의존성이 포함되어 있지 않은지 검토하도록 질문한다.

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0083 →](FC0083.md)

- [ ] 모듈별 build.gradle 설정에 불필요한 의존성이 포함되어 있지 않은지 검토하도록 질문한다. (설계 질문)
  - 조건: 특정 의존성을 불필요하다고 지목하거나 결함으로 확정하지 않았으며, 머지를 막는 요구가 아닌 검토 질문으로 제시했다.

- [ ] 다른 모듈의 의존성은 루트 build.gradle에서 설정하면서 app 모듈만 자체 build.gradle에서 설정한 이유를 질문했다. (설계 질문)
  - 조건: 모듈별 의존성 설정 위치가 다른 이유를 확인하려는 질문이다. 설정 위치를 통일하라는 명시적인 요구나 작성자 답변은 없다.

- [ ] 루트 build.gradle에 작성한 의존성 설정을 각 모듈의 build.gradle에 둘 수도 있다는 방법을 알고 있는지 질문했다. (설계 질문)
  - 조건: 모듈별 의존성 선언이라는 대안을 소개하는 질문이며, 반드시 옮기라는 요구나 현재 방식의 결함 확정은 아니다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```kotlin
dependencies {
    implementation(project(":domain"))
    testImplementation(libs.junit.jupiter)
}
```

**적용 설명:** 버전 카탈로그가 있는 Gradle Kotlin DSL 예시다. domain에 웹 의존성을 끌어들이는 등 모듈 경계를 깨는 의존성은 검토한다.
