## 검토 질문

- [ ] 컬렉션 원소마다 조회하는 대신 필요한 데이터를 일괄 조회하고 부재·순서·크기 제한을 처리하는가?

**직접 작성한 예시**

```java
Map<ProductId, Product> productsById = products.findAllByIds(ids).stream()
    .collect(Collectors.toMap(Product::id, Function.identity()));
```

**적용 설명:** 여러 상품을 일괄 조회한다. 부재 ID·중복 요청·파라미터 개수 제한을 처리한다.

## 구체적인 검토 사례

- [ ] **상황:** 목록 원소마다 연관 데이터를 조회한다.
  - **판단 기준:** ID를 모아 일괄 조회할 수 있다.

- [ ] **상황:** 반환 순서를 입력 순서로 가정한다.
  - **판단 기준:** ID 매핑·부재·중복 정책을 명시한다.
