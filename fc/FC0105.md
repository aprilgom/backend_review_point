# FC0105 · 스레드별 컨텍스트의 수명

## 검토 질문

- [ ] 스레드 로컬 상태를 작업 종료 시 정리하고 풀 재사용·비동기 경계에서 누출되지 않게 하는가?

**직접 작성한 예시**

```java
try {
    requestContext.set(actor);
    process();
} finally { requestContext.remove(); }
```

**적용 설명:** ThreadLocal을 사용하는 스레드 풀에서는 작업 종료 시 제거한다. 다른 스레드·비동기 작업으로 값이 자동 전달된다고 가정하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 스레드 풀 작업에 컨텍스트를 저장한다.
  - **판단 기준:** 종료·실패 모두에서 값을 정리한다.

- [ ] **상황:** 비동기 작업으로 실행이 이동한다.
  - **판단 기준:** 컨텍스트가 자동 전달된다고 가정하지 않는다.
