## 검토 질문

- [ ] 조회 메서드 이름에서 반환 대상과 수행 동작을 명확히 알 수 있는가?

**직접 작성한 예시**

```java
List<BookingReply> getBookings() { return bookings.list(); }
```

**적용 설명:** 조회 대상과 동작을 드러낸 메서드 이름이다.

## 구체적인 검토 사례

- [ ] **상황:** 조회 메서드 이름이 대상 없이 일반적이다.
  - **판단 기준:** 무엇을 조회하는지 드러낸다.

- [ ] **상황:** 이름은 전체 조회인데 필터가 숨어 있다.
  - **판단 기준:** 반환 범위와 조건도 알 수 있게 한다.
