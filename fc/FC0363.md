# FC0363 · 서비스 경계의 입력·출력 모델

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0360](FC0360.md) · [다음 FC: FC0356 →](FC0356.md)

## 검토 질문

- [ ] 서비스가 요청·응답 DTO를 직접 사용할지 별도 계약을 둘지 결합도와 변환 비용으로 판단했는가?

**직접 작성한 예시**

```java
CreateTaskResult result = tasks.create(new CreateTaskCommand(input.title()));
return new TaskReply(result.id(), result.title());
```

**적용 설명:** 서비스용 계약과 HTTP 응답 계약을 나눈 대안이다. 작은 앱에서 DTO 계층을 늘리는 비용도 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스가 HTTP 요청 DTO를 직접 받는다.
  - **판단 기준:** 전송 계층 결합과 변환 비용을 비교한다.

- [ ] **상황:** 계층마다 같은 DTO를 다시 감싼다.
  - **판단 기준:** 독립 계약이 필요한지 확인한다.
