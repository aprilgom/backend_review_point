# FC0203 · 식별자만 필요한 객체의 표현

[소속 분야: 도메인 모델·값 표현](../11-domain-model.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0205 →](FC0205.md)

## 검토 질문

- [ ] 식별자만 필요할 때 나머지 필드가 비어 있는 객체 대신 적절한 ID 타입을 사용하는가?

**직접 작성한 예시**

```java
record CustomerId(long value) {}
void assignOwner(CustomerId id) { this.ownerId = id; }
```

**적용 설명:** 식별자만 필요하면 나머지가 null인 가짜 Customer 대신 ID 타입을 받는다.

## 구체적인 검토 사례

- [ ] **상황:** ID만 넣고 나머지가 null인 객체를 만든다.
  - **판단 기준:** 식별자 타입만 전달해도 되는지 확인한다.

- [ ] **상황:** 불완전한 객체가 정상 로직에 들어간다.
  - **판단 기준:** 유효 상태와 참조 표현을 구별한다.
