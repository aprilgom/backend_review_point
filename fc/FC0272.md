## 검토 질문

- [ ] 느린 조회를 실제 데이터와 실행 계획으로 분석해 인덱스·스캔·정렬 비용을 구분하는가?

**직접 작성한 예시**

```sql
EXPLAIN SELECT COUNT(*) FROM waiting
WHERE slot_id = :slot AND created_at < :created_at;
```

**적용 설명:** 실제 데이터 분포로 실행 계획·인덱스·조회 건수를 확인한다. DB별 EXPLAIN 구문과 실행 여부는 구별한다.

## 구체적인 검토 사례

- [ ] **상황:** 느린 쿼리에 인덱스를 무작정 추가한다.
  - **판단 기준:** 실행 계획으로 스캔·정렬·선택도를 확인한다.

- [ ] **상황:** 개발의 소량 데이터로만 비교한다.
  - **판단 기준:** 실제 분포와 충분한 규모를 사용한다.
