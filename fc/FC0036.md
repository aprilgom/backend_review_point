# FC0036 · 문서 언어의 명시

[소속 분야: 접근성·의미론](../02-accessibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0037 →](FC0037.md)

## 검토 질문

- [ ] HTML 문서와 부분 콘텐츠의 언어가 실제 내용에 맞게 지정되어 있는가?

**직접 작성한 예시**

```html
<html lang="ko">
  <head><title>작업 목록</title></head>
  <body>오늘의 작업</body>
</html>
```

**적용 설명:** 주 언어를 문서에 표시한다. 다른 언어로 된 일부 문구에는 해당 요소의 lang을 별도 지정할 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 문서 언어 설정이 실제 콘텐츠와 다르다.
  - **판단 기준:** 보조 기술이 사용할 언어 정보를 맞춘다.

- [ ] **상황:** 일부 문구만 다른 언어로 표시된다.
  - **판단 기준:** 전체 언어와 부분 요소 언어를 구분한다.
