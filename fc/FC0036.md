# FC0036 · HTML의 lang 속성에 대해 추가로 학습해 보자는 제안이다.

[소속 분야: 접근성·의미론](../02-accessibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [다음 FC: FC0037 →](FC0037.md)

- [ ] HTML의 lang 속성에 대해 추가로 학습해 보자는 제안이다. (개선 제안)
  - 조건: 참여자는 미션 진행에 중요한 사항은 아니라고 명시하고 참고 링크를 제공했다. 특정 속성값으로 변경하라는 요구나 링크 본문에만 있는 설명은 추출하지 않았다.

- [ ] HTML의 lang="kr" 대신 ISO 언어 코드 기준으로 ko를 사용해야 하지 않는지 묻는다. (설계 질문)
  - 조건: 작성자는 수정했다고 답했다. 실제 변경 내용은 답변 외에는 확인되지 않는다.

- [ ] HTML의 주언어 속성을 lang="en"이 아니라 lang="ko"로 설정해야 한다고 지적했다. (문제 보고)
  - 조건: 주언어 선언에 관한 접근성 참고 링크를 함께 제시했다. 링크의 추가 내용이나 실제 수정 여부는 확인하지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```html
<html lang="ko">
  <head><title>작업 목록</title></head>
  <body>오늘의 작업</body>
</html>
```

**적용 설명:** 주 언어를 문서에 표시한다. 다른 언어로 된 일부 문구에는 해당 요소의 lang을 별도 지정할 수 있다.
