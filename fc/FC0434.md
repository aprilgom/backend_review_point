# FC0434 · 테스트 데이터 초기화의 비용과 영향

## 검토 질문

- [ ] 매번 스키마를 재생성하는 대신 데이터 정리로 충분한지와 외래 키·시퀀스·병렬 실행 영향을 검토했는가?

**직접 작성한 예시**

```sql
-- 격리된 테스트 DB 전용
TRUNCATE TABLE test_event;
```

**적용 설명:** DDL 재생성 대신 데이터 초기화하는 예다. DB별 트랜잭션·외래 키·시퀀스·병렬 테스트 영향을 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 매 테스트마다 테이블을 재생성한다.
  - **판단 기준:** 데이터 초기화만으로 충분한지 비교한다.

- [ ] **상황:** TRUNCATE가 항상 롤백된다고 본다.
  - **판단 기준:** DB별 트랜잭션·외래 키·시퀀스 영향을 확인한다.
