# FC0128 · 정렬 기준과 순번의 의미

[소속 분야: 쿼리·데이터 조작](../07-data-query.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0127](FC0127.md)

## 검토 질문

- [ ] ID·생성 시각·커밋 순서가 같은 의미라고 가정하지 않고 업무상 순서와 동률 처리를 정의했는가?

**직접 작성한 예시**

```sql
SELECT id, ROW_NUMBER() OVER (ORDER BY created_at, id) AS queue_position
FROM waiting WHERE slot_id = :slot;
```

**적용 설명:** 동일 시각의 순서를 ID로 보완한다. 자동 증가 ID만으로 커밋 순서나 실제 접수 순서가 보장되지는 않는다.

## 구체적인 검토 사례

- [ ] **상황:** ID 순서를 접수 완료 순서로 간주한다.
  - **판단 기준:** 발급·생성·커밋 순서의 차이를 검토한다.

- [ ] **상황:** 같은 시각의 데이터 순서가 흔들린다.
  - **판단 기준:** 안정적인 보조 정렬 기준을 둔다.
