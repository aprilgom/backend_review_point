# FC0159 · SQL 값 바인딩의 콜백 표현

[소속 분야: 의존성·교체 가능성](../09-dependency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0168](FC0168.md) · [다음 FC: FC0161 →](FC0161.md)

## 검토 질문

- [ ] 쿼리 실행 절차와 파라미터 설정을 분리하면서 타입과 예외 계약을 유지하는가?

**직접 작성한 예시**

```java
StatementBinder values = ps -> {
    ps.setString(1, title);
    ps.setLong(2, ownerId);
};
```

**적용 설명:** SQLException을 허용하는 자체 함수형 계약으로 SQL 값 바인딩을 전달한다. 문자열 연결로 SQL을 만들지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** SQL 실행과 값 설정이 한 덩어리다.
  - **판단 기준:** 바인딩을 콜백으로 전달해 재사용할 수 있다.

- [ ] **상황:** 콜백이 연결을 닫거나 커밋한다.
  - **판단 기준:** 콜백과 실행기의 자원 책임을 명시한다.
