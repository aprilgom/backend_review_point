# FC0470 · 상태 전이 결과의 즉시 피드백

## 검토 질문

- [ ] 완료·종료 상태가 된 직후 추가 조작 없이 결과를 보여 주고 이후 잘못된 행동을 제한하는가?

**직접 작성한 예시**

```javascript
const result = await submitMove(move);
renderBoard(result.board);
if (result.finished) showWinner(result.winner);
```

**적용 설명:** 이번 응답에서 종료 상태를 바로 표시한다. 서버도 종료 이후 추가 수를 거절해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 작업 종료를 다음 조작 때 보여 준다.
  - **판단 기준:** 현재 응답에서 완료 상태를 표시한다.

- [ ] **상황:** 화면만 막고 서버는 추가 변경을 허용한다.
  - **판단 기준:** 종료 상태의 서버 규칙도 보장한다.
