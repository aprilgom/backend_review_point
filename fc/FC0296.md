## 검토 질문

- [ ] 이미 얻은 객체를 검증과 생성에 재사용할 수 있으며 최신 상태 재검증이 필요한 경우와 구분하는가?

**직접 작성한 예시**

```java
Product product = products.get(id);
requireAllowedPrice(product.price());
return new MenuItem(product, quantity);
```

**적용 설명:** 이미 조회한 객체를 검증과 생성에 재사용한다. 최신 상태 재검증이 필요한 경우는 별개다.

## 구체적인 검토 사례

- [ ] **상황:** 이미 조회한 객체를 검증 중 다시 조회한다.
  - **판단 기준:** 같은 스냅샷을 재사용할 수 있다.

- [ ] **상황:** 최신 상태가 필요한데 오래된 값을 쓴다.
  - **판단 기준:** 재조회가 필요한 업무 경계를 구분한다.
