# FC0435 · 공통 테스트 준비의 배치

## 검토 질문

- [ ] 모든 테스트에 필요한 준비만 공통 수명 메서드에 두고 시나리오의 중요한 차이는 드러내는가?

**직접 작성한 예시**

```java
@BeforeEach void prepare() {
    repository = new MemoryRepository();
}
```

**적용 설명:** 모든 테스트에 필요한 공통 준비만 둔다. 특정 시나리오의 중요한 준비 조건은 테스트 안에 남긴다.

## 구체적인 검토 사례

- [ ] **상황:** 공통 준비에 모든 시나리오 데이터를 넣는다.
  - **판단 기준:** 모두 필요한 조건만 수명 메서드에 둔다.

- [ ] **상황:** 비슷한 테스트마다 준비 위치가 다르다.
  - **판단 기준:** 의도와 실행 순서를 일관되게 표현한다.
