# FC0396 · Line이 의도한 대로 동작하는지 확인할 테스트를 더 추가하자는 제안이다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0404](FC0404.md) · [다음 FC: FC0402 →](FC0402.md)

- [ ] Line이 의도한 대로 동작하는지 확인할 테스트를 더 추가하자는 제안이다. (개선 제안)
  - 조건: 작성자는 부족했던 기능과 예외 상황에 대한 테스트를 추가했다고 보고했다. 추가된 테스트의 구체적인 내용이나 충분성은 대화에서 확인되지 않는다.

- [ ] 기존 테스트 외에 더 다양한 테스트를 작성하는 방안을 제안했다. (개선 제안)
  - 조건: 기존 테스트만으로도 충분할 수 있다고 명시한 선택적 제안이다. 추가로 검증할 구체적인 시나리오는 제시하지 않았다.

- [ ] 매핑 중복 상황의 처리 동작을 확인하는 테스트를 추가하도록 제안했다. (개선 제안)
  - 조건: 중복 데이터 처리에 관한 질문에 부수된 테스트 제안이다. 작성자는 생성 시 컬렉션이 비어 있다는 구조적 설명과 리팩터링을 보고했지만, 해당 테스트를 추가했다고 명시하지는 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
Line line = new Line(stationA, stationB);
line.extend(stationC);
assertEquals(List.of(stationA, stationB, stationC), line.stations());
```

**적용 설명:** 도메인 동작의 결과를 검증한다. 중복 역·연결 불가능한 연장도 추가 시나리오다.
