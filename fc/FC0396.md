# FC0396 · 도메인 행동의 결과 검증

## 검토 질문

- [ ] 도메인 메서드가 의도한 상태 변화·불변식을 유지하는지 정상·비정상 사례로 확인하는가?

**직접 작성한 예시**

```java
Line line = new Line(stationA, stationB);
line.extend(stationC);
assertEquals(List.of(stationA, stationB, stationC), line.stations());
```

**적용 설명:** 도메인 동작의 결과를 검증한다. 중복 역·연결 불가능한 연장도 추가 시나리오다.

## 구체적인 검토 사례

- [ ] **상황:** 도메인 변경의 결과를 검증하지 않는다.
  - **판단 기준:** 상태와 불변식을 직접 확인한다.

- [ ] **상황:** 하나의 정상 입력만 사용한다.
  - **판단 기준:** 중복·부재·경계 상황을 추가 검토한다.
