# FC0130 · 업무 흐름에 맞는 관계의 다중성

## 검토 질문

- [ ] 일대일·일대다 같은 관계가 실제로 가능한 업무 사례와 제약을 반영하는가?

**직접 작성한 예시**

```sql
CREATE TABLE reply (
  id BIGINT PRIMARY KEY,
  question_id BIGINT NOT NULL REFERENCES question(id)
);
```

**적용 설명:** 질문당 여러 답변을 허용한 모델이다. 하나만 허용한다면 question_id에 UNIQUE가 필요한지 요구사항으로 판단한다.

## 구체적인 검토 사례

- [ ] **상황:** 일대일 관계로 만들었지만 여러 연결이 가능하다.
  - **판단 기준:** 실제 업무 흐름에 맞게 다중성을 정한다.

- [ ] **상황:** 일대일 규칙을 코드에서만 가정한다.
  - **판단 기준:** DB 제약으로도 보장해야 하는지 확인한다.
