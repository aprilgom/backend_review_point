# FC0024 · 중복된 값 표현의 통합

## 검토 질문

- [ ] 서로 다른 타입이 실제로 같은 값과 책임을 표현한다면 하나로 합칠 수 있는가?

**직접 작성한 예시**

```java
record MediaType(String value) {
    static final MediaType JSON = new MediaType("application/json");
}
```

**적용 설명:** 두 래퍼가 같은 값만 표현한다면 하나로 줄일 수 있다. 파싱 결과와 원문처럼 역할이 다르면 병합하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 두 값 타입이 같은 필드와 동작을 가진다.
  - **판단 기준:** 역할 차이가 없다면 하나로 합칠 수 있다.

- [ ] **상황:** 원문과 파싱 결과를 같은 값으로 취급한다.
  - **판단 기준:** 검증 상태가 다르면 별도 타입이 의미를 가진다.
