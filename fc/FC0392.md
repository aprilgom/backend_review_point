# FC0392 · 인증과 인가의 책임 구분

[소속 분야: 인증·보안·비밀값](../20-security.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0390](FC0390.md)

## 검토 질문

- [ ] 사용자가 누구인지 확인하는 일과 특정 자원 접근을 허용하는 일을 구분해 구현했는가?

**직접 작성한 예시**

```java
Actor actor = authenticate(request);
requireOwner(actor, document);
return document;
```

**적용 설명:** 누구인지 확인하는 인증과 해당 문서 권한을 확인하는 인가를 분리해 이름 붙인다.

## 구체적인 검토 사례

- [ ] **상황:** 사용자 확인과 자원 권한 검사가 한 이름에 숨는다.
  - **판단 기준:** 인증과 인가를 명시적으로 구분한다.

- [ ] **상황:** 인증 성공이면 모든 접근을 허용한다.
  - **판단 기준:** 대상 소유·공유·역할 정책을 확인한다.
