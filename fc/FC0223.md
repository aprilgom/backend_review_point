# FC0223 · 생성 시 보장한 제약의 재검증

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0219](FC0219.md) · [다음 FC: FC0226 →](FC0226.md)

## 검토 질문

- [ ] 이미 유효성이 보장된 불변 값을 받을 때 같은 검증을 반복할 필요가 있으며 외부 상태 의존 검증과 구분하는가?

**직접 작성한 예시**

```java
void changeQuantity(Quantity quantity) {
    this.quantity = Objects.requireNonNull(quantity);
}
```

**적용 설명:** Quantity가 생성 시 양수 조건을 보장하는 불변 값이면 같은 수치 검사를 반복하지 않을 수 있다. 재고 같은 외부 상태 검증은 별개다.

## 구체적인 검토 사례

- [ ] **상황:** 검증된 불변 값을 받을 때 다시 검사한다.
  - **판단 기준:** 생성 계약으로 보장된 조건인지 확인한다.

- [ ] **상황:** 재고 같은 외부 조건도 생략한다.
  - **판단 기준:** 시간·외부 상태에 의존한 규칙은 재확인이 필요하다.
