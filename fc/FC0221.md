# FC0221 · 입력 검증과 도메인 검증의 경계

## 검토 질문

- [ ] 요청 DTO의 형식 검증과 도메인이 항상 지켜야 하는 불변식을 구분하고 모든 진입 경로를 보호하는가?

**직접 작성한 예시**

```java
record Quantity(int value) {
    Quantity { if (value < 1) throw new IllegalArgumentException("quantity"); }
}
```

**적용 설명:** 요청 검증을 거치지 않는 배치·테스트 생성 경로에서도 불변식을 지킨다.

## 구체적인 검토 사례

- [ ] **상황:** 입력 DTO만 검증하고 도메인은 무조건 생성한다.
  - **판단 기준:** 다른 진입 경로에서도 불변식을 보장한다.

- [ ] **상황:** 같은 검증이 여러 계층에서 반복된다.
  - **판단 기준:** 입력 형식과 도메인 제약의 목적을 구분한다.
