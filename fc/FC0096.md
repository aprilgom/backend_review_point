# FC0096 · 시작 배너와 진단 정보의 역할

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0079](FC0079.md)

## 검토 질문

- [ ] 시작 시 출력하는 정보가 운영·식별에 어떤 목적을 가지며 실제 상태 점검과 혼동되지 않는가?

**직접 작성한 예시**

```java
static final String STARTUP_LABEL = "Sample service";
logger.info("Starting {}", STARTUP_LABEL);
```

**적용 설명:** 시작 배너의 역할을 일반 시작 로그로 표현했다. 기능 설정이나 상태 점검을 배너 문자열로 대체하지 않는다.

## 구체적인 검토 사례

- [ ] 변경된 banner.txt 파일의 용도가 무엇인지 질문한다. (설계 질문)
  - 조건: 작성자는 Spring 실행 시 표시되는 배너를 바꾸는 파일이며 소스에는 지장이 없다고 설명했다. 파일 삭제나 기능 결함을 지적한 대화는 아니다.
