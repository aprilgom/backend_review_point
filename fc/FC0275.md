# FC0275 · 리다이렉트의 불필요한 본문 준비

## 검토 질문

- [ ] 클라이언트 이동만 지시하는 응답을 만들면서 대상 파일을 미리 읽는 등 불필요한 작업을 하지 않는가?

**직접 작성한 예시**

```java
return HttpReply.redirect(302, "/not-found");
```

**적용 설명:** 리다이렉트에는 대상 파일 내용을 미리 읽을 필요가 없다. 원 요청 자체에 404를 내려야 하는 계약이라면 직접 404를 반환한다.

## 구체적인 검토 사례

- [ ] **상황:** 이동 응답을 만들며 대상 HTML을 읽는다.
  - **판단 기준:** 이동 지시만 필요하면 본문 준비를 생략한다.

- [ ] **상황:** 오류를 모두 다른 페이지로 이동시킨다.
  - **판단 기준:** 원 요청에 오류 상태를 반환해야 하는지 검토한다.
