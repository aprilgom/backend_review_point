# FC0219 · 구성 값 사이의 관계 검증

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0218](FC0218.md) · [다음 FC: FC0223 →](FC0223.md)

## 검토 질문

- [ ] 개별 값이 유효해도 조합이 잘못될 수 있는 규칙을 객체 생성 경계에서 확인하는가?

**직접 작성한 예시**

```java
record Segment(StationId start, StationId end) {
    Segment { if (Objects.equals(start, end)) throw new SameEndpoint(); }
}
```

**적용 설명:** 서로 다른 양 끝점이라는 규칙을 생성 시 보장한다. null 허용 여부와 이름 대신 ID로 비교할지도 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 구성 값은 각각 유효하지만 조합이 잘못됐다.
  - **판단 기준:** 객체 생성 시 관계 조건도 검사한다.

- [ ] **상황:** 표시 이름이 같으면 같은 대상으로 본다.
  - **판단 기준:** 식별·동등성 기준에 맞게 비교한다.
