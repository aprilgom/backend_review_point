# FC0447 · 인수 테스트의 요청 본문을 Map 대신 LineRequest 객체로 구성할 수 있다고 제안했다.

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0440](FC0440.md) · [다음 FC: FC0443 →](FC0443.md)

- [ ] 인수 테스트의 요청 본문을 Map 대신 LineRequest 객체로 구성할 수 있다고 제안했다. (개선 제안)
  - 조건: 요청 body에 new LineRequest(...)를 전달하는 예시를 제시했다. 기존 Map 방식의 결함을 주장한 것은 아니다.

- [ ] 인수 테스트의 요청 본문을 Map 대신 LineRequest 객체로 구성할 수도 있다고 제안한다. (개선 제안)
  - 조건: 리뷰어는 LineRequest를 생성해 RestAssured의 body에 전달하는 예시를 제시했다. 기존 Map 방식이 잘못되었다고 단정한 지적은 아니다.

- [ ] 인수 테스트의 요청 데이터를 Map으로 구성하는 대신 LineRequest 객체를 직접 사용할 수 있다고 제안했다. (개선 제안)
  - 조건: 원문 맥락 확인

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
CreateLineRequest input = new CreateLineRequest("weekday", "green");
Reply response = client.post("/lines", input);
```

**적용 설명:** 문자열 Map 대신 타입으로 필드 이름·자료형을 맞춘다. 잘못된 입력 계약 테스트에는 일부러 원시 JSON이 필요할 수 있다.
