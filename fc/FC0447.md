# FC0447 · 타입이 있는 테스트 요청 본문

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0440](FC0440.md) · [다음 FC: FC0443 →](FC0443.md)

## 검토 질문

- [ ] 요청 타입을 활용해 필드·자료형 오류를 줄이고 잘못된 입력 검증에는 원시 요청도 별도로 사용하는가?

**직접 작성한 예시**

```java
CreateLineRequest input = new CreateLineRequest("weekday", "green");
Reply response = client.post("/lines", input);
```

**적용 설명:** 문자열 Map 대신 타입으로 필드 이름·자료형을 맞춘다. 잘못된 입력 계약 테스트에는 일부러 원시 JSON이 필요할 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 요청 본문을 문자열 Map으로만 만든다.
  - **판단 기준:** 타입으로 필드·값 오류를 줄일 수 있다.

- [ ] **상황:** 잘못된 형식 테스트까지 정상 DTO로 만든다.
  - **판단 기준:** 비정상 요청은 원시 표현으로 검증할 수 있다.
