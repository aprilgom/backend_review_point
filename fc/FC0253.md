# FC0253 · 삭제의 멱등성과 부재 정책

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0248](FC0248.md) · [다음 FC: FC0255 →](FC0255.md)

## 검토 질문

- [ ] 이미 없는 대상을 삭제할 때 목표 상태 달성을 성공으로 볼지 오류로 볼지 업무 영향으로 결정했는가?

**직접 작성한 예시**

```sql
DELETE FROM slot WHERE id = :id;
```

**적용 설명:** 이미 없어도 목표 상태가 달성된 것으로 보는 멱등 삭제 예다. 삭제 건수 0을 오류로 볼지는 업무 계약에 따른다.

## 구체적인 검토 사례

- [ ] **상황:** 이미 삭제된 대상을 다시 삭제한다.
  - **판단 기준:** 목표 상태만 중요하면 성공으로 볼 수 있다.

- [ ] **상황:** 반드시 존재해야 하는 작업도 조용히 성공한다.
  - **판단 기준:** 업무 영향에 따라 부재 계약을 구분한다.
