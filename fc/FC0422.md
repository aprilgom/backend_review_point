# FC0422 · 테스트 데이터 중복과 단건 계약

## 검토 질문

- [ ] 준비 데이터의 충돌로 단건 조회가 여러 결과를 반환하지 않으며 시나리오 간 격리가 유지되는가?

**직접 작성한 예시**

```java
String uniqueName = "case-" + UUID.randomUUID();
users.insert(new User(uniqueName));
assertTrue(users.findByName(uniqueName).isPresent());
```

**적용 설명:** 중복된 테스트 데이터로 단건 계약을 깨지 않는다. 무작위 이름만으로 완전한 격리가 되는 것은 아니므로 데이터 정리도 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 공유 데이터 때문에 단건 조회가 여러 행을 반환한다.
  - **판단 기준:** 각 테스트의 준비·정리 범위를 격리한다.

- [ ] **상황:** 고유 문자열만 만들고 데이터를 계속 남긴다.
  - **판단 기준:** 재실행·병렬 실행·누적 비용도 고려한다.
