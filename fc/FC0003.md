# FC0003 · 테스트 요청 도우미의 추출 범위

## 검토 질문

- [ ] 반복되는 요청 구성을 공통 도우미로 묶었을 때 재사용성과 테스트 의도의 가독성이 함께 좋아지는가?

**직접 작성한 예시**

```java
Response response = createTask("read", Priority.NORMAL);
assertEquals(201, response.status());
assertEquals("read", response.body().title());
```

**적용 설명:** createTask에 반복 요청 구성을 모은 사용 예시다. 응답 검증까지 숨겨 테스트 의도가 사라지지 않게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 인증·헤더 설정이 모든 요청 테스트에 반복된다.
  - **판단 기준:** 공통 준비를 추출해 일괄 변경 가능성을 높인다.

- [ ] **상황:** 짧은 호출을 다시 한 겹 감싼다.
  - **판단 기준:** 이름이 의미를 더하지 않으면 직접 호출도 허용한다.
