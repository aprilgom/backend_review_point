# FC0336 · 실행 메타데이터의 역할 명명

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0316](FC0316.md)

## 검토 질문

- [ ] 리플렉션 대상 객체·메서드 같은 필드의 이름이 기술적인 선언 형태보다 실제 역할을 설명하는가?

**직접 작성한 예시**

```java
private final Object handler;
private final Method handlerMethod;
```

**적용 설명:** 리플렉션 대상 객체와 호출 메서드의 역할을 이름으로 드러낸다. 가능하면 Object보다 더 좁은 계약을 쓴다.

## 구체적인 검토 사례

- [ ] **상황:** 필드명이 선언 형태만 설명한다.
  - **판단 기준:** 실행 대상·호출 메서드 등 역할을 표현한다.

- [ ] **상황:** Object 타입이 실제 계약을 감춘다.
  - **판단 기준:** 가능하면 더 좁은 타입을 사용한다.
