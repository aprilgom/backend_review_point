# FC0258 · 화면 캐시와 최종 업무 검증

## 검토 질문

- [ ] 화면 표시에 쓰는 캐시와 결제·확정 단계의 최신 상태 검증을 구분하는가?

**직접 작성한 예시**

```javascript
const cached = cartSnapshot.get(productId);
renderQuantity(cached?.quantity ?? 0);
// 주문 확정 시 서버가 현재 가격·재고·권한을 다시 검증한다.
```

**적용 설명:** 화면 표시 캐시는 편의를 위한 값이다. 결제의 정합성 판단을 클라이언트 캐시에 맡기지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 화면 표시마다 같은 데이터를 재조회한다.
  - **판단 기준:** 허용된 최신성 범위에서 캐시할 수 있다.

- [ ] **상황:** 캐시된 가격·재고로 확정을 처리한다.
  - **판단 기준:** 최종 업무 단계에서는 서버가 다시 검증한다.
