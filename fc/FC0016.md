# FC0016 · 반복 처리 규칙의 공통화

[소속 분야: 추상화·중복](../01-abstraction.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0034](FC0034.md) · [다음 FC: FC0010 →](FC0010.md)

## 검토 질문

- [ ] 응답 구성이나 자원 처리에서 반복되는 규칙과 달라지는 동작을 분리해 중복을 줄일 수 있는가?

**직접 작성한 예시**

```java
record ErrorReply(int status, String code) {}
ErrorReply mapFailure(AppFailure failure) {
    return new ErrorReply(failure.status(), failure.publicCode());
}
```

**적용 설명:** 반복 응답 구성의 공통 규칙만 독립 함수로 표현했다. 프레임워크 예외 처리 등록은 생략하고 안전한 공개 코드만 반환한다.

## 구체적인 검토 사례

- [ ] **상황:** 상태별 응답 구성에 같은 규칙이 반복된다.
  - **판단 기준:** 공통 부분과 달라지는 데이터를 분리한다.

- [ ] **상황:** 서로 다른 예외 처리를 한 템플릿에 맞춘다.
  - **판단 기준:** 실패 계약이 다른 경우 독립 처리를 유지한다.
