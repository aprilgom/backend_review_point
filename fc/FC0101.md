# FC0101 · 동시 생성 요청의 정합성

## 검토 질문

- [ ] 같은 자원에 대한 동시 생성 요청에서 트랜잭션·잠금·제약이 함께 업무 불변식을 보장하는가?

**직접 작성한 예시**

```sql
BEGIN;
SELECT id FROM queue_slot WHERE id = :slot_id FOR UPDATE;
INSERT INTO waiting(slot_id, member_id) VALUES (:slot_id, :member_id);
COMMIT;
```

**적용 설명:** 슬롯 행을 잠그는 DB 트랜잭션 예시다. 관련 작업이 같은 잠금 규약을 사용하고 고유 제약도 갖춰야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 동시 요청이 같은 자원을 생성한다.
  - **판단 기준:** 제약·격리·잠금이 불변식을 지키는지 검증한다.

- [ ] **상황:** 애플리케이션 한 곳만 잠금을 사용한다.
  - **판단 기준:** 관련 변경 경로가 같은 규칙을 따르게 한다.
