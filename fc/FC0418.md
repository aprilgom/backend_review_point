# FC0418 · JdbcTemplateTest를 작성해 JdbcTemplate의 동작을 검증해보자는 제안이다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0417](FC0417.md) · [다음 FC: FC0420 →](FC0420.md)

**혼합·경계:** 직접 구현한 JdbcTemplate 동작 검증을 Spring 라이브러리 테스트로 한정하지 않음.

- [ ] JdbcTemplateTest를 작성해 JdbcTemplate의 동작을 검증해보자는 제안이다. (개선 제안)
  - 조건: 작성자는 결과 개수 검증과 예외 처리를 테스트하겠다고 답했다. 구체적인 검증 항목은 작성자가 제시한 계획이며, 테스트 추가 완료 여부는 확인되지 않는다.

- [ ] JdbcTemplate에 대한 테스트를 추가하자는 제안이다. (개선 제안)
  - 조건: 구체적인 검증 시나리오는 제시되지 않았다. 작성자는 테스트를 추가했다고 답했으나 실제 테스트 내용과 실행 결과는 이 대화에서 확인되지 않는다.

- [ ] JdbcTemplate 테스트를 작성해 보도록 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 여유가 있을 때 선택적으로 진행할 사항이며 테스트 작성이 어렵지만 학습할 점이 많을 것이라고 설명했다. 작성자는 테스트를 작성하고 H2를 testImplementation 의존성으로 추가했다고 보고하면서, 특정 데이터베이스에 의존하고 싶지 않았지만 H2 없이는 테스트하기 어려웠다고 밝혔다. 보고된 테스트의 실행 결과나 충분성은 확인되지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
List<Long> ids = runner.query("SELECT id FROM sample ORDER BY id", noParameters, idMapper);
assertEquals(List.of(1L, 2L), ids);
```

**적용 설명:** 직접 작성한 JDBC 실행 도우미의 매핑 계약을 테스트한다. 예외 발생 시 자원 해제도 별도 검증 대상이다.
