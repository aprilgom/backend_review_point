# FC0320 · 테스트 식별자와 매직 넘버

## 검토 질문

- [ ] 테스트 준비에서 얻은 식별자나 의미 있는 이름을 사용해 하드코딩 숫자 의존을 줄였는가?

**직접 작성한 예시**

```java
long savedOrderId = orders.save(sampleOrder()).id();
assertEquals(savedOrderId, orders.get(savedOrderId).id());
```

**적용 설명:** 하드코딩 숫자 대신 준비 단계에서 생성된 식별자를 사용한다.

## 구체적인 검토 사례

- [ ] **상황:** 테스트에 특정 숫자 ID를 고정한다.
  - **판단 기준:** 준비 과정의 반환값을 사용한다.

- [ ] **상황:** 의미 있는 상수가 실제 데이터와 다르다.
  - **판단 기준:** 의미와 저장 결과의 연결을 확인한다.
