# FC0210 · 의도와 제약을 드러내는 상태 변경

## 검토 질문

- [ ] 무제한 setter 대신 변경의 의미와 불변식을 표현하는 메서드를 제공하는가?

**직접 작성한 예시**

```java
void rename(String newName) {
    this.name = requireNonBlank(newName);
}
```

**적용 설명:** 무제한 setter 대신 의도와 불변식을 드러내는 변경 메서드를 둔다.

## 구체적인 검토 사례

- [ ] **상황:** 외부에서 모든 필드를 setter로 바꾼다.
  - **판단 기준:** 의도 있는 변경 API로 제약을 보장한다.

- [ ] **상황:** 변경 메서드가 이름만 다르고 무제한이다.
  - **판단 기준:** 허용 전이와 입력 검증을 실제로 구현한다.
