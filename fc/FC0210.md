# FC0210 · Line의 이름과 색상을 변경하는 setter 사용을 지양하는 것이 어떨지 제안했다.

[소속 분야: 도메인 모델·값 표현](../11-domain-model.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0212](FC0212.md) · [다음 FC: FC0213 →](FC0213.md)

- [ ] Line의 이름과 색상을 변경하는 setter 사용을 지양하는 것이 어떨지 제안했다. (개선 제안)
  - 조건: setter를 피하자는 제안이며, 구체적인 결함이나 대체 구현은 제시되지 않았다.

- [ ] Name을 일반 클래스 대신 record로 표현하는 방안을 제안했다. (개선 제안)
  - 조건: 작성자는 불변 객체이므로 record도 적절하다고 답하고 반영했다고 보고했다. 리뷰 참여자가 필수 변경이나 일반 규칙으로 제시한 것은 아니다.

- [ ] CreateReservationRequest를 record로 변경하는 방안을 제안했다. (개선 제안)
  - 조건: 작성자는 record 변경을 완료했다고 보고했다. 실제 변경된 구현은 이 대화에 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
void rename(String newName) {
    this.name = requireNonBlank(newName);
}
```

**적용 설명:** 무제한 setter 대신 의도와 불변식을 드러내는 변경 메서드를 둔다.
