# FC0073 · 스키마 검증과 자동 변경의 선택

## 검토 질문

- [ ] 실행 시 스키마를 검증할지 자동 변경할지 환경별 요구와 데이터 보존 관점에서 결정했는가?

**직접 작성한 예시**

```properties
hibernate.hbm2ddl.auto=validate
```

**적용 설명:** Hibernate가 스키마를 검증하도록 한 예다. 스키마 변경은 별도 마이그레이션으로 적용하며 update와의 운영상 차이를 설명할 수 있어야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 운영 시작 때 스키마를 자동 변경한다.
  - **판단 기준:** 검증과 명시적 마이그레이션의 이점을 비교한다.

- [ ] **상황:** 검증 실패를 무시하고 실행한다.
  - **판단 기준:** 불일치 원인을 해결한 뒤 배포한다.
