# FC0251 · 오류 본문과 실제 응답 상태

## 검토 질문

- [ ] 본문에만 실패를 적지 않고 실제 HTTP 상태도 오류 계약과 일치시키는가?

**직접 작성한 예시**

```http
HTTP/1.1 404 Not Found
Content-Type: application/json

{"code":"ITEM_NOT_FOUND"}
```

**적용 설명:** 본문 오류 코드뿐 아니라 실제 HTTP 상태도 실패 계약에 맞춘다.

## 구체적인 검토 사례

- [ ] **상황:** 오류 JSON을 HTTP 200으로 보낸다.
  - **판단 기준:** 실제 상태도 실패 계약에 맞춘다.

- [ ] **상황:** 상태는 오류인데 본문이 성공 스키마다.
  - **판단 기준:** 소비자의 파싱·분기 계약을 함께 확인한다.
