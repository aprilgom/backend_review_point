# FC0110 · 비동기 작업의 결과와 예외 회수

## 검토 질문

- [ ] 작업 결과와 예외를 관찰해야 하는지에 맞춰 제출 API를 선택하고 인터럽트도 처리하는가?

**직접 작성한 예시**

```java
Future<Result> result = executor.submit(this::calculate);
try { consume(result.get()); }
catch (ExecutionException failed) { report(failed.getCause()); }
```

**적용 설명:** 결과·실패를 회수해야 하면 Future를 관찰한다. InterruptedException은 상위에 전파하거나 인터럽트를 복원한다.

## 구체적인 검토 사례

- [ ] **상황:** 작업 제출 뒤 결과를 무시한다.
  - **판단 기준:** 실패가 관측 가능한지 확인한다.

- [ ] **상황:** 대기 중 인터럽트를 삼킨다.
  - **판단 기준:** 상위 전파나 인터럽트 복원 계약을 지킨다.
