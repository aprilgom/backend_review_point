# FC0341 · 실행과 단언이 결합된 테스트 구간

## 검토 질문

- [ ] 예외 단언처럼 실행·검증을 함께 하는 구간의 표현이 실제 테스트 흐름을 설명하는가?

**직접 작성한 예시**

```java
// when, then
assertThrows(InvalidPrice.class, () -> new Price(-1));
```

**적용 설명:** 예외 단언은 실행과 검증을 함께 수행한다. 불필요한 구간 주석을 강제할 필요는 없다.

## 구체적인 검토 사례

- [ ] **상황:** 예외 단언에 실행과 검증이 함께 있다.
  - **판단 기준:** 구간 이름이 실제 흐름을 설명하게 한다.

- [ ] **상황:** 주석 형식만 맞추느라 코드를 나눈다.
  - **판단 기준:** 테스트 의도와 가독성을 우선한다.
