# FC0308 · 변환 파이프라인의 가독성

## 검토 질문

- [ ] 중첩 컬렉션 변환을 루프·스트림 중 더 명료한 방식으로 표현하고 중복·순서를 보존하는가?

**직접 작성한 예시**

```java
List<User> users = groups.stream()
    .flatMap(group -> group.users().stream()).toList();
```

**적용 설명:** 여러 그룹의 목록을 평탄화하는 예다. 루프보다 명료한지 확인하고 중복 사용자 제거가 필요한지도 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 중첩 목록 변환에 반복문이 깊어진다.
  - **판단 기준:** 평탄화 연산이 더 명료할 수 있다.

- [ ] **상황:** 스트림 변환에서 순서·중복이 바뀐다.
  - **판단 기준:** 기존 결과 계약을 검증한다.
