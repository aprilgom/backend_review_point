# FC0308 · 조회 결과를 User 리스트로 변환하는 반복문을 stream과 flatMap을 활용해 더 읽기 쉽게 작성해 보라고 제안한다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0299](FC0299.md) · [다음 FC: FC0315 →](FC0315.md)

- [ ] 조회 결과를 User 리스트로 변환하는 반복문을 stream과 flatMap을 활용해 더 읽기 쉽게 작성해 보라고 제안한다. (개선 제안)
  - 조건: 가독성에 대한 제안이며 flatMap의 구체적인 적용 방법이나 타당성은 대화에서 확인되지 않는다. 작성자는 2단계에서 objectMapper를 도입하면서 해당 코드를 제거했다고 보고했으며, 제안한 방식대로 변경했다고 밝힌 것은 아니다.

- [ ] 장바구니 항목을 응답 목록으로 변환하는 반복문을 Stream으로 표현해 보는 것을 제안했다. (개선 제안)
  - 조건: 가능한 대안으로 제시했으며, 현재 반복문이 잘못되었다거나 성능상 문제가 있다는 지적은 아니다.

- [ ] 문자열에 대응하는 예약 상태를 찾는 반복문을 Stream으로 표현하면 더 깔끔해질 수 있다고 제안했다. (개선 제안)
  - 조건: 가독성 개선 제안이며 성능이나 동작 결함을 지적한 것은 아니다. 작성자는 반영했다고 답했으나 변경된 코드는 대화에 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
List<User> users = groups.stream()
    .flatMap(group -> group.users().stream()).toList();
```

**적용 설명:** 여러 그룹의 목록을 평탄화하는 예다. 루프보다 명료한지 확인하고 중복 사용자 제거가 필요한지도 정한다.
