# FC0143 · 생성·수정 시각의 자동 관리

[소속 분야: 데이터 관계·영속성](../08-persistence.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0142](FC0142.md) · [다음 FC: FC0144 →](FC0144.md)

## 검토 질문

- [ ] 시각 메타데이터를 일관되게 기록하고 벌크 변경·시간 기준·테스트 가능성까지 고려했는가?

**직접 작성한 예시**

```java
@PrePersist void onInsert() { createdAt = Instant.now(); }
@PreUpdate void onUpdate() { updatedAt = Instant.now(); }
```

**적용 설명:** Jakarta Persistence 수명 콜백으로 자동 기록하는 조각이다. 테스트 가능한 시계·벌크 SQL 우회·DB 시각 기준을 별도로 고려한다.

## 구체적인 검토 사례

- [ ] **상황:** 수정 시각을 호출부마다 수동 설정한다.
  - **판단 기준:** 공통 수명 콜백으로 누락을 줄일 수 있다.

- [ ] **상황:** 벌크 변경이 콜백을 우회한다.
  - **판단 기준:** 모든 쓰기 경로에서 기록 정책이 유지되는지 확인한다.
