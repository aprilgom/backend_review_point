# FC0366 · 공통 계약의 패키지 소유

## 검토 질문

- [ ] 매핑·애너테이션 등 공통 계약이 특정 기능 패키지에 불필요하게 종속되지 않았는가?

**직접 작성한 예시**

```java
package mvc.mapping;
public @interface Route { String path(); }
```

**적용 설명:** 매핑 표식이 특정 애플리케이션 컨트롤러에 속하는지 프레임워크에 속하는지 구분한다. 리플렉션에 쓰려면 RUNTIME 보존 정책을 추가해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 공통 매핑 계약이 특정 기능 아래 있다.
  - **판단 기준:** 재사용 책임을 가진 모듈에 둘 수 있다.

- [ ] **상황:** 옮긴 뒤 앱 구체 타입을 계속 참조한다.
  - **판단 기준:** 물리 위치와 실제 의존 방향을 함께 본다.
