# FC0425 · 테스트 코드가 전반적으로 동작하지 않는 것 같다며 작성자 환경에서는 정상적으로 실행되는지 확인을 요청했다.

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0428](FC0428.md) · [다음 FC: FC0430 →](FC0430.md)

- [ ] 테스트 코드가 전반적으로 동작하지 않는 것 같다며 작성자 환경에서는 정상적으로 실행되는지 확인을 요청했다. (설계 질문)
  - 조건: 후속 댓글에서 DM으로 해결책을 전달받아 확인했다고 밝혔다. DM 내용과 실행 실패 원인은 제공되지 않았으며, 실제 수정 여부나 정상 실행 결과를 확정할 수 없다. 최초 문제 제기를 명시적으로 철회하지는 않았다.

- [ ] MemberReservationControllerTest에도 일괄 실행 시 실패하는 테스트가 있으므로 확인해 달라고 요청했다. (문제 보고)
  - 조건: 작성자는 다른 지적과 동일한 원인으로 발생한 오류이며 반영했다고 보고했다. 참조한 다른 대화의 원인은 제공되지 않았으므로 구체적인 실패 원인이나 실제 해결 여부는 확인할 수 없다.

- [ ] 잘못된 secret-key를 검증하는 테스트가 토스 운영 서버를 실제 호출해도 괜찮은지, 운영 DB를 대상으로 테스트하는 것과 같은 문제가 없는지 질문한다. (설계 질문)
  - 조건: 리뷰 참여자는 설정된 base-url을 근거로 운영 서버 호출로 보인다고 우려했다. 실제 운영 데이터에 영향이 발생했다는 보고나 작성자의 설명은 없다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```sh
./gradlew clean test --no-build-cache
```

**적용 설명:** 로컬 캐시에 기대지 않는 재현 예시다. 실행 환경·JDK·외부 서비스 조건도 함께 기록한다.
