# FC0425 · 다른 환경에서의 테스트 재현

## 검토 질문

- [ ] 작성자 환경뿐 아니라 깨끗한 빌드와 필요한 실행 조건에서도 테스트가 재현되는가?

**직접 작성한 예시**

```sh
./gradlew clean test --no-build-cache
```

**적용 설명:** 로컬 캐시에 기대지 않는 재현 예시다. 실행 환경·JDK·외부 서비스 조건도 함께 기록한다.

## 구체적인 검토 사례

- [ ] **상황:** 특정 PC에서만 테스트가 통과한다.
  - **판단 기준:** JDK·설정·외부 의존을 명시한다.

- [ ] **상황:** 빌드 캐시에 의존해 누락을 못 찾는다.
  - **판단 기준:** 깨끗한 환경에서도 재현한다.
