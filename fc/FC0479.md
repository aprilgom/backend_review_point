# FC0479 · 앱에서 구간 관리의 구간 추가 버튼을 눌러도 반응이 없으며, 모달 관련 로직이 누락된 것 같다는 문제 보고다.

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0469](FC0469.md) · [다음 FC: FC0481 →](FC0481.md)

- [ ] 앱에서 구간 관리의 구간 추가 버튼을 눌러도 반응이 없으며, 모달 관련 로직이 누락된 것 같다는 문제 보고다. (문제 보고)
  - 조건: 버튼 무반응은 리뷰 참여자가 실행 후 보고한 현상이고 모달 로직 누락은 추정이다. 작성자는 리팩터링 중 발생한 버그를 재수정했다고 답했으나 이후 동작 확인은 제공되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```javascript
document.querySelector("#add-segment").addEventListener("click", () => {
  document.querySelector("#segment-dialog").showModal();
});
```

**적용 설명:** DOM 생성 후 실행하는 대화상자 연결 예다. 버튼 존재·dialog 타입·키보드 포커스와 제출 동작도 확인한다.
