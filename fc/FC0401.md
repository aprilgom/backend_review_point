# FC0401 · 응답 필드의 충분한 검증

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0405](FC0405.md) · [다음 FC: FC0397 →](FC0397.md)

## 검토 질문

- [ ] ID뿐 아니라 중요한 반환 필드를 확인해 누락·오매핑을 잡는가?

**직접 작성한 예시**

```java
assertAll(
    () -> assertEquals(savedId, reply.id()),
    () -> assertEquals("green", reply.color()),
    () -> assertEquals("weekday", reply.name()));
```

**적용 설명:** 식별자만 맞고 다른 필드가 잘못 매핑된 오류도 잡는다.

## 구체적인 검토 사례

- [ ] 노선 목록 조회 테스트에서 응답 본문의 id뿐 아니라 다른 필드 값도 검증하자는 제안이다. (개선 제안)
  - 조건: 작성자는 저장된 id와 응답의 id를 이미 비교하고 있다고 설명하며 모든 본문 값을 검증하라는 뜻인지 물었다. 리뷰 참여자는 LineResponse에 id 외의 값도 있으므로 이를 검증하면 더 꼼꼼한 테스트가 된다는 취지라고 명확히 했다.

- [ ] 노선 조회 테스트에서 lineId뿐 아니라 응답의 다른 값들도 검증하도록 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 ID만 검증해도 충분한지 의문을 제기했다. 작성자는 해당 부분과 전반적으로 부족한 테스트를 추가했다고 보고했지만, 구체적인 추가 검증 내용은 대화에 제시되지 않았다.

- [ ] 노선 수정 인수 테스트에서 상태 코드뿐 아니라 수정 후 조회한 내용도 검증하자는 제안이다. (개선 제안)
  - 조건: 리뷰 참여자는 advanced 개선 사항으로 제시했다. 작성자는 조회하여 확인하도록 변경했다고 보고했으며, 실제 변경 결과를 별도로 검증한 근거는 없다.
