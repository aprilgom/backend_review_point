# FC0055 · 핸들러 반환 계약의 확장성

[소속 분야: API·공개 인터페이스 계약](../03-api-contract.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0063](FC0063.md) · [다음 FC: FC0066 →](FC0066.md)

## 검토 질문

- [ ] 핸들러가 지원해야 하는 여러 결과 형식을 반환 타입과 후속 처리 계약에 명확히 표현했는가?

**직접 작성한 예시**

```java
interface Handler { HandlerResult handle(HttpRequest request); }
sealed interface HandlerResult permits TextResult, PageResult {}
record TextResult(String body) implements HandlerResult {}
record PageResult(String template, Map<String, Object> model) implements HandlerResult {}
```

**적용 설명:** 직접 만드는 핸들러의 결과 타입을 명시적으로 확장한다. 각 결과를 처리하는 렌더러도 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 처리기가 문자열 결과만 반환할 수 있다.
  - **판단 기준:** 필요한 출력 종류를 결과 계약에 표현한다.

- [ ] **상황:** 지원하지 않는 반환 타입이 들어온다.
  - **판단 기준:** 명시적 실패나 확장 처리 규칙을 둔다.
