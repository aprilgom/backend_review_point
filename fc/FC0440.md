# FC0440 · 날짜 의존 테스트의 시간 기준

## 검토 질문

- [ ] 고정 데이터와 현재 날짜가 어긋나지 않도록 앱·DB의 시간 기준과 입력 날짜를 제어하는가?

**직접 작성한 예시**

```java
Clock clock = Clock.fixed(Instant.parse("2025-03-08T00:00:00Z"), ZoneOffset.UTC);
LocalDate from = LocalDate.now(clock).minusDays(6);
```

**적용 설명:** 애플리케이션 기준 오늘을 고정한 예다. SQL이 CURRENT_DATE를 직접 쓰면 이 Clock만으로 고정되지 않으므로 날짜를 바인딩하거나 DB 시계 전략도 맞춘다.

## 구체적인 검토 사례

- [ ] **상황:** 고정 날짜와 현재 날짜를 함께 사용한다.
  - **판단 기준:** 테스트 시간 기준을 제어한다.

- [ ] **상황:** 앱 시계만 고정하고 DB는 현재 날짜를 쓴다.
  - **판단 기준:** 바인딩 날짜나 DB 시간 전략을 맞춘다.
