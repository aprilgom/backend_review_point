# FC0311 · LoginResult 클래스가 사용되지 않고 있음을 지적했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0306](FC0306.md) · [다음 FC: FC0322 →](FC0322.md)

- [ ] LoginResult 클래스가 사용되지 않고 있음을 지적했다. (관찰)
  - 조건: 인라인 대상은 LoginResult 클래스 선언이다. 삭제 요구나 후속 조치는 명시되지 않았다.

- [ ] RelatedDataExistException 클래스가 사용되지 않는 것으로 보인다고 지적한다. (관찰)
  - 조건: 사용되지 않는 것 같다는 리뷰 참여자의 관찰이며, 실제 사용 여부나 삭제 결과를 확인하는 후속 발언은 없다.

- [ ] gameRepository와 pieceRepository가 사용되지 않는 것으로 보인다고 지적한다. (관찰)
  - 조건: 사용되지 않는 것 같다는 잠정적 관찰이며, 작성자는 감사만 표했다. 실제 사용 여부를 검증했거나 제거했다는 근거는 없다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
// 실제 사용하는 반환 계약만 유지
Actor login(Credentials credentials) { return authenticator.requireActor(credentials); }
```

**적용 설명:** 사용하지 않는 LoginResult를 제거하기 전 직렬화·리플렉션·외부 API 사용 여부를 확인한다.
