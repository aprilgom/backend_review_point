# FC0311 · 사용되지 않는 결과 타입

## 검토 질문

- [ ] 사용하지 않는 응답·결과 타입이 남아 있지 않으며 외부·동적 사용을 확인한 뒤 정리하는가?

**직접 작성한 예시**

```java
// 실제 사용하는 반환 계약만 유지
Actor login(Credentials credentials) { return authenticator.requireActor(credentials); }
```

**적용 설명:** 사용하지 않는 LoginResult를 제거하기 전 직렬화·리플렉션·외부 API 사용 여부를 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 사용하지 않는 결과 모델이 남아 있다.
  - **판단 기준:** 실제 소비자를 확인하고 정리한다.

- [ ] **상황:** 내부 참조가 없다는 이유로 삭제한다.
  - **판단 기준:** 직렬화·외부 API·동적 사용도 점검한다.
