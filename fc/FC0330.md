# FC0330 · SQL 변수 타입 표기의 기준

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0317](FC0317.md) · [다음 FC: FC0339 →](FC0339.md)

## 검토 질문

- [ ] SQL 문자열 선언의 타입 표기 기준이 명확하고 혼용으로 의미를 찾기 어렵지 않은가?

**직접 작성한 예시**

```java
String sql = "SELECT id FROM tag WHERE name = ?";
```

**적용 설명:** SQL 변수 타입 표기를 하나의 팀 규칙으로 맞춘 예다.

## 구체적인 검토 사례

- [ ] **상황:** SQL 변수 선언 방식이 기준 없이 섞인다.
  - **판단 기준:** 같은 맥락에는 일관된 표기를 적용한다.

- [ ] **상황:** 추론 타입 때문에 값의 의미를 잃는다.
  - **판단 기준:** 읽는 데 필요한 정보가 보이는지 확인한다.
