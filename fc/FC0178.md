# FC0178 · HTTP 클라이언트 선택 기준

## 검토 질문

- [ ] 동기·비동기·풀·타임아웃·테스트 지원 요구에 맞춰 클라이언트와 어댑터 경계를 선택했는가?

**직접 작성한 예시**

```java
interface RemoteCatalog { Item fetch(ItemId id); }
RemoteCatalog catalog = new JdkCatalogClient(httpClient);
```

**적용 설명:** HTTP 클라이언트 선택을 어댑터 경계로 표현했다. 동기·비동기, 풀, 타임아웃, 테스트 지원 요구를 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 익숙한 HTTP 라이브러리를 바로 선택한다.
  - **판단 기준:** 동기성·풀·타임아웃·대역 지원을 비교한다.

- [ ] **상황:** 클라이언트 API가 업무 코드에 퍼진다.
  - **판단 기준:** 외부 연동 계약을 어댑터로 격리할 수 있다.
