# FC0303 · 검증 의도를 드러내는 단언

## 검토 질문

- [ ] 크기 숫자 등 간접 표현 대신 비어 있음·포함 관계 같은 실제 기대를 읽기 쉽게 표현하는가?

**직접 작성한 예시**

```java
assertTrue(repository.findAll().isEmpty());
```

**적용 설명:** 삭제 후 비어 있다는 의도를 직접 표현한다. 사용하는 단언 라이브러리의 isEmpty도 가능하다.

## 구체적인 검토 사례

- [ ] **상황:** 비어 있음을 크기 0으로 우회 표현한다.
  - **판단 기준:** 의도를 직접 드러내는 단언을 고려한다.

- [ ] **상황:** 짧은 단언으로 실패 설명이 부족해진다.
  - **판단 기준:** 필요한 맥락과 기대값을 유지한다.
