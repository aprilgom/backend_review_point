# FC0403 · 테스트 계층별 검증 범위

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0408](FC0408.md) · [다음 FC: FC0411 →](FC0411.md)

## 검토 질문

- [ ] 단위·슬라이스·통합 테스트가 각각 잡는 실패를 구분하고 같은 검증을 불필요하게 중복하지 않는가?

**직접 작성한 예시**

```java
// 통합: 실제 HTTP부터 DB까지 생성 흐름
assertEquals(201, client.post("/tasks", new CreateTaskRequest("read")).status());
// 단위: 경계값 계산 등 통합 테스트가 다루지 않는 분기
```

**적용 설명:** 각 계층 테스트가 잡는 실패가 다른지 확인한다. 같은 성공 흐름을 여러 층에서 반복할 필요는 없다.

## 구체적인 검토 사례

- [ ] **상황:** 각 계층에서 같은 성공 흐름을 반복한다.
  - **판단 기준:** 테스트별로 잡을 실패를 구분한다.

- [ ] **상황:** 통합 테스트만 있어 경계 실패 원인을 찾기 어렵다.
  - **판단 기준:** 필요한 단위 검증을 보완한다.
