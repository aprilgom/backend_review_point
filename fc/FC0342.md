# FC0342 · 호출부에 맞는 조건 이름

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0338](FC0338.md) · [다음 FC: FC0316 →](FC0316.md)

## 검토 질문

- [ ] 긍정·부정 판정 이름을 호출부에서 자연스럽게 읽히도록 선택하고 이중 부정을 피하는가?

**직접 작성한 예시**

```java
if (!first.hasSameColorAs(second)) allowConnection();
```

**적용 설명:** 긍정형에 부정을 붙인 형태도 읽기 쉬울 수 있다. 호출부가 대부분 부정 조건이라면 hasDifferentColorFrom 같은 이름을 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 호출부에 부정 연산이 반복된다.
  - **판단 기준:** 차이를 직접 표현하는 이름을 비교한다.

- [ ] **상황:** 부정형 이름에 다시 부정을 붙인다.
  - **판단 기준:** 이중 부정이 생기지 않게 한다.
