# FC0244 · 외부 서비스 오류의 처리 경계

## 검토 질문

- [ ] 외부 상태 코드·본문·통신 오류를 어느 경계에서 해석하고 재시도·실패 계약으로 바꾸는가?

**직접 작성한 예시**

```java
RemoteReply reply = transport.send(request);
if (reply.status() >= 400) throw remoteErrors.translate(reply);
return decode(reply.body());
```

**적용 설명:** 외부 오류 해석을 한 경계에 모은 대안이다. 상태별 재시도·파싱 실패·민감 정보 제거를 따로 정의한다.

## 구체적인 검토 사례

- [ ] **상황:** 외부 오류 해석이 호출부마다 다르다.
  - **판단 기준:** 변환 책임을 연동 경계에 모을 수 있다.

- [ ] **상황:** 모든 외부 실패를 즉시 재시도한다.
  - **판단 기준:** 상태·멱등성·횟수 제한에 따라 구분한다.
