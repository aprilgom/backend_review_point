## 검토 질문

- [ ] 동일 데이터를 같은 형태로 여러 번 변환하지 않고 한 번 만든 결과를 안전하게 재사용할 수 있는가?

**직접 작성한 예시**

```java
List<Mapping> mappingList = Arrays.asList(mappings);
validate(mappingList);
register(mappingList);
```

**적용 설명:** 반복 생성 대신 한 번 만든 뷰를 재사용한다. Arrays.asList는 배열 변경과 연결되고 크기 변경이 제한된다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 배열을 반복해서 목록으로 바꾼다.
  - **판단 기준:** 한 번 만든 표현을 재사용할 수 있다.

- [ ] **상황:** 재사용한 뷰의 원본 배열이 변경된다.
  - **판단 기준:** 복사와 연결된 뷰의 차이를 이해한다.
