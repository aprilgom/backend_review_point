# FC0028 · 응답 객체의 변환 책임

## 검토 질문

- [ ] 도메인 필드를 호출부마다 꺼내 조립하는 대신 응답 객체의 생성 경계에 변환 규칙을 모을 수 있는가?

**직접 작성한 예시**

```java
static CartLineReply from(CartLine line) {
    return new CartLineReply(line.productName(), line.quantity());
}
```

**적용 설명:** 응답 타입이 도메인을 읽게 해 변환 코드를 모은다. 도메인에서 응답 타입을 참조하는 역방향 의존은 피한다.

## 구체적인 검토 사례

- [ ] **상황:** 응답 생성 때마다 도메인 필드를 꺼낸다.
  - **판단 기준:** 변환 책임을 응답 생성 경계에 둘 수 있다.

- [ ] **상황:** 도메인이 HTTP 응답 타입을 참조한다.
  - **판단 기준:** 의존 방향이 안쪽 모델로 역전되지 않게 한다.
