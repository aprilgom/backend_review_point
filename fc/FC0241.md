# FC0241 · 검증 상황에 맞는 오류 메시지

## 검토 질문

- [ ] 오류 메시지가 실제 필드·조건·실패 이유를 설명하며 민감한 입력을 노출하지 않는가?

**직접 작성한 예시**

```java
if (quantity < 1) throw new InvalidQuantity("수량은 1 이상이어야 합니다");
```

**적용 설명:** 필드·조건에 맞는 메시지를 제공한다. 입력 원문이나 비밀값을 메시지에 그대로 넣지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 다른 필드의 오류 메시지를 재사용한다.
  - **판단 기준:** 실제 조건에 맞는 안전한 설명을 제공한다.

- [ ] **상황:** 원본 입력을 메시지에 그대로 넣는다.
  - **판단 기준:** 개인정보·비밀값 노출을 방지한다.
