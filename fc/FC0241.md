# FC0241 · 검증 상황에 맞는 오류 메시지

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0240](FC0240.md) · [다음 FC: FC0242 →](FC0242.md)

## 검토 질문

- [ ] 오류 메시지가 실제 필드·조건·실패 이유를 설명하며 민감한 입력을 노출하지 않는가?

**직접 작성한 예시**

```java
if (quantity < 1) throw new InvalidQuantity("수량은 1 이상이어야 합니다");
```

**적용 설명:** 필드·조건에 맞는 메시지를 제공한다. 입력 원문이나 비밀값을 메시지에 그대로 넣지 않는다.

## 구체적인 검토 사례

- [ ] 입력 예외가 사용되는 상황에 맞게 예외 메시지도 수정할 필요가 있다고 제안했다. (개선 제안)
  - 조건: 대화에는 현재 메시지의 구체적인 내용이나 대체 문구가 제시되지 않았다. 작성자의 답변은 명명에 대한 동의이며 메시지 수정 결과를 보고한 것은 아니다.

- [ ] 예외 발생 시 사용자에게 적합한 메시지를 전달할 예외 처리 지점이 필요하다고 제안했다. (개선 제안)
  - 조건: 작성자는 사용자에게 예외 메시지를 전달하도록 예외 처리를 추가하겠다고 답했다. 이는 변경 계획이며 실제 구현이나 응답 계약은 확인되지 않는다.

- [ ] 예외 발생 이유를 구분할 수 있도록 예외 메시지를 설정하자고 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 메시지가 없으면 다른 이유로 발생한 예외를 구별하기 어렵다고 우려했다. 작성자는 예외 메시지를 설정하거나 커스텀 예외를 만들 예정이라고 답했고, 리뷰 참여자는 다음 단계에서 확인하겠다고 했다. 구현 완료는 확인되지 않는다.
