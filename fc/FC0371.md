# FC0371 · 서비스와 데이터 접근 코드의 경계

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0381](FC0381.md)

## 검토 질문

- [ ] 서비스의 업무 흐름에 SQL·결과 매핑·연결 처리 같은 기술 세부사항이 섞이지 않는가?

**직접 작성한 예시**

```java
List<Task> tasks = taskStore.findDueBefore(deadline);
```

**적용 설명:** 서비스에서 ResultSet·SQL 조립을 직접 하지 않고 저장 계약에 맡긴다.

## 구체적인 검토 사례

- [ ] **상황:** 서비스 안에 SQL과 행 매핑이 섞인다.
  - **판단 기준:** 저장 계약 뒤로 기술 세부사항을 옮긴다.

- [ ] **상황:** 모든 필터를 메모리에서 수행한다.
  - **판단 기준:** DB 조건과 업무 정책의 비용·책임을 비교한다.
