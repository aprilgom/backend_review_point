# FC0058 · 테스트만을 위한 공개 API

[소속 분야: API·공개 인터페이스 계약](../03-api-contract.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0057](FC0057.md) · [다음 FC: FC0059 →](FC0059.md)

## 검토 질문

- [ ] 테스트 편의를 위해 추가한 공개 메서드가 제품 계약에도 필요하며 기존 공개 동작으로 검증할 수는 없는가?

**직접 작성한 예시**

```java
assertEquals("blue", parsed.queryParameter("color").orElseThrow());
// 테스트 전용 hasParameters()를 추가하지 않고 공개 동작을 검증한다.
```

**적용 설명:** 관찰용 메서드가 제품 계약에 필요한지 검토한다. 테스트 편의가 공개 API 확대의 유일한 이유인지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 테스트에서만 쓰는 공개 조회 메서드가 생긴다.
  - **판단 기준:** 기존 공개 동작으로 검증 가능한지 살핀다.

- [ ] **상황:** 내부 상태를 광범위하게 노출한다.
  - **판단 기준:** 테스트 편의보다 제품 계약의 안정성을 우선한다.
