# FC0399 · 계산 규칙의 직접 검증

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0402](FC0402.md) · [다음 FC: FC0407 →](FC0407.md)

## 검토 질문

- [ ] 계산·변환 로직의 정상값과 경계값을 직접 검증해 통합 흐름만으로 놓치는 오류를 잡는가?

**직접 작성한 예시**

```java
assertEquals(0, discount.apply(0));
assertEquals(90, discount.apply(100));
```

**적용 설명:** 계산 정책의 정상·경계 동작을 직접 검증하는 예다. 숫자는 이 가상 10% 정책에 한정된다.

## 구체적인 검토 사례

- [ ] **상황:** 계산 결과를 통합 화면에서만 확인한다.
  - **판단 기준:** 정상·경계값의 단위 검증을 둔다.

- [ ] **상황:** 반올림·오버플로 경계가 빠진다.
  - **판단 기준:** 자료형과 업무 규칙의 한계를 확인한다.
