# FC0395 · 중요 분기와 실패 이후 부작용

## 검토 질문

- [ ] 조건에 따라 달라지는 동작과 실패 시 실행되지 않아야 할 후속 작업을 우선 검증하는가?

**직접 작성한 예시**

```java
assertThrows(OutOfStock.class, () -> checkout.place(unavailableItem));
assertEquals(0, payments.chargeCount());
```

**적용 설명:** 검증 실패 이후 결제가 실행되지 않는 중요한 분기를 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 실패해도 후속 외부 호출이 실행된다.
  - **판단 기준:** 중단되어야 할 부작용을 검증한다.

- [ ] **상황:** 정상 분기만 테스트한다.
  - **판단 기준:** 조건별 결과와 경계를 우선한다.
