# FC0176 · 실행 환경의 실제 저장 구현

## 검토 질문

- [ ] 운영·개발·테스트에서 선택한 저장 구현이 영속성 요구와 일치하는가?

**직접 작성한 예시**

```java
Users users = config.production()
    ? new SqlUsers(dataSource)
    : new MemoryUsers();
```

**적용 설명:** 실제 실행 환경의 저장 구현을 확인한다. 재시작 후 데이터 보존 요구와 개발·테스트 구성을 구분한다.

## 구체적인 검토 사례

- [ ] **상황:** 실행 앱이 메모리 저장소를 사용한다.
  - **판단 기준:** 재시작 후 보존 요구와 맞는지 확인한다.

- [ ] **상황:** 테스트와 운영의 저장 계약이 다르다.
  - **판단 기준:** 부재·중복·정렬 차이를 검증한다.
