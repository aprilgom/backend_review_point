# FC0147 · 로컬 캐시와 공유 캐시의 선택

## 검토 질문

- [ ] 지연·일관성·메모리·장애·인스턴스 간 공유 요구를 기준으로 캐시 구현을 선택했는가?

**직접 작성한 예시**

```java
Cache cache = new LocalCache(maxEntries, ttl);
// 다른 서버 인스턴스의 쓰기는 이 로컬 캐시에 자동 반영되지 않는다.
```

**적용 설명:** 로컬 캐시와 원격 공유 캐시를 지연·일관성·메모리·장애 처리로 비교한다. LocalCache는 가상 타입이다.

## 구체적인 검토 사례

- [ ] **상황:** 로컬 캐시에 저장한 값이 서버마다 다르다.
  - **판단 기준:** 공유·일관성 요구와 맞는지 확인한다.

- [ ] **상황:** 원격 캐시 장애가 모든 요청을 막는다.
  - **판단 기준:** 실패·대체·부하 증가 정책을 정한다.
