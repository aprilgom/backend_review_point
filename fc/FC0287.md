## 검토 질문

- [ ] 반복문 안의 DB 접근을 사전 일괄 조회로 바꿀 수 있으며 데이터량과 묶음 크기를 제한하는가?

**직접 작성한 예시**

```java
Map<Long, Row> rows = store.findAll(ids);
for (long id : ids) consume(requireRow(rows, id));
```

**적용 설명:** 반복문 밖에서 필요한 데이터를 모은다. 한 번에 너무 많은 ID를 보내면 묶음 크기를 제한한다.

## 구체적인 검토 사례

- [ ] **상황:** 반복문 안에서 매번 DB에 접근한다.
  - **판단 기준:** 사전 조회 결과를 재사용할 수 있다.

- [ ] **상황:** 대량 데이터를 한 번에 모두 적재한다.
  - **판단 기준:** 메모리·일관성·페이지 처리 비용을 평가한다.
