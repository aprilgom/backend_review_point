# FC0432 · 생성 결과 ID를 사용하는 테스트

[소속 분야: 테스트 준비·격리](../22-test-isolation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0434](FC0434.md) · [다음 FC: FC0427 →](FC0427.md)

## 검토 질문

- [ ] DB의 특정 ID를 가정하지 않고 준비 과정에서 반환된 식별자로 대상에 접근하는가?

**직접 작성한 예시**

```java
long id = slots.save(sampleSlot()).id();
assertEquals(204, client.delete("/slots/" + id).status());
```

**적용 설명:** DB 생성 ID를 사용해 시퀀스 상태에 덜 의존하게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 삭제 테스트가 고정 ID를 사용한다.
  - **판단 기준:** 삽입 결과의 ID로 요청한다.

- [ ] **상황:** ID가 시퀀스 초기화에 의존한다.
  - **판단 기준:** 실행 순서와 재실행에 독립적인 준비를 한다.
