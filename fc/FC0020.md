# FC0020 · 핸들러 탐색과 호출 방식의 분리

## 검토 질문

- [ ] 요청에 맞는 핸들러를 찾는 책임과 여러 형태의 핸들러를 호출하는 책임을 분리할 필요가 있는가?

**직접 작성한 예시**

```java
interface HandlerAdapter {
    boolean supports(Object handler);
    HttpReply invoke(Object handler, HttpRequest request);
}
```

**적용 설명:** 핸들러를 찾는 매핑과 호출 방법을 분리한다. supports가 겹칠 때의 선택 규칙과 미지원 처리도 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 요청 탐색 코드가 호출 방식까지 분기한다.
  - **판단 기준:** 핸들러 선택과 실행 방법을 분리할 수 있다.

- [ ] **상황:** 지원 구현이 하나뿐인데 계층이 많다.
  - **판단 기준:** 추가 어댑터가 실제 확장 지점을 만드는지 확인한다.
