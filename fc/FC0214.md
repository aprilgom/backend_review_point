# FC0214 · 유형별 유효 필드와 값의 부재

[소속 분야: 도메인 모델·값 표현](../11-domain-model.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0213](FC0213.md)

## 검토 질문

- [ ] 유형에 따라 쓰지 않는 필드를 기본값으로 채워 부재 의미를 숨기지 않고 유효 조합을 보장하는가?

**직접 작성한 예시**

```sql
CHECK (
  (kind = 'FIXED' AND fixed_amount IS NOT NULL AND rate IS NULL) OR
  (kind = 'RATE' AND rate IS NOT NULL AND fixed_amount IS NULL)
)
```

**적용 설명:** 쿠폰 유형별 유효 필드를 제약으로 표현한 조각이다. kind 자체는 NOT NULL과 허용 값 제약을 별도로 둔다.

## 구체적인 검토 사례

- [ ] **상황:** 유형마다 쓰지 않는 필드를 0으로 채운다.
  - **판단 기준:** 부재와 유효한 0을 구분한다.

- [ ] **상황:** 유형에 맞지 않는 값 조합이 저장된다.
  - **판단 기준:** 필드 간 제약이나 분리된 타입으로 제한한다.
