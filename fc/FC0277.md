## 검토 질문

- [ ] 생성 시 캐시와 조회 미스 시 캐시 중 선택 이유가 명확하고 무효화·동시 미스·부재 정책을 정의했는가?

**직접 작성한 예시**

```java
Product value = cache.get(id);
if (value == null) { value = products.get(id); cache.put(id, value); }
return value;
```

**적용 설명:** cache-aside 형태의 개념 코드다. 동시 미스·오래된 값·부재 캐싱 정책을 보완해야 한다.

## 구체적인 검토 사례

- [ ] **상황:** 생성 시점과 조회 미스 모두에서 캐싱한다.
  - **판단 기준:** 각 적재 방식의 목적을 정한다.

- [ ] **상황:** 동시 미스가 원본 저장소에 몰린다.
  - **판단 기준:** 중복 적재·잠금·오래된 쓰기를 검토한다.
