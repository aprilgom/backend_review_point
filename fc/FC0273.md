# FC0273 · 요청을 처리할 때마다 컨트롤러 인스턴스를 새로 생성해야 하는지 질문했다.

[소속 분야: 성능·측정](../16-performance.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0269](FC0269.md) · [다음 FC: FC0282 →](FC0282.md)

- [ ] 요청을 처리할 때마다 컨트롤러 인스턴스를 새로 생성해야 하는지 질문했다. (설계 질문)
  - 조건: 매 요청 시 인스턴스 생성의 필요성을 묻는 질문이며 성능 결함을 확정한 것은 아니다. 작성자는 디스패처 서블릿에서 컨트롤러를 주입받도록 변경했다고 답했다.

- [ ] 요청을 처리할 때마다 newInstance로 객체를 새로 생성할 필요가 있는지 질문했다. (설계 질문)
  - 조건: 참여자는 요청별 객체 생성이 불필요할 수 있다는 관점에서 필요성을 물었다. 작성자는 Scanner가 생성한 객체를 생성자로 주입받아 사용하도록 수정했다고 보고했다. 성능 측정이나 재사용의 적합성 검증은 제시되지 않았다.

- [ ] RequestMapper를 요청마다 새로 생성해야 하는지 질문했다. (설계 질문)
  - 조건: RequestHandler.run에서 RequestMapper를 생성하는 코드에 대한 질문이다. 재사용 가능 여부, 공유 시의 안전성 또는 실제 생성 비용은 이 대화에서 확인되지 않으며, 특정 재사용 방식을 요구하지도 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
Map<String, Controller> controllers = Map.of("/health", new HealthController());
Controller controller = controllers.get(path);
```

**적용 설명:** 공유 가능한 무상태 컨트롤러라면 생성 비용을 줄일 수 있다. 사용자별 상태를 필드에 두지 않는다.
