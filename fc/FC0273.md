## 검토 질문

- [ ] 같은 역할의 객체를 매 요청마다 만들 필요가 있으며 재사용 시 상태 격리와 동시성도 안전한가?

**직접 작성한 예시**

```java
Map<String, Controller> controllers = Map.of("/health", new HealthController());
Controller controller = controllers.get(path);
```

**적용 설명:** 공유 가능한 무상태 컨트롤러라면 생성 비용을 줄일 수 있다. 사용자별 상태를 필드에 두지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 컨트롤러를 요청마다 새로 만든다.
  - **판단 기준:** 무상태라면 공유 수명을 검토한다.

- [ ] **상황:** 공유 후 요청 간 필드값이 섞인다.
  - **판단 기준:** 상태를 지역 범위로 옮기거나 수명을 분리한다.
