# FC0158 · 저장소 인터페이스의 실질적 가치

## 검토 질문

- [ ] 저장소 추상화가 도메인 계약을 제한하거나 기술 변경을 격리하는지, 단순 전달 계층만 추가하는지 확인했는가?

**직접 작성한 예시**

```java
interface Documents {
    Optional<Document> find(DocumentId id);
    void save(Document document);
}
```

**적용 설명:** 도메인 언어로 저장 계약을 제한하는 예다. 같은 메서드 전달만 추가하는지, 실제 의존 경계를 만드는지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 저장소 인터페이스가 DB API를 그대로 복사한다.
  - **판단 기준:** 도메인이 요구하는 계약으로 좁힐 수 있다.

- [ ] **상황:** 변경 가능성만으로 추상화 계층을 추가한다.
  - **판단 기준:** 현재 격리되는 의존과 비용을 비교한다.
