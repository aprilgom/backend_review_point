# FC0246 · 조회 부재의 명시적 표현

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0243](FC0243.md) · [다음 FC: FC0244 →](FC0244.md)

## 검토 질문

- [ ] 조회 결과가 없을 수 있음을 Optional·예외 등 계약으로 표현하고 호출자가 처리하도록 하는가?

**직접 작성한 예시**

```java
Optional<User> user = users.find(id);
return user.orElseThrow(UserNotFound::new);
```

**적용 설명:** 조회 부재를 저장소 계약에서 드러내고 예외 선택은 호출 맥락에서 한다.

## 구체적인 검토 사례

- [ ] **상황:** 조회 부재를 null로 반환한다.
  - **판단 기준:** 부재 가능성을 타입이나 예외 계약에 드러낸다.

- [ ] **상황:** 저장소가 항상 업무 예외를 결정한다.
  - **판단 기준:** 호출 목적에 따라 부재가 정상일 수도 있다.
