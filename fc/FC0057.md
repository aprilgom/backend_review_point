# FC0057 · 사용자 상태에 따른 화면 이동

[소속 분야: API·공개 인터페이스 계약](../03-api-contract.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0054](FC0054.md) · [다음 FC: FC0058 →](FC0058.md)

## 검토 질문

- [ ] 사용자의 인증·업무 상태에 따라 기대한 화면으로 이동하며 응답 상태와 이동 경로도 맞는가?

**직접 작성한 예시**

```java
if (session.isAuthenticated() && request.path().equals("/login")) {
    return HttpReply.redirect(303, "/home");
}
```

**적용 설명:** 로그인 사용자의 화면 이동 계약 예시다. 실제 응답의 Location 헤더와 로그인하지 않은 경우도 테스트한다.

## 구체적인 검토 사례

- [ ] **상황:** 인증된 사용자가 불필요한 입력 화면에 남는다.
  - **판단 기준:** 상태에 맞는 이동 경로를 검증한다.

- [ ] **상황:** 화면은 바뀌지만 이동 응답이 잘못됐다.
  - **판단 기준:** 상태 코드·위치 헤더·브라우저 흐름을 함께 확인한다.
