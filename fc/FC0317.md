# FC0317 · import 정리의 일관성

## 검토 질문

- [ ] 사용하지 않는 import를 제거하고 정렬·명시적 사용 규칙을 일관되게 적용하는가?

**직접 작성한 예시**

```java
import java.util.List;
import java.util.Map;
```

**적용 설명:** 실제 사용 타입만 명시적으로 import한다. 저장 시 정리 기능과 빌드 검사를 함께 활용할 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 미사용 import가 반복해서 남는다.
  - **판단 기준:** 자동 정리와 검사를 활용할 수 있다.

- [ ] **상황:** 와일드카드 때문에 출처를 알기 어렵다.
  - **판단 기준:** 선택한 팀 규칙에 맞게 명시한다.
