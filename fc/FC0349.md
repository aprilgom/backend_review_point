# FC0349 · 서버와 클라이언트 렌더링의 선택

[소속 분야: 렌더링·데이터 로딩](../18-rendering.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0353](FC0353.md) · [다음 FC: FC0352 →](FC0352.md)

## 검토 질문

- [ ] 화면을 생성하는 위치를 응답 형식·초기 로딩·상호작용·운영 비용에 맞게 선택했는가?

**직접 작성한 예시**

```java
// 서버 렌더링: HTML 문서가 응답 본문이다.
String html = templates.render("tasks", Map.of("tasks", tasks));
// 클라이언트 렌더링: 데이터 계약을 보내고 브라우저가 화면을 만든다.
String json = jsonWriter.write(tasks);
```

**적용 설명:** SSR·CSR의 렌더링 위치를 비교하는 조각이다. 이 코드만으로 실제 Controller 애너테이션 의미를 대체하지 않는다.

## 구체적인 검토 사례

- [ ] SSR과 CSR을 비교하며 @Controller와 @RestController의 차이, 사용 시점과 뷰가 그려지는 위치를 정리해 보도록 제안한다. (개선 제안)
  - 조건: 작성자가 제기한 ResponseEntity와 ResponseBody 관련 질문을 이해하기 위한 학습 관점으로 제시되었다. 특정 구현이 잘못되었다고 확정하거나 질문의 기술적 정답을 제시한 것은 아니다.
