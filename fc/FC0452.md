# FC0452 · JDBC 자원의 해제 범위

[소속 분야: 트랜잭션·자원 수명](../23-transaction.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0451](FC0451.md)

## 검토 질문

- [ ] ResultSet·Statement·Connection 각각의 소유자와 종료 범위를 정하고 예외에도 안전하게 해제하는가?

**직접 작성한 예시**

```java
try (PreparedStatement ps = connection.prepareStatement(sql);
     ResultSet rows = ps.executeQuery()) {
    while (rows.next()) consume(rows);
}
```

**적용 설명:** ResultSet과 Statement를 범위에 포함해 역순 해제한다. 이 조각은 호출자가 소유한 connection을 닫지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** ResultSet을 자원 범위 밖에서 만든다.
  - **판단 기준:** 해제 경로와 소유자를 명시한다.

- [ ] **상황:** 상위 호출자의 Connection까지 닫는다.
  - **판단 기준:** 문장·결과·연결의 수명을 구분한다.
