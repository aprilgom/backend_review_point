## 검토 질문

- [ ] 팀의 공백·들여쓰기·괄호 규칙을 일관되게 적용하고 자동화할 수 있는가?

**직접 작성한 예시**

```java
if (isReady) {
    process();
}
```

**적용 설명:** 팀의 괄호·들여쓰기·공백 규칙을 자동 포맷터와 맞춘다. 스타일 차이를 기능 결함과 구분한다.

## 구체적인 검토 사례

- [ ] **상황:** 공백·들여쓰기 규칙이 파일마다 다르다.
  - **판단 기준:** 선택한 포맷터와 규칙에 맞춘다.

- [ ] **상황:** 서식 변경과 기능 수정을 섞는다.
  - **판단 기준:** 리뷰 범위와 변경 의도를 구분한다.
