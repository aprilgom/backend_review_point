# FC0430 · 저장소 테스트에 필요한 실행 범위

## 검토 질문

- [ ] 저장소만 검증하는 테스트에 전체 앱을 띄울 필요가 있으며 DB·주입 객체·슬라이스 구성을 이해하는가?

**직접 작성한 예시**

```java
@org.springframework.boot.test.autoconfigure.jdbc.JdbcTest
class AccountJdbcTest {
    // JDBC 슬라이스 구성으로 저장소 검증
}
```

**적용 설명:** 기존 제외 목록 밖의 혼합 FC이므로 Spring 사례를 유지했다. Boot 3 계열 패키지 기준 조각이며 사용하는 버전·DB 교체·추가 빈 요구에 맞게 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 저장소 테스트에 전체 앱을 띄운다.
  - **판단 기준:** 필요한 구성만 실행하는 방식을 비교한다.

- [ ] **상황:** 슬라이스로 바꾼 뒤 DB가 자동 교체된다.
  - **판단 기준:** 실제 검증할 DB와 주입 객체를 확인한다.
