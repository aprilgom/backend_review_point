# FC0218 · 값이 없는 키 입력의 파싱

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0222](FC0222.md) · [다음 FC: FC0219 →](FC0219.md)

## 검토 질문

- [ ] 키만 있거나 빈 값·구분 문자가 포함된 입력을 처리하는 규칙이 명확한가?

**직접 작성한 예시**

```java
String[] pair = part.split("=", 2);
String key = pair[0];
String value = pair.length == 2 ? pair[1] : "";
```

**적용 설명:** 키만 있는 입력을 빈 값으로 취급하는 계약 예시다. 디코딩·중복 키·빈 키 정책은 별도로 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 키만 있는 쿼리 문자열을 처리한다.
  - **판단 기준:** 빈 값·잘못된 입력 중 계약을 선택한다.

- [ ] **상황:** 값에 등호나 인코딩 문자가 포함된다.
  - **판단 기준:** 분할과 디코딩 순서를 명확히 한다.
