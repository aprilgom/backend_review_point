# FC0120 · 존재 여부 조회의 양쪽 결과

[소속 분야: 쿼리·데이터 조작](../07-data-query.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0119](FC0119.md) · [다음 FC: FC0122 →](FC0122.md)

## 검토 질문

- [ ] 존재·부재를 모두 테스트해 조회가 항상 같은 참·거짓 값을 반환하는 오류를 잡는가?

**직접 작성한 예시**

```java
assertFalse(bookings.existsForSlot(emptySlot));
bookings.save(newBooking(emptySlot));
assertTrue(bookings.existsForSlot(emptySlot));
```

**적용 설명:** 항상 true인 구현을 잡기 위해 존재·부재를 모두 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 존재하는 데이터만으로 조회를 테스트한다.
  - **판단 기준:** 부재 결과도 확인해 상수 반환 오류를 잡는다.

- [ ] **상황:** 다른 상태의 행이 같은 조건을 공유한다.
  - **판단 기준:** 업무상 대상 행만 존재로 계산하는지 검증한다.
