# FC0207 · 제한된 값 집합의 타입 표현

[소속 분야: 도메인 모델·값 표현](../11-domain-model.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0206](FC0206.md) · [다음 FC: FC0204 →](FC0204.md)

## 검토 질문

- [ ] 지원 값이 닫힌 집합이라면 문자열 대신 enum 등으로 표현하고 확장 요구도 고려했는가?

**직접 작성한 예시**

```java
enum MediaType {
    JSON("application/json"), HTML("text/html");
    final String value;
    MediaType(String value) { this.value = value; }
}
```

**적용 설명:** 지원 집합이 닫혀 있을 때의 예시다. 임의의 확장 미디어 타입을 받아야 하면 enum이 과도한 제약일 수 있다.

## 구체적인 검토 사례

- [ ] 문자열로 지정하는 ContentType을 HttpStatusCode처럼 enum으로 관리하자고 제안했다. (개선 제안)
  - 조건: 작성자는 반영했다고 답했으며, 구체적인 enum 설계나 변경 코드는 대화에 제시되지 않았다.

- [ ] 여러 곳에서 사용될 HTTP 메서드를 하드코딩된 문자열 대신 enum으로 관리하자는 제안이다. (개선 제안)
  - 조건: 코드가 복잡해질수록 문자열을 관리하기 어려워질 수 있다는 우려를 근거로 제안했다. 작성자는 enum으로 수정했다고 답했다.

- [ ] 문자열로 표현한 requestMethod를 enum 타입으로 관리해 관리와 사용을 편하게 만드는 것을 제안했다. (개선 제안)
  - 조건: 작성자는 적용하여 수정했다고 보고했다. 변경 코드의 동작이나 타당성까지 확인된 것은 아니다.
