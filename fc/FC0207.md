# FC0207 · 제한된 값 집합의 타입 표현

[소속 분야: 도메인 모델·값 표현](../11-domain-model.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0206](FC0206.md) · [다음 FC: FC0204 →](FC0204.md)

## 검토 질문

- [ ] 지원 값이 닫힌 집합이라면 문자열 대신 enum 등으로 표현하고 확장 요구도 고려했는가?

**직접 작성한 예시**

```java
enum MediaType {
    JSON("application/json"), HTML("text/html");
    final String value;
    MediaType(String value) { this.value = value; }
}
```

**적용 설명:** 지원 집합이 닫혀 있을 때의 예시다. 임의의 확장 미디어 타입을 받아야 하면 enum이 과도한 제약일 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 닫힌 집합의 값을 문자열로 관리한다.
  - **판단 기준:** enum 등으로 잘못된 값을 줄일 수 있다.

- [ ] **상황:** 외부 확장 값도 계속 들어온다.
  - **판단 기준:** 닫힌 타입이 필요한 확장을 막지 않는지 본다.
