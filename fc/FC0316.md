# FC0316 · 패키지 깊이와 탐색 비용

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0342](FC0342.md) · [다음 FC: FC0336 →](FC0336.md)

## 검토 질문

- [ ] 패키지·모듈 구조의 추가 단계가 역할과 경계를 설명하는지 단순히 탐색 비용만 늘리는지 검토했는가?

**직접 작성한 예시**

```text
domain/
  order/Order.java
  order/OrderId.java
application/
  PlaceOrder.java
```

**적용 설명:** 역할과 탐색 비용을 기준으로 단순화한 구조 예다. 패키지를 줄이는 것 자체보다 의존 방향이 중요하다.

## 구체적인 검토 사례

- [ ] **상황:** 모듈 아래 의미 없는 패키지 층이 생긴다.
  - **판단 기준:** 역할 구분에 도움이 되는지 검토한다.

- [ ] **상황:** 단순화하려고 경계를 모두 합친다.
  - **판단 기준:** 탐색성과 의존 방향을 함께 유지한다.
