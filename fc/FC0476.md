# FC0476 · 로그인 페이지에 연결된 링크로 이동하면 회원가입 페이지가 보이지 않는 문제를 보고하고 확인을 요청했다.

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0480](FC0480.md) · [다음 FC: FC0478 →](FC0478.md)

- [ ] 로그인 페이지에 연결된 링크로 이동하면 회원가입 페이지가 보이지 않는 문제를 보고하고 확인을 요청했다. (문제 보고)
  - 조건: 작성자는 처음에는 정상적으로 보인다고 답했으나, 리뷰 참여자가 로그인 페이지의 링크를 통해 접근한 상황이라고 구체화했다. 이후 작성자는 로그인 페이지 버튼의 엔드포인트를 수정하지 않았던 것이 원인이라며 수정했다고 보고했고, 리뷰 참여자도 후속 댓글에서 동작을 확인했다고 밝혔다. 첨부 이미지의 구체적인 화면 내용은 추정하지 않았다.

- [ ] 로그인한 상태에서 로그인 페이지에 다시 접근해도 인덱스 페이지로 이동하지 않는 문제를 보고했다. (문제 보고)
  - 조건: 이미 로그인한 사용자의 재접근 상황에 한정한 보고다. 이후 승인과 격려만으로 해당 동작이 수정되었다고 판단할 수 없다.

- [ ] 로그인 페이지로 이동할 때 로그인 화면 대신 에러 페이지가 반환되는 문제를 보고하고 확인을 요청했다. (문제 보고)
  - 조건: 리뷰어의 동작 보고이며, 원인이나 수정 결과는 이 대화에 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```html
<a href="/signup">회원가입</a>
```

**적용 설명:** 링크 대상이 실제로 화면을 제공하는지 브라우저 탐색·라우팅 테스트로 확인한다.
