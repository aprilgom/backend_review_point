# FC0476 · 화면 탐색 링크의 실제 동작

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0480](FC0480.md) · [다음 FC: FC0478 →](FC0478.md)

## 검토 질문

- [ ] 링크가 의도한 화면으로 연결되고 직접 접근·라우팅·권한 상태에서도 동작하는가?

**직접 작성한 예시**

```html
<a href="/signup">회원가입</a>
```

**적용 설명:** 링크 대상이 실제로 화면을 제공하는지 브라우저 탐색·라우팅 테스트로 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 링크는 있지만 대상 화면이 열리지 않는다.
  - **판단 기준:** 실제 라우팅·권한 상태에서 탐색한다.

- [ ] **상황:** 직접 주소 접근만 실패한다.
  - **판단 기준:** 새로고침과 서버 경로 처리도 확인한다.
