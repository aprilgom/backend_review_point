# FC0165 · 구현하는 인터페이스의 의미

## 검토 질문

- [ ] 클래스가 실제 제공하는 기능과 구현한 인터페이스의 이름·계약이 일치하는가?

**직접 작성한 예시**

```java
interface Users { User find(UserId id); }
final class AppUsers implements Users {
    public User find(UserId id) { return store.get(id); }
}
```

**적용 설명:** 범용 Service보다 실제 제공 기능의 계약을 구현한다. store 필드와 생성자는 생략했다.

## 구체적인 검토 사례

- [ ] **상황:** 구현 클래스가 지나치게 범용 계약을 따른다.
  - **판단 기준:** 제공하는 역할에 맞는 인터페이스를 선택한다.

- [ ] **상황:** 이름은 같은데 동작 의미가 다르다.
  - **판단 기준:** 대체 가능성을 메서드 형태 이상으로 검증한다.
