# FC0290 · 중복 존재 검사와 값 조회

[소속 분야: 성능·측정](../16-performance.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0278](FC0278.md)

## 검토 질문

- [ ] 같은 키의 존재 여부와 값을 반복 조회하지 않도록 단순화할 수 있으며 null 계약도 유지하는가?

**직접 작성한 예시**

```java
String sessionId = cookies.get("SESSION");
if (sessionId != null) loadSession(sessionId);
```

**적용 설명:** null 값을 저장하지 않는 Map이라는 전제에서 중복 존재 검사를 줄인다.

## 구체적인 검토 사례

- [ ] hasJsessionId()의 키 존재 검사와 getValue() 내부의 containsKey() 검사가 중복된다. (관찰)
  - 조건: 작성자는 의도한 구현이 아니라 실수라고 답했다. 실제 수정 여부는 이 대화에서 확인되지 않는다.
