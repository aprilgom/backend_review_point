## 검토 질문

- [ ] 전체 데이터를 메모리에 올린 뒤 거르지 않고 필요한 조건을 저장소 조회에 반영할 수 있는가?

**직접 작성한 예시**

```sql
SELECT id, starts_at FROM slot WHERE day = :day AND available = TRUE;
```

**적용 설명:** 필요한 범위를 DB에서 제한한다. available이 저장값인지 계산값인지에 따라 실제 조회를 설계한다.

## 구체적인 검토 사례

- [ ] **상황:** 전체 행을 가져와 메모리에서 필터링한다.
  - **판단 기준:** 필요한 조건을 DB에 전달할 수 있다.

- [ ] **상황:** 필터를 옮겨 부재·NULL 의미가 달라진다.
  - **판단 기준:** 결과 계약이 같은지 검증한다.
