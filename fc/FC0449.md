# FC0449 · 외부 연동 확인과 반복 테스트의 분리

## 검토 질문

- [ ] 실제 외부 계약 확인은 유지하면서 일반 테스트가 외부 상태·호출 제한에 좌우되지 않도록 분리했는가?

**직접 작성한 예시**

```java
@Tag("external-contract")
@Test void remoteSandboxMatchesContract() { verifyRemoteContract(); }
```

**적용 설명:** 외부 연동 확인을 별도 태그로 분리하고 일반 테스트는 통제된 대역을 사용한다. 자격증명·호출 제한·실행 조건을 명시한다.

## 구체적인 검토 사례

- [ ] **상황:** 모든 테스트가 실제 외부 API를 호출한다.
  - **판단 기준:** 통제된 대역과 별도 계약 검증을 나눈다.

- [ ] **상황:** 대역만 사용해 외부 변경을 놓친다.
  - **판단 기준:** 제한된 환경에서 실제 계약도 주기적으로 확인한다.
