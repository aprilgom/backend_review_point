# FC0347 · 브라우저의 추가 리소스 요청

[소속 분야: 렌더링·데이터 로딩](../18-rendering.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0344](FC0344.md) · [다음 FC: FC0348 →](FC0348.md)

## 검토 질문

- [ ] HTML 이후 CSS·JS 등 추가 요청이 발생하는 흐름과 서버의 경로·캐시·제공 설정을 확인했는가?

**직접 작성한 예시**

```html
<link rel="stylesheet" href="/assets/site.css">
<script src="/assets/site.js" defer></script>
```

**적용 설명:** 브라우저는 HTML을 해석하며 참조 리소스를 추가 요청한다. 서버 라우팅·캐시·리소스 경로를 함께 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** HTML이 열리면 정적 파일도 성공했다고 본다.
  - **판단 기준:** 브라우저의 추가 요청을 확인한다.

- [ ] **상황:** CSS·JS 요청이 다른 경로로 실패한다.
  - **판단 기준:** base path·매핑·캐시를 개별 점검한다.
