# FC0357 · 입력 추출과 저장 실행의 분리

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0366](FC0366.md) · [다음 FC: FC0382 →](FC0382.md)

## 검토 질문

- [ ] 요청을 해석하는 과정이 저장 등 부작용까지 일으키지 않도록 역할을 나누었는가?

**직접 작성한 예시**

```java
CreateUserCommand command = requestParser.parse(request);
User user = userService.create(command);
```

**적용 설명:** 입력 해석과 저장 실행을 분리한다. 파서는 DB 변경을 일으키지 않는다는 계약이다.

## 구체적인 검토 사례

- [ ] **상황:** 요청 파싱 중 DB 저장까지 실행한다.
  - **판단 기준:** 입력 해석과 업무 실행을 나눈다.

- [ ] **상황:** 파싱 실패 뒤 일부 데이터가 남는다.
  - **판단 기준:** 부작용 시작 시점과 원자성을 확인한다.
