# FC0091 · 저장소 제외 규칙의 배치

## 검토 질문

- [ ] 공통·모듈별 제외 규칙의 역할이 분명하고 필요한 파일이 누락되거나 산출물이 잘못 추적되지 않는가?

**직접 작성한 예시**

```gitignore
# 저장소 루트 .gitignore 예
**/build/
**/.gradle/
.env.local
```

**적용 설명:** 공통 규칙은 루트에 두고 모듈 특수 규칙만 별도 파일로 둘 수 있다. 이미 추적 중인 파일은 ignore만으로 제외되지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 모듈마다 제외 파일이 반복된다.
  - **판단 기준:** 공통 규칙과 모듈 특수 규칙을 나눈다.

- [ ] **상황:** 이미 추적된 산출물에 제외 규칙만 추가한다.
  - **판단 기준:** 기존 추적 상태를 별도로 확인한다.
