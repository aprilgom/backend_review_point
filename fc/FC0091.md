# FC0091 · 각 모듈마다 .gitignore 파일이 생성된 이유를 질문했다.

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0088](FC0088.md) · [다음 FC: FC0094 →](FC0094.md)

- [ ] 각 모듈마다 .gitignore 파일이 생성된 이유를 질문했다. (설계 질문)
  - 조건: 작성자는 각 도메인 모듈이 별도 프로젝트처럼 분리되어 생긴 것 같다고 추측하며 추가 확인이 필요하다고 답했다. 리뷰어도 모듈 생성 방법에 따라 생길 수 있다고 추측했다. 생성 원인이 확정되거나 파일 삭제를 요구한 것은 아니다.

- [ ] 불필요한 파일이 많이 보여 gitignore가 제대로 동작하는지 점검할 필요를 제기했다. (위험 지적)
  - 조건: 불필요한 파일이 보인다는 지적이며, 원인이 실제로 gitignore의 동작 문제인지는 추정으로 표현했다. 구체적인 파일 목록이나 후속 조치는 제시되지 않았다.

- [ ] .gitignore에서 제외 대상으로 지정한 파일 중 무시하면 안 될 것으로 보이는 파일이 있다고 지적했다. (개선 제안)
  - 조건: 작성자는 수정했다고 답했으나, 제공된 본문에는 대상 파일명이나 제외하면 안 되는 이유가 없다. 구체적인 파일과 변경의 적절성은 추가 확인이 필요하다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```gitignore
# 저장소 루트 .gitignore 예
**/build/
**/.gradle/
.env.local
```

**적용 설명:** 공통 규칙은 루트에 두고 모듈 특수 규칙만 별도 파일로 둘 수 있다. 이미 추적 중인 파일은 ignore만으로 제외되지 않는다.
