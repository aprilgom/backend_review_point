# FC0384 · DAO와 Repository의 책임 차이

## 검토 질문

- [ ] 테이블 행 접근과 도메인 저장 계약의 차이를 이해하고 이름·구현·계층을 일관되게 선택했는가?

**직접 작성한 예시**

```java
interface Orders { Optional<Order> find(OrderId id); }
interface OrderRows { Optional<OrderRow> selectById(long id); }
```

**적용 설명:** 도메인 컬렉션 같은 계약과 테이블 행 접근 계약의 차이를 보인다. 두 계층을 항상 동시에 만들 필요는 없다.

## 구체적인 검토 사례

- [ ] **상황:** DAO와 Repository라는 이름만 다르게 쓴다.
  - **판단 기준:** 행 접근과 도메인 저장 역할을 설명한다.

- [ ] **상황:** 두 계층을 항상 함께 만든다.
  - **판단 기준:** 필요한 변환·정책이 있을 때만 분리한다.
