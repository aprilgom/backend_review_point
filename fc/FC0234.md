# FC0234 · 필수 관계의 DB 표현

## 검토 질문

- [ ] 항상 필요한 연관 값에 NOT NULL·외래 키 등 적절한 제약을 설정했는가?

**직접 작성한 예시**

```sql
CREATE TABLE booking (
  id BIGINT PRIMARY KEY,
  slot_id BIGINT NOT NULL REFERENCES slot(id),
  theme_id BIGINT NOT NULL REFERENCES theme(id)
);
```

**적용 설명:** 항상 필요한 연관관계를 NOT NULL과 외래 키로 표현한다.

## 구체적인 검토 사례

- [ ] **상황:** 필수 연관 ID가 비어 있는 행이 저장된다.
  - **판단 기준:** NOT NULL과 참조 제약을 함께 검토한다.

- [ ] **상황:** 제약 추가 전 잘못된 데이터가 남아 있다.
  - **판단 기준:** 데이터 정리와 적용 순서를 마련한다.
