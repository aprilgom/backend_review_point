# FC0131 · 연관관계의 참조 방향

## 검토 질문

- [ ] 어떤 객체가 다른 객체를 알아야 하는지 탐색·생명주기·책임을 기준으로 정했는가?

**직접 작성한 예시**

```java
record Payment(BookingId bookingId, Money amount) {}
```

**적용 설명:** 결제가 어떤 예약을 위한 것인지 탐색하는 방향을 표현한다. 양쪽이 반드시 서로 참조해야 하는 것은 아니다.

## 구체적인 검토 사례

- [ ] **상황:** 양쪽 객체가 서로를 참조한다.
  - **판단 기준:** 실제 탐색과 생명주기 요구를 확인한다.

- [ ] **상황:** 한 방향만 알면 되는 작업이다.
  - **판단 기준:** 불필요한 역참조를 제거해 결합을 줄일 수 있다.
