# FC0382 · 공통 예외 처리의 책임 분리

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0357](FC0357.md) · [다음 FC: FC0377 →](FC0377.md)

## 검토 질문

- [ ] 컨트롤러마다 반복되는 오류 응답 처리를 적절한 경계로 모아 업무 처리와 분리할 수 있는가?

**직접 작성한 예시**

```java
try { return controller.handle(request); }
catch (AppFailure failure) { return errorMapper.toReply(failure); }
```

**적용 설명:** 예외 응답 매핑을 요청 경계에서 공통 처리한다. ControllerAdvice는 이를 구현하는 한 프레임워크 수단이다.

## 구체적인 검토 사례

- [ ] **상황:** 컨트롤러마다 같은 예외 변환이 반복된다.
  - **판단 기준:** 공통 요청 경계로 모을 수 있다.

- [ ] **상황:** 모든 오류를 하나의 응답으로 축약한다.
  - **판단 기준:** 실패 종류별 의미와 상태를 보존한다.
