# FC0222 · 중복 검증 제약의 정리

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0221](FC0221.md) · [다음 FC: FC0218 →](FC0218.md)

## 검토 질문

- [ ] 여러 검증 제약의 보장 범위가 겹친다면 그룹·메시지 차이를 확인한 뒤 중복을 줄일 수 있는가?

**직접 작성한 예시**

```java
record Form(@jakarta.validation.constraints.NotBlank String title) {}
```

**적용 설명:** NotBlank는 null과 공백 문자열을 모두 거절한다. 검증 그룹·메시지를 별도로 쓰는 경우까지 동일한지는 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** null을 이미 거절하는 제약을 중복 선언한다.
  - **판단 기준:** 그룹·메시지가 같다면 중복을 줄일 수 있다.

- [ ] **상황:** 겉보기만 같은 제약을 제거한다.
  - **판단 기준:** 공백·길이·null의 실제 검사 범위를 비교한다.
