## 검토 질문

- [ ] 같은 의미의 경로나 설정값이 여러 곳에서 중복 정의되어 변경 시 어긋날 가능성은 없는가?

**직접 작성한 예시**

```java
final class TemplatePaths {
    static final Path ROOT = Path.of("views");
    private TemplatePaths() {}
}
```

**적용 설명:** 같은 의미의 경로가 여러 곳에 흩어졌을 때 공유한다. 배포 환경마다 다르면 상수 대신 설정으로 주입한다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 리소스 경로가 여러 파일에 흩어져 있다.
  - **판단 기준:** 같은 의미의 값은 한 정의를 사용한다.

- [ ] **상황:** 환경마다 달라지는 값을 상수로 고정한다.
  - **판단 기준:** 환경별 값은 설정으로 공급하고 시작 시 검증한다.
