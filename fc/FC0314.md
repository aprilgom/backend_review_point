# FC0314 · 미사용 구현의 제거

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0307](FC0307.md) · [다음 FC: FC0325 →](FC0325.md)

## 검토 질문

- [ ] 호출되지 않는 구현을 동적 사용까지 확인한 뒤 제거하고 공개 동작 검증을 유지하는가?

**직접 작성한 예시**

```java
// 삭제 후에도 공개 동작 검증이 유지되는지 확인
assertEquals(expected, service.execute(input));
```

**적용 설명:** 미사용 코드 제거의 검증 형태다. 호출 검색만으로 동적 사용까지 없다고 단정하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 사용하지 않는 구현이 계속 남는다.
  - **판단 기준:** 호출·동적 사용 확인 후 제거한다.

- [ ] **상황:** 정리 후 공개 동작 테스트도 사라진다.
  - **판단 기준:** 필요한 계약 검증은 유지한다.
