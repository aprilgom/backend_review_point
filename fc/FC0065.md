# FC0065 · 응답 본문과 Content-Type

## 검토 질문

- [ ] 클라이언트가 본문 형식을 정확히 해석하도록 응답 미디어 타입을 명시했는가?

**직접 작성한 예시**

```http
HTTP/1.1 200 OK
Content-Type: application/json

{"state":"ready"}
```

**적용 설명:** 전송할 본문의 형식을 헤더에 명시한다. 클라이언트가 헤더를 보고 올바른 파서를 선택하는지도 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** JSON 본문인데 미디어 타입이 누락된다.
  - **판단 기준:** 클라이언트가 올바른 파서를 선택하도록 명시한다.

- [ ] **상황:** 문자 인코딩이 본문과 맞지 않는다.
  - **판단 기준:** 헤더뿐 아니라 실제 인코딩도 확인한다.
