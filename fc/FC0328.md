## 검토 질문

- [ ] 파일 끝 개행 등 저장 형식이 팀·도구 규칙과 일치하는가?

**직접 작성한 예시**

```java
class Example {
}
```

**적용 설명:** 표시된 마지막 줄 뒤에도 실제 파일은 LF로 끝나도록 저장한다. 문서 렌더링만으로 EOF 개행을 판별하지 않는다.

## 구체적인 검토 사례

- [ ] 파일 끝에 개행을 추가하는 코드 형식에 주의하도록 제안했다. (개선 제안)
  - 조건: 리뷰어는 유닉스 표준의 줄 정의를 근거로 설명했다. 외부 링크의 내용을 별도로 확인하거나 실행상 결함으로 확대하지 않는다.

- [ ] 테스트 파일 끝의 개행을 챙기자고 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 Git 줄 끝 처리 문서를 참고 링크로 제시했고 작성자는 취지를 이해했다고 답했다. 개행이 필요한 구체적인 기술적 이유는 댓글 본문에 설명되어 있지 않아 링크 내용을 보충하지 않았다.

- [ ] 파일 마지막에 개행이 없는 곳이 여러 군데 있다고 지적한다. (문제 보고)
  - 조건: CouponDaoTest.java에 남긴 인라인 댓글에서 여러 파일의 끝 개행 누락을 보고했다. 구체적인 전체 대상 목록이나 수정 여부는 제시되지 않았다.
