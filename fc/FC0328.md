# FC0328 · 파일 종료 형식의 일관성

## 검토 질문

- [ ] 파일 끝 개행 등 저장 형식이 팀·도구 규칙과 일치하는가?

**직접 작성한 예시**

```java
class Example {
}
```

**적용 설명:** 표시된 마지막 줄 뒤에도 실제 파일은 LF로 끝나도록 저장한다. 문서 렌더링만으로 EOF 개행을 판별하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 파일 끝 개행이 누락된다.
  - **판단 기준:** 팀과 도구의 저장 형식을 맞춘다.

- [ ] **상황:** 렌더링 화면으로만 개행을 판단한다.
  - **판단 기준:** 실제 파일 끝 바이트를 확인한다.
