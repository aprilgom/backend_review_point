# FC0027 · 조회 결과 매핑의 재사용

## 검토 질문

- [ ] 여러 쿼리의 결과를 같은 객체로 변환하는 규칙을 재사용하면서 컬럼·NULL 계약의 차이도 처리하는가?

**직접 작성한 예시**

```java
User mapUser(ResultSet row) throws SQLException {
    return new User(row.getLong("id"), row.getString("name"));
}
```

**적용 설명:** 순수 JDBC 결과 매핑을 재사용한다. 조회 컬럼 별칭·NULL 처리 계약이 다른 쿼리에는 그대로 적용하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 조회마다 같은 행 매핑을 다시 작성한다.
  - **판단 기준:** 컬럼과 NULL 계약이 같은 경우 재사용한다.

- [ ] **상황:** 서로 다른 조인 결과에 같은 매퍼를 적용한다.
  - **판단 기준:** 컬럼 별칭·부재 값 차이를 먼저 확인한다.
