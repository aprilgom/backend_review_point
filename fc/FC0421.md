# FC0421 · 테스트 유형별 구성 범위

## 검토 질문

- [ ] 서버·포트·DB 같은 설정을 실제로 필요한 테스트에만 제공하고 구성 차이를 설명할 수 있는가?

**직접 작성한 예시**

```java
record TestConfig(int httpPort, DataSource dataSource) {}
TestConfig acceptance = new TestConfig(0, isolatedTestDataSource);
```

**적용 설명:** HTTP 포트와 DB가 필요한 테스트에만 해당 설정을 제공한다. 순수 단위 테스트는 서버 설정을 요구하지 않게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 순수 단위 테스트에도 서버 설정이 필요하다.
  - **판단 기준:** 테스트 유형별 구성을 줄인다.

- [ ] **상황:** 인수 테스트만 특별한 설정을 쓴다.
  - **판단 기준:** 실제 대상 환경과 차이가 필요한 이유를 확인한다.
