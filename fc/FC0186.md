# FC0186 · 양방향 의존의 비대칭 추상화

## 검토 질문

- [ ] 한 방향만 인터페이스로 바꾼 뒤에도 반대 의존으로 결합이나 순환이 남아 있지 않은가?

**직접 작성한 예시**

```java
interface TableAvailability { boolean isOpen(TableId id); }
OrderService service = new OrderService(tableAvailability);
```

**적용 설명:** 한쪽 경계에서 필요한 역할만 추출한다. 반대 방향 의존이 남아 있으면 여전히 순환하는지 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 한 방향만 인터페이스로 분리했다.
  - **판단 기준:** 역방향 참조로 순환이 남았는지 확인한다.

- [ ] **상황:** 추상화가 많아도 같이 수정된다.
  - **판단 기준:** 공유 변경 이유와 경계를 다시 살핀다.
