# FC0196 · 설계 선택 이유의 기록

## 검토 질문

- [ ] 변경 내용뿐 아니라 해결하려는 문제·대안·선택 이유·검증 결과를 함께 기록했는가?

**직접 작성한 예시**

```text
문제: 외부 전송 실패가 주문 저장까지 되돌리고 있었다.
선택: 저장 후 발송 작업을 별도 큐에 기록한다.
검증: 재시도 중 중복 발송 여부를 확인한다.
```

**적용 설명:** 변경·선택 이유·검증을 함께 쓰는 설명 템플릿이다. 실제 구현하지 않은 내용을 완료로 쓰지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 변경 목록만 리뷰 설명에 적는다.
  - **판단 기준:** 문제·선택 이유·검증을 함께 기록한다.

- [ ] **상황:** 대안을 고려했지만 근거가 없다.
  - **판단 기준:** 다른 선택이 나아지는 조건도 남긴다.
