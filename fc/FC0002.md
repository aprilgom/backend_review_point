# FC0002 · 테스트 실행 코드의 공통화

## 검토 질문

- [ ] 여러 테스트에서 반복되는 실행 코드를 추출하면서 각 테스트의 입력과 기대 결과를 명확히 유지할 수 있는가?

**직접 작성한 예시**

```java
Response createLabel(String name) {
    return api.post("/labels", new LabelInput(name));
}
assertEquals(201, createLabel("study").status());
```

**적용 설명:** api는 테스트용 HTTP 도우미다. 요청 구성만 재사용하고 테스트마다 기대 결과는 드러낸다.

## 구체적인 검토 사례

- [ ] **상황:** 여러 테스트가 같은 요청을 반복 작성한다.
  - **판단 기준:** 실행 절차는 묶고 입력과 기대값은 호출부에 남긴다.

- [ ] **상황:** 도우미가 단언까지 모두 숨긴다.
  - **판단 기준:** 실패 이유와 검증 의도를 직접 읽을 수 있게 한다.
