# FC0231 · 공개 변경 메서드의 제약 보장

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0230](FC0230.md) · [다음 FC: FC0237 →](FC0237.md)

## 검토 질문

- [ ] 외부에서 호출 가능한 모든 변경 경로가 불변식을 지키며 직접 컬렉션 변경으로 우회할 수 없는가?

**직접 작성한 예시**

```java
void addProduct(Product product) {
    requirePriceWithinLimit(product.price());
    products.add(product);
}
```

**적용 설명:** 공개 변경 메서드도 제약을 보장해야 한다. 외부에서 컬렉션을 직접 수정할 수 없도록 한다.

## 구체적인 검토 사례

- [ ] **상황:** 공개 추가 메서드가 생성 제약을 우회한다.
  - **판단 기준:** 모든 변경 경로에서 불변식을 지킨다.

- [ ] **상황:** 내부 목록을 반환해 외부가 직접 수정한다.
  - **판단 기준:** 읽기 전용 뷰나 복사본을 제공할 수 있다.
