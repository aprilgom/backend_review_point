# FC0168 · 표현 계층의 저장 구현 의존

## 검토 질문

- [ ] 컨트롤러가 특정 DB 구현에 직접 결합하지 않도록 필요한 계약과 조립 위치를 분리했는가?

**직접 작성한 예시**

```java
CartController(Carts carts) { this.carts = carts; }
CartController controller = new CartController(new SqlCarts(dataSource));
```

**적용 설명:** 컨트롤러가 특정 DB 제품 구현을 직접 지정하지 않도록 조립 위치로 옮긴다.

## 구체적인 검토 사례

- [ ] **상황:** 컨트롤러에 DB 제품 전용 구현을 넣는다.
  - **판단 기준:** 필요한 역할이나 서비스 경계로 의존을 좁힌다.

- [ ] **상황:** 구현 선택이 여러 호출부에 흩어진다.
  - **판단 기준:** 조립 지점에서 한 번 결정하게 한다.
