# FC0318 · 사용하지 않는 주석 처리된 코드를 삭제하도록 요청했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0334](FC0334.md) · [다음 FC: FC0337 →](FC0337.md)

- [ ] 사용하지 않는 주석 처리된 코드를 삭제하도록 요청했다. (개선 제안)
  - 조건: 작성자는 삭제하겠다고 답했으며, 실제 삭제 여부는 대화만으로 확인되지 않는다.

- [ ] 주석 처리되어 사용하지 않는 코드는 가능하면 바로 제거하자고 제안한다. (개선 제안)
  - 조건: OrderLineItemRequest의 주석 처리된 코드를 대상으로 한 정리 제안이며, 실제 제거 여부는 확인되지 않는다.

- [ ] 주석 처리된 SectionStationResultMap 파일을 사용하지 않는다면 삭제하는 것을 제안한다. (조건부 제안)
  - 조건: 사용하지 않는 파일이라는 조건이 붙은 제안이며, 실제 사용 여부나 삭제 결과는 확인되지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
Price price = calculator.calculate(input);
return price; // 이전 구현을 주석 덩어리로 남기지 않는다.
```

**적용 설명:** 과거 구현은 버전 이력에서 확인하고 현재 코드의 의도를 명확히 한다.
