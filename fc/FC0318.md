## 검토 질문

- [ ] 사용하지 않는 이전 구현을 주석으로 쌓아 현재 코드의 의도를 흐리지 않는가?

**직접 작성한 예시**

```java
Price price = calculator.calculate(input);
return price; // 이전 구현을 주석 덩어리로 남기지 않는다.
```

**적용 설명:** 과거 구현은 버전 이력에서 확인하고 현재 코드의 의도를 명확히 한다.

## 구체적인 검토 사례

- [ ] **상황:** 이전 구현을 주석으로 길게 남긴다.
  - **판단 기준:** 현재 동작만 읽히도록 정리한다.

- [ ] **상황:** 변경 이유까지 모두 삭제한다.
  - **판단 기준:** 필요한 이유는 주석·기록으로 보존한다.
