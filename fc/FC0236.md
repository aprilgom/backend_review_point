# FC0236 · 기간 계산의 포함·제외 경계

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0239](FC0239.md) · [다음 FC: FC0225 →](FC0225.md)

## 검토 질문

- [ ] 발급일·시작일·종료일을 포함하는지 명확하고 날짜 단위 기간과 시간 단위 기간을 구분하는가?

**직접 작성한 예시**

```java
LocalDate lastUsableDay = issuedOn.plusDays(6);
boolean usable = !today.isBefore(issuedOn) && !today.isAfter(lastUsableDay);
```

**적용 설명:** 발급일 포함 7일이라는 날짜 단위 계약이다. 시각 단위 168시간 계약과 구분한다.

## 구체적인 검토 사례

- [ ] 발급일을 포함해 7일간 사용할 수 있는 쿠폰이라면 만료일 계산에서 7일이 아니라 6일을 더해야 하는지 확인했다. (설계 질문)
  - 조건: 작성자는 계산 실수였다고 인정하고 6일을 더하도록 반영했다고 보고했다. 실제 변경 결과는 이 대화만으로 검증되지 않았다.

- [ ] 쿠폰을 시작일 00:00:00.000000부터 종료일 23:59:59.999999까지 발급할 수 있다는 시간 경계 요구사항을 반영하도록 요청한다. (개선 제안)
  - 조건: 작성자는 기존 validate만으로는 해당 요구사항을 충족하지 못한다고 인정하고 반영했다고 보고했다. 변경된 코드나 경계 동작 검증 결과는 이 대화에 제시되지 않았다.

- [ ] 존재하지 않는 날짜인 2026-02-31이 2026-02-28로 자동 보정되는 경우를 어떻게 처리할지 검토한다. (위험 지적)
  - 조건: 리뷰 참여자는 p4 의견으로 날짜 자동 보정 사례를 제시했다. 작성자는 의도하지 않은 날짜로 예약될 위험을 이유로 STRICT 적용, uuuu 패턴 변경, 해당 날짜 테스트 추가를 했다고 보고했다. 변경의 실제 동작은 대화에서 확인되지 않는다.
