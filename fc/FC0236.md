# FC0236 · 기간 계산의 포함·제외 경계

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0239](FC0239.md) · [다음 FC: FC0225 →](FC0225.md)

## 검토 질문

- [ ] 발급일·시작일·종료일을 포함하는지 명확하고 날짜 단위 기간과 시간 단위 기간을 구분하는가?

**직접 작성한 예시**

```java
LocalDate lastUsableDay = issuedOn.plusDays(6);
boolean usable = !today.isBefore(issuedOn) && !today.isAfter(lastUsableDay);
```

**적용 설명:** 발급일 포함 7일이라는 날짜 단위 계약이다. 시각 단위 168시간 계약과 구분한다.

## 구체적인 검토 사례

- [ ] **상황:** 시작일 포함 기간을 하루 길게 계산한다.
  - **판단 기준:** 포함·제외 경계를 예제로 검증한다.

- [ ] **상황:** 날짜 7일을 항상 168시간으로 계산한다.
  - **판단 기준:** 시간대와 일광절약 등 실제 기간 의미를 고려한다.
