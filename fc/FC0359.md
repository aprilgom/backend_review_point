## 검토 질문

- [ ] 응답 값 표현이 라우팅·핸들러 선택·실행까지 담당하지 않도록 분리했는가?

**직접 작성한 예시**

```java
Handler handler = routes.find(request);
HttpReply reply = handler.handle(request);
writer.write(reply);
```

**적용 설명:** 응답 값 객체가 라우팅과 실행까지 맡지 않도록 역할을 나눈다.

## 구체적인 검토 사례

- [ ] **상황:** 응답 객체가 처리기를 찾고 실행한다.
  - **판단 기준:** 응답 표현과 요청 실행을 분리한다.

- [ ] **상황:** 분리 후 오류 응답 책임이 불명확하다.
  - **판단 기준:** 오류 매핑과 실제 출력 경계도 정한다.
