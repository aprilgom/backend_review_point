# FC0249 · 공개 오류와 내부 진단의 분리

[소속 분야: 예외·실패 계약](../13-errors.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0251](FC0251.md) · [다음 FC: FC0252 →](FC0252.md)

## 검토 질문

- [ ] 상세 원인은 통제된 로그에 남기고 사용자에게는 안전한 메시지와 추적 수단을 제공하는가?

**직접 작성한 예시**

```java
String incidentId = newIncidentId();
logFailure(incidentId, failure);
return error(500, "INTERNAL_ERROR", incidentId);
```

**적용 설명:** 상세 원인은 통제된 로그에 남기고 응답에는 추적 ID와 일반 코드를 준다.

## 구체적인 검토 사례

- [ ] **상황:** 예상 밖 예외 메시지를 응답에 넣는다.
  - **판단 기준:** 상세 원인은 통제된 로그로 분리한다.

- [ ] **상황:** 안전한 메시지만 남겨 추적이 불가능하다.
  - **판단 기준:** 응답과 로그를 연결하는 식별자를 제공한다.
