# FC0127 · 조인 종류와 누락 데이터

## 검토 질문

- [ ] 내부 조인과 외부 조인의 차이를 이해하고 연관 데이터가 없을 때 원하는 결과가 나오는가?

**직접 작성한 예시**

```sql
SELECT b.id, s.starts_at
FROM booking b LEFT JOIN slot s ON s.id = b.slot_id;
```

**적용 설명:** 슬롯이 없는 행도 남기는 계약이다. INNER JOIN과 NULL 처리 결과를 실제 데이터로 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 연관 데이터가 없는 행이 조회에서 사라진다.
  - **판단 기준:** 내부 조인이 의도한 제외인지 확인한다.

- [ ] **상황:** 외부 조인 뒤 조건이 다시 행을 제거한다.
  - **판단 기준:** 조건 위치와 NULL 의미를 확인한다.
