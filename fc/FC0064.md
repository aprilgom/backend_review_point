# FC0064 · 직접 사용하지 않는 기본 생성자의 접근 제한자를 public에서 protected로 변경할 것을 제안한다.

[소속 분야: API·공개 인터페이스 계약](../03-api-contract.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0066](FC0066.md) · [다음 FC: FC0067 →](FC0067.md)

- [ ] 직접 사용하지 않는 기본 생성자의 접근 제한자를 public에서 protected로 변경할 것을 제안한다. (개선 제안)
  - 조건: MenuGroup의 기본 생성자에 달린 의견이며, 리뷰 참여자는 전체적으로 사용되지 않는 생성자들에 같은 변경을 제안했다. 실제 사용 여부나 변경 결과는 대화에서 추가 확인되지 않는다.

- [ ] 기본 생성자를 직접 사용하지 않는다면 접근 수준을 public에서 protected로 제한하는 것을 제안한다. (조건부 제안)
  - 조건: 직접 사용하지 않는 경우라는 조건이 있다. 리뷰 참여자는 Spring Data가 사용하는 생성자는 private만 아니면 될 것이라고 설명하고 관련 문서 읽기를 권했지만, 그 기술적 주장을 이 대화에서 검증한 것은 아니다.

- [ ] User의 기본 생성자를 private으로 바꾸어 외부에 허용하는 객체 생성 API를 제한하자는 제안이다. (개선 제안)
  - 조건: 공개 기본 생성자의 접근 수준에 관한 제안이다. 작성자의 답변이나 변경 결과는 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
class Customer {
    protected Customer() {} // 영속화 도구용
    public Customer(String name) { this.name = requireName(name); }
}
```

**적용 설명:** 직접 호출하지 않는 기본 생성자의 노출 범위를 제한한다. 사용하는 매핑 도구의 접근 요구는 확인해야 한다.
