# FC0477 · 정상 사용자 흐름의 회귀 검증

[소속 분야: UI 동작·사용성](../25-ui-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0478](FC0478.md) · [다음 FC: FC0472 →](FC0472.md)

## 검토 질문

- [ ] 정상 조건의 생성·수정·삭제 흐름도 실제로 동작하는지 확인해 과도한 검증과 연결 오류를 잡는가?

**직접 작성한 예시**

```java
SlotId unused = slots.save(sampleSlot()).id();
assertDoesNotThrow(() -> slotService.delete(unused));
assertFalse(slots.exists(unused));
```

**적용 설명:** 사용 중이지 않은 슬롯 삭제의 정상 경로도 검증해 과도한 거절 조건을 잡는다.

## 구체적인 검토 사례

- [ ] 예약이 걸려 있지 않은 시간 슬롯을 삭제하려 해도 오류가 발생한다고 보고했다. (문제 보고)
  - 조건: 오류의 원인이나 응답 내용은 제시되지 않았다. 작성자는 이후 schedule CRD 기능 추가를 보고했지만, 이 삭제 오류의 해결 여부를 별도로 확인한 근거는 없다.

- [ ] 회원가입 기능도 동작하지 않는 것으로 보인다며 확인을 요청했다. (문제 보고)
  - 조건: 최초 보고는 '작동하지 않는 것 같다'는 유보적인 표현이며 재현 입력이나 오류 내용은 제시되지 않았다. 작성자는 메서드 매핑 오류를 언급했고 리뷰 참여자는 이후 전체 기능 동작을 확인했다고 했지만, 회원가입에 대한 개별 수정 내용은 확인되지 않는다.

- [ ] 시간 관리 화면의 기능들이 동작하지 않는 것으로 보인다며 확인과 수정을 요청한다. (문제 보고)
  - 조건: 리뷰 참여자가 관찰한 동작 문제이며 구체적인 실패 기능은 본문에 명시되지 않았다. 작성자는 IDE 일괄 변경 가능성을 인정했지만 기능 수정 완료를 보고하지는 않았다. 첨부 이미지의 세부 내용은 근거로 보충하지 않았다.
