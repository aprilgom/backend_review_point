# FC0217 · 도메인 생성 경계의 불변식

[소속 분야: 도메인 검증](../12-validation.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0216](FC0216.md) · [다음 FC: FC0220 →](FC0220.md)

## 검토 질문

- [ ] HTTP 외의 생성 경로에서도 유효한 객체만 만들어지도록 도메인 자체에서 필요한 제약을 보장하는가?

**직접 작성한 예시**

```java
record Name(String value) {
    Name { if (value == null || value.isBlank()) throw new IllegalArgumentException(); }
}
```

**적용 설명:** HTTP 외의 생성 경로에서도 도메인 불변식이 유지되도록 한다.

## 구체적인 검토 사례

- [ ] **상황:** HTTP 검증은 있지만 배치 생성은 우회한다.
  - **판단 기준:** 도메인 불변식을 생성 경계에 둔다.

- [ ] **상황:** 외부 상태 조회까지 값 객체가 수행한다.
  - **판단 기준:** 정적 값 제약과 실행 시 정책을 구분한다.
