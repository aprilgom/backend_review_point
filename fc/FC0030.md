## 검토 질문

- [ ] 연결·문장 실행·예외·자원 해제의 반복을 도우미로 묶되 트랜잭션 참여 계약을 유지하는가?

**직접 작성한 예시**

```java
// 직접 작성한 SQL 실행 도우미의 사용 예
sqlRunner.update("INSERT INTO activity(kind) VALUES (?)",
    statement -> statement.setString(1, "LOGIN"));
```

**적용 설명:** sqlRunner는 가상 자체 도우미다. 연결 생성·해제·예외 변환을 공통화하되 트랜잭션 참여 계약을 먼저 정한다.

## 구체적인 검토 사례

- [ ] **상황:** DAO마다 연결·예외·해제가 반복된다.
  - **판단 기준:** 공통 실행 도우미로 정책을 모을 수 있다.

- [ ] **상황:** 도우미가 빌린 연결도 닫는다.
  - **판단 기준:** 소유 연결과 트랜잭션 참여 연결을 구분한다.
