# FC0088 · 배포 경로에 독립적인 리소스 주소

## 검토 질문

- [ ] 정적 리소스 주소가 개발 머신에 묶여 있지 않고 실제 배포 base path에서도 동작하는가?

**직접 작성한 예시**

```html
<link rel="stylesheet" href="/assets/app.css">
```

**적용 설명:** 개발 머신 주소를 제거한 루트 상대경로다. 하위 경로에 배포하는 앱이라면 배포 base path도 반영한다.

## 구체적인 검토 사례

- [ ] **상황:** 정적 주소에 개발 머신 이름이 들어 있다.
  - **판단 기준:** 배포 기준 상대경로를 사용한다.

- [ ] **상황:** 앱을 하위 경로에 배포한다.
  - **판단 기준:** 루트 기준 경로가 아닌 base path 요구를 확인한다.
