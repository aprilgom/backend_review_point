# FC0405 · 해당 컨트롤러 테스트가 무엇을 검증하며 현재도 필요한 테스트인지 묻는다.

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0395](FC0395.md) · [다음 FC: FC0401 →](FC0401.md)

- [ ] 해당 컨트롤러 테스트가 무엇을 검증하며 현재도 필요한 테스트인지 묻는다. (설계 질문)
  - 조건: 작성자는 컨트롤러에서 DB 관련 로직을 분리하는 요구사항의 테스트라고 설명하며, 동작 확인 후 제거해도 괜찮을 것 같다는 의견을 냈다. 제거 여부에 대한 리뷰 참여자의 후속 판단이나 실제 제거 결과는 없다.

- [ ] 서비스 테스트에서 무엇을 검증하려는지 생각하고 컨트롤러 테스트의 검증 범위도 함께 고민하도록 제안했다. (개선 제안)
  - 조건: 테스트 목적과 수준을 돌아보라는 요청이며, 구체적인 누락 테스트나 컨트롤러 테스트의 결함을 확정한 것은 아니다.

- [ ] Controller 응답을 검증하는 테스트도 추가해보자고 제안했다. (개선 제안)
  - 조건: 작성자는 @WebMvcTest를 먼저 학습한 뒤 작성하겠다고 했고, 이후 Controller 테스트를 작성했다고 보고했다. 실제 테스트 내용과 검증 범위는 이 대화에서 확인되지 않는다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
Reply reply = controller.create(new Input(""));
assertEquals(400, reply.status());
```

**적용 설명:** 컨트롤러의 입력 오류 변환 계약을 검증하는 예다. 도메인 계산 검증과 범위를 구분한다.
