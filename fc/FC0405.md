## 검토 질문

- [ ] 컨트롤러 테스트가 입력 변환·상태 코드·오류 처리 등 해당 경계의 계약을 실제로 검증하는가?

**직접 작성한 예시**

```java
Reply reply = controller.create(new Input(""));
assertEquals(400, reply.status());
```

**적용 설명:** 컨트롤러의 입력 오류 변환 계약을 검증하는 예다. 도메인 계산 검증과 범위를 구분한다.

## 구체적인 검토 사례

- [ ] **상황:** 컨트롤러 테스트가 도메인 계산만 검증한다.
  - **판단 기준:** 입력·응답 변환 경계의 책임을 확인한다.

- [ ] **상황:** mock 반환을 그대로 확인한다.
  - **판단 기준:** 검증이 실제 오류를 잡는지 평가한다.
