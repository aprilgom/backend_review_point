# FC0377 · 매핑과 어댑터 역할의 구분

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0382](FC0382.md) · [다음 FC: FC0380 →](FC0380.md)

## 검토 질문

- [ ] 요청에 맞는 핸들러를 찾는 일과 그 핸들러를 실행하는 일의 분리 이유를 설명할 수 있는가?

**직접 작성한 예시**

```java
Object handler = mapping.find(request.path(), request.method());
HandlerAdapter adapter = adapters.supporting(handler);
return adapter.invoke(handler, request);
```

**적용 설명:** 어떤 핸들러인지와 어떻게 호출할지를 나눈다. 핸들러 종류가 하나뿐이면 분리 비용도 검토한다.

## 구체적인 검토 사례

- [ ] **상황:** 라우팅과 호출 방식 분기가 함께 늘어난다.
  - **판단 기준:** 매핑과 어댑터의 책임을 구분한다.

- [ ] **상황:** 실제 변형이 없는데 계층만 많다.
  - **판단 기준:** 분리의 확장 이점과 비용을 비교한다.
