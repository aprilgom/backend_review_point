# FC0098 · 요청 처리 자원의 상한

[소속 분야: 비동기·동시성](../05-concurrency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0103](FC0103.md) · [다음 FC: FC0104 →](FC0104.md)

## 검토 질문

- [ ] 요청마다 스레드를 생성하지 않고 실행 수·대기열·거절 정책을 통해 부하를 제한하는가?

**직접 작성한 예시**

```java
ExecutorService pool = new ThreadPoolExecutor(
    4, 4, 0, TimeUnit.SECONDS, new ArrayBlockingQueue<>(64),
    new ThreadPoolExecutor.AbortPolicy());
```

**적용 설명:** 요청마다 새 스레드를 만드는 대신 작업 수·대기열을 제한한다. 거절 응답 처리와 종료 시 shutdown도 필요하다.

## 구체적인 검토 사례

- [ ] **상황:** 요청마다 새 스레드를 만든다.
  - **판단 기준:** 실행 수와 대기열에 상한을 둔다.

- [ ] **상황:** 상한 도달 시 예외가 사용자에게 새어 나온다.
  - **판단 기준:** 거절·재시도·과부하 응답 정책을 마련한다.
