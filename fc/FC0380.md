# FC0380 · 도메인 행동의 응집도

## 검토 질문

- [ ] 서비스에 흩어진 계산과 판단 중 관련 데이터를 가진 도메인에 모을 수 있는 것이 있는가?

**직접 작성한 예시**

```java
Money total = order.total();
```

**적용 설명:** 서비스가 주문 항목을 꺼내 계산하기보다 관련 데이터를 가진 객체에 계산을 위임한다. 외부 API 호출까지 도메인에 넣지는 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 데이터와 관련 계산이 서로 멀리 있다.
  - **판단 기준:** 도메인 행동으로 모을 수 있다.

- [ ] **상황:** 외부 API까지 도메인에 넣는다.
  - **판단 기준:** 순수 판단과 외부 조율 책임을 구분한다.
