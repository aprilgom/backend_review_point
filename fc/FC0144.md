# FC0144 · 영속 객체의 생성 계약

[소속 분야: 데이터 관계·영속성](../08-persistence.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0143](FC0143.md) · [다음 FC: FC0145 →](FC0145.md)

## 검토 질문

- [ ] 매핑 도구가 요구하는 생성 경로와 정상 도메인 생성 경로를 구분하고 접근 수준을 제한했는가?

**직접 작성한 예시**

```java
@Entity
class Receipt {
    protected Receipt() {}
    public Receipt(String number) { this.number = number; }
}
```

**적용 설명:** 매핑 도구의 생성 경로와 도메인 생성 경로를 구분한다. ID·필드 매핑은 생략했다.

## 구체적인 검토 사례

- [ ] **상황:** 매핑 도구가 객체를 생성하지 못한다.
  - **판단 기준:** 필요한 생성자와 접근 조건을 확인한다.

- [ ] **상황:** 도구용 생성자로 일반 코드가 빈 객체를 만든다.
  - **판단 기준:** 정상 생성 경로와 분리한다.
