# FC0367 · 파싱·업무 처리·출력의 분리

[소속 분야: 책임·계층 경계](../19-responsibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0364](FC0364.md) · [다음 FC: FC0362 →](FC0362.md)

## 검토 질문

- [ ] 요청 객체나 파서가 업무 실행과 응답 생성까지 담당하지 않도록 처리 단계를 구분했는가?

**직접 작성한 예시**

```java
Request request = parser.parse(input);
Reply reply = dispatcher.dispatch(request);
encoder.write(reply, output);
```

**적용 설명:** 파싱·실행·출력을 분리해 프로토콜 값 객체에 부작용이 몰리지 않게 한다.

## 구체적인 검토 사례

- [ ] **상황:** 요청 객체가 파싱·실행·출력을 모두 한다.
  - **판단 기준:** 단계별 계약과 실패 책임을 나눈다.

- [ ] **상황:** 단계마다 같은 데이터를 다시 파싱한다.
  - **판단 기준:** 경계 분리와 불필요한 중복을 구분한다.
