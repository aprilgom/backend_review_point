# FC0199 · 완료 상태와 검증 근거

## 검토 질문

- [ ] 요구사항의 완료 표시가 실제 구현·검증 상태와 일치하는가?

**직접 작성한 예시**

```text
완료: 빈 제목 거절 — rejectsBlankTitle 테스트 통과
미완료: 제목 중복 정책 — 요구사항 확인 필요
```

**적용 설명:** 완료 표시를 근거와 연결하는 문서 조각이다. 학습·검토 중인 항목을 구현 완료로 표시하지 않는다.

## 구체적인 검토 사례

- [ ] README의 기능 요구사항 목록에서 완료한 항목을 체크해 달라고 요청했다. (개선 제안)
  - 조건: 작성자는 체크를 깜빡했다고 답했다. 체크리스트가 실제로 갱신되었는지는 확인되지 않는다.

- [ ] README의 기능 요구사항 체크리스트에 완료 표시를 하지 않은 것이 의도적인지 질문했다. (설계 질문)
  - 조건: 작성자는 표시를 잊었다고 답했다. 체크리스트 갱신이나 각 기능의 실제 구현 완료 여부까지 확인된 것은 아니다.

- [ ] README의 기능 구현 목록에 완료 체크를 표시해 달라고 요청했다. (개선 제안)
  - 조건: 미체크 상태의 기능 구현 목록에 달린 짧은 요청이며, 작성자는 체크했다고 답했다. 이 답변만으로 해당 기능의 실제 구현 완료 여부까지 확인되는 것은 아니다.
