# FC0199 · 완료 상태와 검증 근거

## 검토 질문

- [ ] 요구사항의 완료 표시가 실제 구현·검증 상태와 일치하는가?

**직접 작성한 예시**

```text
완료: 빈 제목 거절 — rejectsBlankTitle 테스트 통과
미완료: 제목 중복 정책 — 요구사항 확인 필요
```

**적용 설명:** 완료 표시를 근거와 연결하는 문서 조각이다. 학습·검토 중인 항목을 구현 완료로 표시하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 문서의 완료 표시가 실제 구현보다 앞선다.
  - **판단 기준:** 동작 검증과 연결해 완료를 표시한다.

- [ ] **상황:** 코드는 있지만 실패 경로를 확인하지 않았다.
  - **판단 기준:** 검증된 범위를 명확히 구분한다.
