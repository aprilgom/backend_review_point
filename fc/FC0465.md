# FC0465 · TxExecutor에 @FunctionalInterface 어노테이션을 붙이자고 제안했다.

[소속 분야: 타입·타입 테스트](../24-type-safety.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0458](FC0458.md) · [다음 FC: FC0455 →](FC0455.md)

- [ ] TxExecutor에 @FunctionalInterface 어노테이션을 붙이자고 제안했다. (개선 제안)
  - 조건: 작성자는 어노테이션을 추가했다고 답했다. 실제 변경 코드는 이 대화에 제시되지 않았다.

- [ ] RowMapper를 함수형 인터페이스로 사용할 것이라면 @FunctionalInterface를 붙이자고 제안했다. (조건부 제안)
  - 조건: 함수형 인터페이스로 사용할 의도가 있다는 조건의 제안이며, 어노테이션 부재로 실제 문제가 발생했다고 보고한 것은 아니다.

- [ ] 함수형 인터페이스로 사용하는 PreparedStatementSetter에 @FunctionalInterface를 명시적으로 붙이는 방안을 제안했다. (개선 제안)
  - 조건: 함수형 인터페이스로 사용하고 있는 것으로 보인다는 판단에 따른 제안이다. 작성자 답변이나 반영 결과는 제시되지 않았다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
@FunctionalInterface
interface TxWork<T> { T execute(Connection connection) throws SQLException; }
```

**적용 설명:** 자체 함수형 계약에 단일 추상 메서드 제약을 명시한다. 자원 수명과 예외 처리 책임도 문서화한다.
