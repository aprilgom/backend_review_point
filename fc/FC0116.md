# FC0116 · 조회 컬럼의 명시

## 검토 질문

- [ ] 실제로 필요한 컬럼만 조회해 전송량과 스키마 변경 영향을 제한하는가?

**직접 작성한 예시**

```sql
SELECT id, display_name FROM account WHERE id = :id;
```

**적용 설명:** 사용하는 컬럼을 명시하면 불필요한 전송과 스키마 변경의 영향을 줄일 수 있다.

## 구체적인 검토 사례

- [ ] **상황:** 조회에서 모든 컬럼을 가져온다.
  - **판단 기준:** 실제 사용 필드와 큰 데이터 전송을 점검한다.

- [ ] **상황:** 새 컬럼 추가 후 응답·매핑이 바뀐다.
  - **판단 기준:** 명시적 컬럼으로 계약을 제한할 수 있다.
