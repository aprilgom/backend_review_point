# FC0089 · 설정 파일의 형식과 우선순위

[소속 분야: 빌드·환경·배포](../04-build-config.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0076](FC0076.md) · [다음 FC: FC0082 →](FC0082.md)

## 검토 질문

- [ ] 설정이 여러 파일에 중복되거나 서로 덮어쓰지 않으며 형식·로딩 우선순위의 선택 이유가 명확한가?

**직접 작성한 예시**

```properties
# 애플리케이션이 읽는 단일 설정 파일 예
db.pool.max=8
feature.export=false
```

**적용 설명:** 동일 키를 여러 형식의 파일에 중복하지 않는 예시다. 프로파일은 실제 환경 차이를 표현하며 로딩 우선순위를 문서화한다.

## 구체적인 검토 사례

- [ ] **상황:** 같은 키를 여러 형식의 파일에 적는다.
  - **판단 기준:** 단일 정의나 명시적 우선순위로 정리한다.

- [ ] **상황:** 프로파일 이름만으로 환경이 구분된다고 본다.
  - **판단 기준:** 실제로 적용된 값을 확인한다.
