# FC0319 · 판정 메서드의 동작 의미

## 검토 질문

- [ ] 메서드 이름이 단순 보유 여부인지 겹침·포함·일치 판정인지 정확히 설명하는가?

**직접 작성한 예시**

```java
boolean hasOverlappingStation(Set<StationId> first, Set<StationId> second) {
    return first.stream().anyMatch(second::contains);
}
```

**적용 설명:** 겹침 검사라는 반환 의미를 이름에서 드러낸다.

## 구체적인 검토 사례

- [ ] **상황:** 보유 여부 이름으로 겹침을 판정한다.
  - **판단 기준:** 실제 반환 의미에 맞게 이름을 정한다.

- [ ] **상황:** 부정과 긍정 이름이 섞인다.
  - **판단 기준:** 호출 조건을 자연스럽게 읽을 수 있는지 본다.
