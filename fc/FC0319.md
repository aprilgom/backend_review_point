# FC0319 · 겹치는 역이 있는지 찾는 동작이 드러나도록 haveStation보다 적절한 메서드 이름을 검토해 보라고 제안했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0322](FC0322.md) · [다음 FC: FC0323 →](FC0323.md)

- [ ] 겹치는 역이 있는지 찾는 동작이 드러나도록 haveStation보다 적절한 메서드 이름을 검토해 보라고 제안했다. (개선 제안)
  - 조건: 리뷰 참여자는 메서드가 겹치는 역을 찾는 것으로 보인다고 표현했으며, 작성자는 haveOverlapStation으로 변경했다고 보고했다. 변경된 이름에 대한 후속 평가는 없다.

- [ ] createResponse라는 이름이 생성한 정보를 반환하는 메서드로 읽힐 수 있으므로 더 명확한 이름을 검토하도록 제안했다. (개선 제안)
  - 조건: 반환형이 void인 createResponse(DataOutputStream dos)에 대한 명명 의견이며, 대체 이름은 지정하지 않았다.

- [ ] 객체를 생성하는 메서드에 getUser라는 이름이 적절한지 의문을 제기하고, 생성 역할에 맞는 명명을 제안했다. (개선 제안)
  - 조건: 작성자는 메서드명을 createUser로 변경했다고 보고했다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
boolean hasOverlappingStation(Set<StationId> first, Set<StationId> second) {
    return first.stream().anyMatch(second::contains);
}
```

**적용 설명:** 겹침 검사라는 반환 의미를 이름에서 드러낸다.
