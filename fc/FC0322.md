# FC0322 · 검증 대상이 드러나는 이름

## 검토 질문

- [ ] 막연한 검증 메서드 이름 대신 무엇의 어떤 조건을 확인하는지 명시했는가?

**직접 작성한 예시**

```java
void validatePositiveQuantity(int quantity) {
    if (quantity <= 0) throw new InvalidQuantity();
}
```

**적용 설명:** 검증 대상을 메서드 이름에 드러낸다.

## 구체적인 검토 사례

- [ ] **상황:** 여러 검증 메서드 이름이 모두 모호하다.
  - **판단 기준:** 검증 대상과 조건을 표현한다.

- [ ] **상황:** 이름에 조건이 너무 많아진다.
  - **판단 기준:** 독립 불변식으로 분리할 수 있는지 본다.
