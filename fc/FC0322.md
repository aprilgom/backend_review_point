# FC0322 · 검증 대상을 알 수 있도록 verifyRequest를 더 의미 있는 메서드 이름으로 바꾸자고 제안했다.

[소속 분야: 가독성·명명](../17-readability.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0311](FC0311.md) · [다음 FC: FC0319 →](FC0319.md)

- [ ] 검증 대상을 알 수 있도록 verifyRequest를 더 의미 있는 메서드 이름으로 바꾸자고 제안했다. (개선 제안)
  - 조건: 현재 이름만으로 무엇을 검증하는지 잘 와닿지 않는다는 가독성 의견이며, 구체적인 대체 이름은 제시하지 않았다.

- [ ] findIdByUserName 메서드 이름을 findIdByUsername으로 변경하도록 제안했다. (개선 제안)
  - 조건: 코드 제안으로 메서드 이름의 표기를 변경했으며, 실제 반영 여부는 확인되지 않는다.

- [ ] 단순한 update라는 이름 대신 어떤 변경을 수행하는지 드러나는 메서드 이름을 제안했다. (개선 제안)
  - 조건: 작성자는 변경 대상 필드마다 메서드가 늘어날 수 있고 메서드 이름으로 내부 상태가 노출되는 것 아니냐고 반문했다. 이에 대한 후속 답변이나 합의는 없다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```java
void validatePositiveQuantity(int quantity) {
    if (quantity <= 0) throw new InvalidQuantity();
}
```

**적용 설명:** 검증 대상을 메서드 이름에 드러낸다.
