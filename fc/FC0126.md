# FC0126 · 조인 조회와 단계별 일괄 조회의 비교

## 검토 질문

- [ ] 한 번의 복잡한 조회와 여러 단계의 일괄 조회를 왕복 비용·중복 전송·가독성으로 비교했는가?

**직접 작성한 예시**

```sql
SELECT topic_id, COUNT(*) AS uses
FROM booking GROUP BY topic_id ORDER BY uses DESC, topic_id;
```

**적용 설명:** 집계 후 상세를 일괄 조회하는 방식과 조인 한 번으로 가져오는 방식을 왕복 횟수·중복 전송량으로 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 집계와 상세 조회를 큰 조인 하나로 합친다.
  - **판단 기준:** 반환 중복과 실행 계획을 비교한다.

- [ ] **상황:** 두 단계 조회 사이 데이터가 바뀐다.
  - **판단 기준:** 요구된 일관성에 맞는 읽기 범위를 정한다.
