# FC0413 · 도메인 단위 테스트의 경계값

[소속 분야: 테스트 대상·검증](../21-test-behavior.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0409](FC0409.md) · [다음 FC: FC0414 →](FC0414.md)

## 검토 질문

- [ ] 인수 테스트와 별개로 도메인의 불변식과 경계를 빠르게 검증하는 테스트가 있는가?

**직접 작성한 예시**

```java
assertThrows(SameEndpoint.class, () -> new Segment(stationA, stationA));
```

**적용 설명:** HTTP 흐름 없이 도메인 불변식을 빠르게 검증한다.

## 구체적인 검토 사례

- [ ] 인수 테스트에 비해 도메인 클래스 테스트가 부족해 보이므로 도메인 단위 테스트를 추가하자는 제안이다. (개선 제안)
  - 조건: 인수 테스트는 충분하다는 참여자의 평가를 전제로 하며, 추가할 개별 테스트 사례는 명시하지 않았다.

- [ ] 모든 도메인의 단위 테스트까지 작성하지 않더라도 통합 테스트는 추가해 보도록 제안했다. (개선 제안)
  - 조건: 테스트 범위에 대해 완화된 대안을 제시한 것이며, 특정 검증 시나리오는 명시하지 않았다. 작성자는 테스트 작성 의사를 밝혔지만 완료 여부는 확인되지 않는다.

- [ ] 도메인으로 검증 책임을 분리하면서 해당 검증에 대한 단위 테스트도 작성하도록 제안한다. (개선 제안)
  - 조건: 리뷰 참여자는 도메인 검증에 대한 단위 테스트가 미션 요구사항에 명시되어 있다고 설명했다. 실제 테스트 추가 여부는 확인되지 않는다.
