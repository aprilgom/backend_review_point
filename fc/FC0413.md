## 검토 질문

- [ ] 인수 테스트와 별개로 도메인의 불변식과 경계를 빠르게 검증하는 테스트가 있는가?

**직접 작성한 예시**

```java
assertThrows(SameEndpoint.class, () -> new Segment(stationA, stationA));
```

**적용 설명:** HTTP 흐름 없이 도메인 불변식을 빠르게 검증한다.

## 구체적인 검토 사례

- [ ] **상황:** 인수 테스트만으로 모든 도메인 규칙을 확인한다.
  - **판단 기준:** 경계값은 빠른 단위 검증으로 보완한다.

- [ ] **상황:** 내부 필드 구조를 직접 단언한다.
  - **판단 기준:** 공개 행동과 불변식을 검증한다.
