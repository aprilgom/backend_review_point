## 검토 질문

- [ ] 표현의 가독성과 실제 비용을 비교하고 추측만으로 반복 처리 방식을 최적화하지 않는가?

**직접 작성한 예시**

```java
for (Item item : items) {
    validate(item);
}
```

**적용 설명:** 단순 반복은 읽기 쉬운 표현을 택한다. 스트림·루프의 성능 차이를 근거 없이 일반화하지 않는다.

## 구체적인 검토 사례

- [ ] **상황:** 모든 루프를 스트림으로 바꾼다.
  - **판단 기준:** 읽기 흐름과 실제 비용을 비교한다.

- [ ] **상황:** 작은 비용 차이를 전체 병목으로 추정한다.
  - **판단 기준:** 실제 사용 규모에서 측정한다.
