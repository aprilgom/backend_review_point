# FC0041 · 이미지 요소의 alt가 어떤 용도로 사용되는지 물으며 관련 문서 확인을 권했다.

[소속 분야: 접근성·의미론](../02-accessibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0037](FC0037.md)

- [ ] 이미지 요소의 alt가 어떤 용도로 사용되는지 물으며 관련 문서 확인을 권했다. (설계 질문)
  - 조건: 작성자는 처음에는 대체 이미지를 지정하는 것으로 이해했다고 답했으나, 문서 안내 후 대체 메시지임을 알게 되었다고 자신의 설명을 정정했다. 외부 문서의 상세 내용은 근거로 보충하지 않았으며, 리뷰 참여자가 현재 alt 값의 결함이나 구체적인 변경을 직접 요구한 것은 아니다.

**직접 작성한 예시 · 첫 번째 백엔드 항목**

```html
<img src="/images/guide.png" alt="설정 메뉴에서 알림을 켜는 위치">
<img src="/images/divider.png" alt="">
```

**적용 설명:** 정보 이미지는 의미를 설명하고 장식 이미지는 빈 대체 텍스트를 사용한다. 인접 문구와 중복되는 설명은 줄인다.
