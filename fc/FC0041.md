# FC0041 · 이미지의 대체 텍스트

[소속 분야: 접근성·의미론](../02-accessibility.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0037](FC0037.md)

## 검토 질문

- [ ] 이미지의 정보·장식 역할에 맞는 대체 텍스트를 제공하고 주변 설명과 불필요하게 중복하지 않는가?

**직접 작성한 예시**

```html
<img src="/images/guide.png" alt="설정 메뉴에서 알림을 켜는 위치">
<img src="/images/divider.png" alt="">
```

**적용 설명:** 정보 이미지는 의미를 설명하고 장식 이미지는 빈 대체 텍스트를 사용한다. 인접 문구와 중복되는 설명은 줄인다.

## 구체적인 검토 사례

- [ ] **상황:** 정보 이미지에 대체 설명이 없다.
  - **판단 기준:** 이미지가 전달하는 의미를 짧게 설명한다.

- [ ] **상황:** 장식 이미지가 반복 설명을 만든다.
  - **판단 기준:** 의미가 없거나 중복되면 빈 대체 텍스트를 고려한다.
