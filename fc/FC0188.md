## 검토 질문

- [ ] 캐시의 크기·만료·무효화·키 범위·동시 미스 정책을 실제 사용 요구에 맞게 정의했는가?

**직접 작성한 예시**

```java
CacheKey key = new CacheKey(accountId, query);
return cache.get(key, () -> repository.search(accountId, query));
```

**적용 설명:** 로컬 캐시 도입의 사용 형태다. 크기 제한·만료·무효화·키에 사용자 범위 포함 여부를 확인한다.

## 구체적인 검토 사례

- [ ] **상황:** 캐시 라이브러리를 성능만 보고 선택한다.
  - **판단 기준:** 크기·만료·무효화·장애 동작을 확인한다.

- [ ] **상황:** 키에서 사용자 범위를 생략한다.
  - **판단 기준:** 공유하면 안 되는 결과가 섞이지 않게 한다.
