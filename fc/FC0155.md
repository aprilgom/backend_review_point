# FC0155 · 구현 탐색과 등록 방식

[소속 분야: 의존성·교체 가능성](../09-dependency.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0149](FC0149.md) · [다음 FC: FC0151 →](FC0151.md)

## 검토 질문

- [ ] 구현을 직접 등록할지 동적으로 탐색할지 결정하고 초기화 실패·순서·운영 복잡성을 처리하는가?

**직접 작성한 예시**

```java
List<HandlerMapping> mappings = ServiceLoader.load(HandlerMapping.class)
    .stream().map(ServiceLoader.Provider::get).toList();
```

**적용 설명:** 구현 탐색을 위한 JDK 대안이다. 서비스 제공자 등록·초기화 실패·순서를 명시하고 동적 탐색의 복잡성을 비교한다.

## 구체적인 검토 사례

- [ ] **상황:** 지원 구현을 코드에 직접 나열한다.
  - **판단 기준:** 확장 빈도에 따라 동적 등록을 비교한다.

- [ ] **상황:** 자동 탐색 결과 순서에 의존한다.
  - **판단 기준:** 우선순위·충돌·초기화 실패 규칙을 둔다.
