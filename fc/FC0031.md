# FC0031 · 표준 enum 변환 기능의 활용

[소속 분야: 추상화·중복](../01-abstraction.md) · [전체 목차](../README.md) · [FC 번호별 목차](../FC_INDEX.md) · [← 이전 FC: FC0029](FC0029.md) · [다음 FC: FC0032 →](FC0032.md)

## 검토 질문

- [ ] 직접 작성한 문자열 변환을 표준 기능으로 단순화할 수 있으며 대소문자·잘못된 값의 처리가 명확한가?

**직접 작성한 예시**

```java
Method method;
try { method = Method.valueOf(raw.toUpperCase(Locale.ROOT)); }
catch (IllegalArgumentException invalid) { throw new BadMethod(raw); }
```

**적용 설명:** 자체 enum 변환 예시다. 대소문자 정규화 허용 여부와 지원하지 않는 메서드의 응답 정책을 정한다.

## 구체적인 검토 사례

- [ ] **상황:** 문자열을 enum으로 바꾸는 분기가 반복된다.
  - **판단 기준:** 표준 변환으로 대체하고 오류 계약을 정한다.

- [ ] **상황:** 대소문자가 다른 외부 값이 들어온다.
  - **판단 기준:** 정규화를 허용할지 프로토콜 규칙에 따라 결정한다.
